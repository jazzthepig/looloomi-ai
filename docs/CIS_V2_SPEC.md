# CIS v2 —— 分数只留慢维度,动量 / 情绪 / 热度改成「状态」(2026-10-22,台账 S-668 / S-669)

> Jazz 10-22:「先升级 CIS,编制和数据都有不少提升空间。」裁定:**拆两层**、**只扩传统资产不加币**、**影子并行,过了再切**。

## 为什么改

| 证据 | 说的事 |
|---|---|
| S-383 | v1 的综合分有区分度,而那个区分度就是动量;综合分比它的动量支柱还弱 |
| S-523 | 2025-05 → 2026-10:OUTPERFORM 那组跑输 UNDERPERFORM 那组 |
| CIS_STANDARD §6 | 正式档位(两种口径)都不预测之后收益 —— 档位是描述 |
| S-630 | 当 ② 倾斜用,在山寨里挑币与随机打乱分不开 |
| S-589 / S-587 | 两段都为正的只有 F、O 与质量(大 + 稳) |
| S-664 / S-665 | 「不稀释」留出段 IC +0.119;开在稀释币上的 R-v2 票少赚一半 |

CIS 的本职是 ②(在持仓里多配更好的资产)。分数里应该只留**慢、难伪造、两段数据里都站得住**的东西;
「最近谁在追」照样展示,但作为状态,不冒充评级。

## 第一层:分数(`src/data/cis/v2.py`,唯一一份定义)

| 组 | 维度(组内百分位,等权,≥ 2 维才打分,不拟合权重) |
|---|---|
| 加密(CIS 的 25 个,不加币) | 规模(log 市值)· 稳定(−90 日日收益 σ)· 供给纪律(−流通量 90 日增长)· v1 的 F 支柱 · v1 的 O 支柱 |
| 个股(CIS 现有美股 + World50 候选池美股挂牌 / 美元 ADR) | 规模 · 稳定(−26 周周收益 σ,总回报口径)· 供给纪律(−**申报**股数 52 周增长 = 净回购为正;直接读 `world50_mcap_weekly.shares`,**不**用 市值 ÷ 收盘 推 —— 收盘是总回报复权的)|
| 宏观 ETF(债、商品、外汇、地产、新兴、SPY / QQQ / XLF) | **不打分**(没有供给与基本面可言),只给状态层;影子期内对外仍是 v1 |

同一个「供给纪律」跨两个资产类别:币的流通量增长与公司的净增发是同一件事 —— 持有人被稀释。
个股的基本面这一版缺(EODHD 基本面 403,SEC 只有收入),明说,不补代理。

## 第二层:状态(S-669,只描述)

趋势(价格对 50 / 200 日线)· 30 日动量(组内强 / 中 / 弱)· 拥挤(加密:7 日平均资金费率组内 z)· 市场情绪(FNG / VIX)。
对外写「描述,不是预测」;S-669 量出有预测力的标签只记为候选,另立预注册,不塞回分数。

## 怎么上线(Jazz:影子并行,过了再切)

- 影子:每天与 v1 正式序列并排算 v2(新版本号 `cis-v2.0`,v1 的历史原样保留,一个 d 只发一次)。
- **按组切换**(S-668 原文):影子连续 20 天 ≥ 95% 名字有分、输入齐;换档频率不高于 v1;证据 —— 个股要 H1 过(T-169),
  加密要 H2 回放分位 ≥ 80(T-170)。不满足的组继续 v1,v2 影子累计 26 周前向 IC > 0 再提。
- 切换后撤回:某组前向滚动 26 周平均 IC < 0 且 t ≤ −2 ⇒ 撤回 v1,记台账。
