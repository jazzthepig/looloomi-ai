## 1. The kernel, stated geometrically(内核的几何表述)

- ARCHITECTURE 的内核:最深的对象不是 Asset,是 **Entity/Decision** —— 影响力作为**向量场**
  传播成 quality 与 price。CIS 与动量是波前**经过之后**的反射。**Edge = lag(时滞就是优势)。**
- 几何化:embedding 相似度图 = **扩散场/传播介质**。相似 = 传播意义上的"近"。一个决策在场上
  注入信号,沿边扩散 —— `propagation.py` 的 `p=(1−α)s+αWp` 就是这个波前的线性算子。
- **beta+ 是时间向量**:站在波前上游。判据(S-81 定义):`entanglement_delta = p − s` —— 场
  (邻域)已动而节点自身反射未动 ⇒ 节点在波前上游 ⇒ beta+ 候选。

## 2. Be water(大象无形的算子形式)

- 没有冻结的因子。场算子 **W 每个周期随 embedding 重塑** —— 策略是"当前 regime 下对
  价格发现的追踪",不是固定公式(ARCHITECTURE §大象无形)。
- Regime 不是标签,是**场的相**:同一算子在不同相里给出不同的传播结构。R20 的教训:相变
  不可 profitable 地择时 —— regime 信息只进 sizing,不做 alpha 轮动。
- 稳定性溢价的真解读(S-76/R63b):ΔS/ΔO 大 = 场刚经历大重定价 = 高波相 = edge 退化。
  这是"相"的读数,不是采样延迟问题。

## 3. Be quantum(量子表述 —— 是严格类比,不是玄学)

- **叠加态**:资产的状态不是一个标量分,是**分布** —— I5 规定编码 mean/vol/p10(左尾)。
  R63 证明高 S 均值不变而尾部加深:只看均值的 schema 恰好瞎在亏钱的地方。v5 的
  `blended_for_display` 明令禁止用于排序 —— 因为它把两个正交可观测量塌缩成一个数。
- **非局域/纠缠**:节点的完整状态依赖**整个场**,不只自身坐标。`entanglement_delta` 度量
  "场对节点的隐含"超出其自身反射的部分。
- **测量与塌缩**:CIS 快照是一次**测量** —— 它把连续演化的场塌缩成一个读数,且带 lag。
  S-76 的实证:S/O 与价格同 bar 塌缩(coincident),所以**测量结果(level)不携带波前信息**。
- **S-81 的核心定理(实证,勿丢)**:**扩散"反射"(level)被证伪**(IC −0.16 —— 只是反推
  低分);**必须扩散"因"(change/flow/decision)**。正确形态:邻域的 Δpillar / 资金流(D1)/
  注意力扩散(D4)/ holder-Δ 是否领先节点自身的前向变化。这是 frontier 的可证伪形式,
  等真·多周期 CIS 数据(data_align)开测。
- **量子计算应用(前向钩子,保持线性以便移植)**:
  - 场扩散 `p=(1−α)s+αWp` 是**线性算子** = 经典 PPR,天然对应 **quantum walk**;保持算子
    线性,未来量子版是直接替换,不是重写。
  - 组合/sleeve 选择(coverage_gaps 填洞 + redundancy 去重 + 容量约束)是 **QUBO 结构**,
    QAOA/量子退火的标准候选。
  - 高维 embedding 的 **amplitude encoding**:27+ 维态可编码为 log₂(n) qubits —— VDB 里的
    向量就是未来量子态制备的经典描述。
  - 诚实边界:今天全部是 **quantum-inspired classical**;不声称量子优势;所有主张仍过
    反冒充 gauntlet(事件计数、OOS、per-cycle)。

## 5b. ⚠️ 收益层级 —— 资产管理的四级优先序(Jazz, 2026-07-27;凌驾于一切策略工作)

> **"我是做 asset management 的:首先保证吃到 beta,然后 beta+,再 beta multiplier,最后才考虑 pure alpha。"**

**这是优先级,不是菜单。低层没锁住之前,不许去做高层。**

| 层 | 是什么 | 我们的载体 | 状态 |
|---|---|---|---|
| **① Beta capture** | 保证吃到市场收益(等权/市值持有本 panel) | FoF 核心持仓;被动、满仓、低成本 | 🔴 **从未系统落地** — 最该先做的一层 |
| **② Beta+** | 在持仓内**超配**更优资产(选券倾斜,仍满仓多头) | **CIS 的真正岗位**(F锚/A/O 排序 → 权重倾斜) | 🟡 有分数,无倾斜产品 |
| **③ Beta multiplier** | **择时调节总暴露**(1.0x / 1.3x / 0.7x),不做空 | regime × vol 语法(S-78)、liquidity gate、CIS v5 risk score → size | 🟡 有信号,被我错框成"alpha sizing" |
| **④ Pure alpha** | 市场中性/对冲的独立收益 | 15 连败的坟场(R76–R94) | 🔴 最难、最后、目前无幸存者 |

**我们把顺序做反了 —— 这是比任何单个 refutation 都贵的错误。** 整个 R76–R94 是在打第④层
(cross-sectional demean = 构造上中性 = 先扔掉 beta),而第①层(保证吃到 beta)**从来没有作为产品被建过**。
在一个长期正漂移的资产类里,先扔掉唯一确定的收益源、再去赌最不确定的那部分,15 次全灭不是运气差,是设定错误。

**重新归位(每个已有资产的正确岗位):**
- **CIS ≠ alpha 引擎,CIS = beta+ 引擎。** 它的产品形态是**在持有的 panel 内决定超配谁**,不是构造多空。
  S-80 的 F_IC 12/12 年为正正是 beta+ 该有的证据形态(稳定的排序能力),不需要它做出中性 alpha。
- **S-78 的 regime×vol 是第③层(beta multiplier),不是 alpha sizing。** 我当时按"中性 sleeve"去证伪它;
  作为**暴露调节语法**它的门槛完全不同 —— 只需要"在某些相位少暴露/多暴露能改善持有体验"。
- **S-82 的事件延续是第②/③层的输入**:事件后向该资产倾斜(②),或短暂提升总暴露(③)。**全程不做空。**

**三条纪律:**
1. **默认满仓多头,倾斜而非中性(tilt, don't neutralize)。** 中性只在有明确已验证的对冲理由时才允许,
   且必须显式说明放弃 beta 的代价。
2. **总收益是第一报告口径。** 每个策略必须报 `total_return`、`vs 等权持有本 panel`、再报超额。
   **只报超额 = 隐藏了它连 beta 都没跑赢。** 基准永远是"等权持有",不是 0。
3. **β 调整用于归因,不用于建仓。** R62 的 β-adj 度量继续判断"信号是否携带信息";**仓位不因此中性化。**

**S-82 的正确读法:** up-shock 后事件资产 5 日**原始 +5.44%**(+2.71% 超额 + 其余 beta)。产品含义不是
"抓 +2.71% 的中性 alpha",而是 **持有 panel(①)+ 事件后向该资产倾斜(②)**。邻居没有额外超额,
但它们也在 panel 里,照样吃 beta。**没有任何一步需要做空。**

### 5b 之前的旧表述(保留以示纠正路径)
**"不吃 beta 是很愚蠢的。"** 这条凌驾于所有测量习惯之上,写在这里因为它已经吃掉了我们 15+ 次尝试。

**病灶:把"归因"和"产品"搞混。** 扣掉市场基线对**测量机制**是对的(有没有传播);对**设计产品**是错的。
ARCHITECTURE §大象无形 早就写了:**beta = HOLD(被动捕获,升级版指数 / FoF 内核);alpha = niche(当下
正在被价格发现的具体低效)**。我们是 FoF —— 客户要的是**总收益**,不是一个漂亮的残差。

**它解释了整个坟场:** R76–R94 全族(cross-sectional demean / market-neutral L/S)**在构造上就把 beta 扔了**,
然后在残差里找纯 alpha。15 次全灭不是运气差,是**设定错误**:在一个长期正漂移的资产类里做中性,等于
先扔掉唯一确定的收益源,再去赌不确定的那部分。S-82 同理:邻居"超额 ≈ 0"但**原始 +3.39%** —— 它们照样

**三条纪律(从此写进每个 sleeve 的设计):**
1. **默认满仓多头,倾斜而非中性(tilt, don't neutralize)。** 信号的用途是决定**超配谁 / 何时加减暴露**,

   **只报超额 = 隐藏了它是否连 beta 都没跑赢**。基准永远是"等权持有本 panel",不是 0。

## 5b-bis. ⚠️ 层级之上还有一层:风格周期判断(OVERRIDE)—— Jazz, 2026-07-27

**纠正前一版规格的两个教条错误(我写错了,记在这里以免重犯):**

**错误一:把"正交"当成建仓约束。** 正交只是**归因工具**(为了知道钱从哪来);
**它绝不是仓位纪律。** 在市场边际流动性转向时,三层本来就应该**同时服从同一个判断** ——
那不是"污染归因",那是**正确的风险反应**。归因可以事后拆,风险不能事后补。

**错误二:给暴露设了 0.7x 下限、并禁止做空。**
> **Jazz: "在市场边际流动性转向的时候,有时候就是空仓或者裸空的好时候。"**

所以正确的暴露区间是 **[−0.3x … 1.3x]**,包含 **0x(空仓)** 与 **负(裸空)**。
①层"保证吃到 beta"的正确表述是:**默认状态是满仓吃 beta,但它是"条件性默认",不是无条件义务** ——
当周期判断说流动性在转向时,**空仓/做空优先于吃 beta**。少亏就是赚,这在资产管理里是第一性的。

### 因此架构变成:四层之上有一个 OVERRIDE 层
```
        ┌─────────────────────────────────────────────┐
   ⓪    │  风格/流动性周期判断 (REGIME OVERRIDE)      │  ← 最重要的一层
        │  正常相 → 放行①②③   转向相 → 压制一切     │
        └─────────────────────────────────────────────┘
                 ↓ 放行时                ↓ 转向时
        ① beta ② tilt ③ multiplier      空仓 / 裸空 / 极低暴露
```
**⓪层是我们最该建的能力,不是③层的一个信号变体。** 它的判据也不同:
不是"提升 Sharpe",而是 **"在 2018 / 2022 / 2025-26 这三段崩塌里,是否把回撤显著削掉"**。
一个只在牛市有效的⓪层没有意义;⓪层的全部价值在拐点。

**这与"beta 必须吃"不矛盾:** 吃 beta 是**默认**,⓪层是**例外处理**。
没有⓪层的纯多头 = 完整承受每一次熊市;有⓪层 = 大部分时间吃 beta,少数时间躲开/反手。

## 5b-ter. 组织形态:Millennium 模型(Jazz 的目标形态)

**Millennium 的本质不是"很多好策略",而是"中心化的风险分配 + 铁腕的资本回收"。**
平台的 edge 在**风险管理**,不在任何单个 pod。映射到我们:

| Millennium 机制 | 我们的对应 | 现状 |
|---|---|---|
| 多个独立 pod,各自小风险预算 | 多 sleeve;strategy_records 是 pod 名册 | 🟡 有名册,无预算 |
| **严格回撤止损**(pod 触及 ~5-7% DD 即削减/关闭) | **每个 sleeve 必须写明 stop 规则** | 🔴 **缺失 —— 最该补的** |
| 中心风险台按表现动态调配资本 | ⓪层 + 组合层的资本分配器 | 🔴 未建 |
| pod 层面可方向性,组合层面受控 | sleeve 可多可空,组合暴露由ⓠ层统一约束 | 🟡 |
| 严禁 pod 之间隐性相关 | `redundancy()` 已能测(risk_direction_score 是枢纽) | ✅ 工具已有 |

**立刻可执行的一条:每个 sleeve 记录必须新增 `max_dd_stop` 与 `capital_action_on_breach`**
(削半 / 归零 / 观察),写进 `StrategyRecord` 的证据字段,由 CI 强制 —— **没有止损规则的 sleeve 不许进生产。**
这是 Millennium 化最便宜、最见效的一步:先有纪律,再谈规模。

## 6. 反冒充边界(这一层的纪律)

高维语言容易变成玄学。此文档的每个可操作主张都已经或必须过 loop:S-76/S-81 是已跑的实证
(含证伪);§3 的 frontier 形式有明确数据门槛;量子钩子只约束**算子保持线性**,不改变任何
当下决策。**凡不能被外部 agent 验证的表述,不得出现在投资者面前。**
