# CIS 统一标准 v1 —— 历史重建与实盘同一条序列(T-079 / S-531)

> Jazz 10-09:「先开始重建。付费 api 待定,先统一标准。重建不是问题,问题是要数据和时序对上。有缺了维度的补上。」

## 为什么

S-530 测得:我们手里的 CIS 历史是三段拼起来的 —— 2025-05 → 2026-05 是事后用动量 + 波动**代理**重建的(77%),
2026-04 起是 Mac 引擎 T2、06-05 起 T1,同时还有 Railway 快照和小时线在写同一批名字;日视图每天取「最后一条」,
来源天天换。三段的方向都不一样(重建段 OUTPERFORM 维持住之后跑赢,实盘 T1 之后跑输)。
**一条序列只能有一个公式、一套取数时点、一个来源优先级** —— 否则「根据过往表现展示」展示的是拼接缝。

## 1. 公式:冻结,一处定义

- 支柱:`src/data/cis/cis_provider.py::calculate_cis_score`(纯函数)。
- 合成:`calculate_total_score`(类别基础权重 × 状态乘数,重归一)。**IC 反馈层关闭**(`ic_mult=None`)—— 它读的是当时 Redis 里的值,历史上无法复原。
- 评级 / 信号:`get_grade` / `get_signal`(A+ ≥ 85 … F < 25)。
- 状态:`detect_regime(btc_30d, fng, vix, btc_dominance)`。
- 版本:`CODE_REF = "cis-standard-v1"`;公式一改,版本号就改,重建整条重跑,旧版本的行保留。

## 2. 时点:d = UTC 日,取 d 收盘时已知的值

| 输入 | 时点规则 |
|---|---|
| 加密价格、高低、成交 | d 那根日线(UTC 00:00–24:00),`bar_semantics.covered_day` |
| CoinGecko 市值 / 总成交 / 价格 | market_chart 在 d+1 00:00 的采样点 = d 的收盘(已有约定,S-436) |
| 传统资产(EODHD) | d 当天或之前最近一个交易日的收盘(美股收盘 20:00/21:00 UTC < d 收盘) |
| 恐惧贪婪 | 时间戳日期 = d 的那个值(00:00 UTC 发布,早于 d 收盘) |
| VIX | d 当天或之前最近一个交易日的收盘 |
| 资金费率 | d 当天结算的各期平均(UTC) |
| TVL(DeFiLlama) | 时间戳日期 = d 的那个点;**今天的占位点不收** |
| 30 / 7 / 1 日涨跌、ATH 距离、30 日 β | 只用 ≤ d 的收盘计算 |

## 4. 维度清单 —— 能复原的补上,不能复原的明说

| 维度 | 用在 | 历史 | 处理 |
|---|---|---|---|
| 价格、30/7/1 日动量、ATH 距离、日内波动 | M / O / S / A | ✓ 2020 起 | 照算 |
| 市值、总成交、成交/市值 | F / M / S | 市值 ✓;**总成交缺** | **补**:market_chart 的 total_volumes 一直被丢掉,改为落库 |
| TVL | F / O | 链 ✓;**协议缺** | **补**:DeFiLlama 协议 TVL 历史 |
| 恐惧贪婪 | S / 状态 | **缺** | **补**:alternative.me 全历史 |
| VIX | S(传统)/ 状态 | **缺** | **补**:EODHD |
| BTC 占比 | 状态 | **缺** | **补**:CG 全市场市值历史 |
| 资金费率 | O | 10 个名字 2024-02 起,其余 2026-09 起 | **补**:全部加密名字回填到 2023 |
| 传统资产日线 | 全部 | eodhd 2025-07 起 | **补**:回填到 2022-10 |
| 宏观 β(美元、VIX) | S / A | 实盘 T2 的 β 依赖已停的 yfinance,现在实际走「相对 BTC」代理 | v1 两边都用代理(一致);美元 / VIX 序列已补,v2 再换真 β |
| 未平仓量 | O | 币安只给 30 天 | **缺,不能复原** → 标准里置中性;前向起落库 |
| 美股基本面(PE、营收) | F(美股) | 季度财报有历史 | 第二步补(按披露日) |
| GitHub 提交 | S | 只能回看 52 周 | 第二步补;更早为空 |
| CG 开发者分、热搜排名、叙事乘数 | F / S | **没有历史** | **不进标准分**;作为单独的关注度叠加层,前向记录 |

不能复原的维度在重建与实盘两边**都**置中性 —— 只有这样两段才是同一个公式。实盘 T2 改到这个标准、Mac T1 收敛到同一函数,
是下一步(MINIMAX_SYNC §2 合约先行)。

**与实盘 T2 的已知口径差(重建取统一口径,实盘下一步跟上):** 加密成交额用 CG 全市场(实盘混用币安 24 小时成交);
「24 小时」用 UTC 日线(实盘是滚动 24 小时);传统资产成交按美元(实盘是股数);7 日动量用日线(实盘用 168 点小时线)。

## 5. 宇宙

`ASSETS_CONFIG`(加密 25 + 传统 33)。某个名字在 d 进入当天的宇宙 = d 有收盘且 ≥ 30 天历史。
类别中位数(S 的偏离项)= 当天同类别在宇宙内名字的 30 日涨跌中位数。**幸存者偏差**:名单是今天的,标注。

## 6. 标签:滞回(Jazz 10-09 批准)

分数 → 档位后,换档要越过门槛 ±2 分(门槛 85 / 65 / 45 / 35),按日终分数判定;在缓冲带内保持原档并标「观察 ↑/↓」。
T1 单一来源模拟:换档每名字每 30 天 2.35 → 1.30 次,3 天内变回 45% → 26%(S-530)。
