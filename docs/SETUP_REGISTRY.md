## 排队要挖的(每条先登记后计算)

- **拥挤的多头被套 ⇒ 破位**(教义 §5 第一行):资金费那一刀已经站住(S-886,形态 #1 的附加条件);持仓读数那一刀(S-881)切分退化 —— 按时点 z 在 2023 年后漂到一边,先改成滚动分位再重量(T-399)。
- **按币**:同一个触发,用按币的资金面向量挑「哪个币」(库里 652 个币,到现在一次没用过)—— S-881 之后。
- **投降 / 吸筹清单、派发清单**(档案里已有逐项读数,S-849 / S-855)各自做成带触发与认错标准的形态。
- ~~**反弹失败**做成触发~~ —— S-885:「反弹跌回一半就空」两段不一致(线下 · 抽 +2.5% → −3.3% / 张),**等破 20 日低再空(#1)才站住**;反弹失败的触发就是破位,不是回撤一半。
- **同一个价位的两种结局:扫过再收回(反手)vs 破位顺势** 与 **波动压缩后的突破**(外部从业者最常讲的两个形态,`docs/research/EXTERNAL_SETUPS_2026-11-15.md`)—— S-884 在量。

## 到 11-15 为止的一句总话(S-884 补)

价格触发是主力;状态在做空那一侧(熊市里的破位)最有用、要与人群读数一起确认(#1:p = 0.09,资金费分得开);在做多那一侧主要用来**排除**坏的格子(#2 / #3 的状态增量 p = 0.19 / 0.27,但「线下 · 二线领」做多两层都负)。

## 每张基率表必须自带的对照(S-882)

不带条件的全部样本;只满足「波动大」那一半条件的样本。没有这两组,常态会被读成形态 ——「两边至少碰一边 > 90%」在所有周末都是 95%。

## 不再做的写法

日历进场 × 单个读数的高低位(S-878:336 个条件,留出段确认 0 个);向量邻域 + 之后 60 天 + 每月一次(S-875 / S-876);
把现成的简单策略排一排当成「组合升级」(S-869 那一轮的起点);**「周末缺口会补」**(S-883:补的那一档被碰到 70%,同距离反方向的一档 68 – 70%,赌回补均值为零);**「熊市反弹回撤一半就空」**(S-885:早进会被剩下的回补挤掉);**「扫过前高 / 前低再收回就反手」**(S-884 两份实现:四格、两种止损,没有一格站住;不带状态时扫低收回做多 −2.4% / 0.0%、扫高收回做空 −0.8% / −0.8%);**「到期前钉住」**(S-883:中位窄 13 – 17%,秩检验不显著,2023 年后消失)。它们量出来的东西留作读数,不当形态。
