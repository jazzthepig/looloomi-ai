# Layer-② 倾斜 与 Layer-③ 暴露乘数 — 规格书 (Seth, 2026-07-27; M-WO-B / M-WO-C 的实现依据)

> 层级见 `HIGH_DIM_ONTOLOGY.md` §5b。①层基准见 `BETA_CORE_SPEC.md`(先有它,才有这两层)。
> **一句话:②改变"持仓内谁多谁少",③改变"总共暴露多少"。两者都不做空,都以①为基准。**
> 本文与 §BETA-CORE-SPEC §6 一致;有冲突以本文为准(更细)。

> **⚠️ 2026-07-27 修订(Jazz):正交是归因工具,不是建仓约束。** 本文的分层测试用于**归因**
> (知道钱从哪来);但在**边际流动性转向**时,三层应同时服从⓪层(风格周期)判断 —— 那不是污染归因,
> 是正确的风险反应。**⓪层 OVERRIDE 的优先级高于本文全部内容**,见 `HIGH_DIM_ONTOLOGY.md` §5b-bis。
> 暴露区间已由 [0.7, 1.3] 放宽为 **[−0.3, 1.3]**(含空仓与裸空)。

## 0. 分层的意义:三个独立的收益引擎,三条独立的证据链
把它们混在一个"策略"里,任何一层的失败都会污染其余两层的**归因**judgment —— 这正是我们过去 15 次踩的坑。
**分开建、分开测、分开归因;最后才谈叠加。**
**但:分层是为了看清,不是为了绑手。** 遇到⓪层转向信号,允许(且应当)三层同时收缩 —— 事后按本文
方法拆归因即可。

| 层 | 改变什么 | 不改变什么 | 失败时的后果 |
|---|---|---|---|
| ① Beta core | — | — | 无基准可比 |
| ② Tilt | **相对权重** | 总暴露恒为 100% | 选券无效,回落到① |
| ③ Multiplier | **总暴露 0.7–1.3x** | 相对权重(沿用①或②) | 择时无效,回落到②/① |

**正交性要求:②的测试必须固定暴露=100%;③的测试必须固定权重结构。** 否则无法归因。

# Layer-② — CIS 倾斜引擎 (M-WO-B)

## 2.1 它到底是什么
**CIS 的真正岗位。** 不是多空,不是 alpha —— 是"在①层已经持有的池子里,谁该多拿一点"。
S-80 的 **F_IC 12/12 年为正** 正是倾斜引擎需要的证据形态(稳定的排序能力),我们从未给它这个产品形式。

## 2.2 权重构造(唯一形式,别自创)
在①层的合格池与再平衡日上:
```
raw_i    = base_i × m(rank_i)          # base_i = ①层权重(EW 或 CW-capped)
w_i      = raw_i / Σ raw_i             # 归一化 ⇒ 永远满仓 100%
m(rank)  ∈ [0.5, 2.0]                  # 倾斜乘数,线性映射自 CIS 截面分位
```
- `m` 由**截面分位**决定(非绝对分数):最高分位 → 2.0,最低 → 0.5,中位 → 1.0,线性插值。
- **上下限 0.5x / 2.0x 是硬约束**(避免退化成集中押注);超限即截断。
- **禁止负权重。** 低分资产减配到 0.5x 为止,**不做空**(做空属于④层,已冻结)。
- 分数缺失(NaN)的资产 → `m = 1.0`(中性,不假装有观点 — I1)。

## 2.3 必须跑的变体(三组,回答三个不同问题)
| 变体 | 排序依据 | 回答的问题 |
|---|---|---|
| T1 | **pillar_F**(S-80 的 12/12 锚) | 最稳的单一 pillar 能否产生倾斜价值 |
| T2 | **CIS v5 return_score**(F锚 0.40/M 0.25/A 0.35) | 我们的合成分数是否优于单 pillar |
| T3 | **CIS v5 return_score × risk_score 调整**(高风险资产额外减配) | ③层之外,风险分在②层是否也有用 |
各变体 × ①层的 {EW, CW-capped} 基座 × {0bps, 10bps} 成本。

## 2.4 判据(与①层同口径,缺一不可)
1. **total_return / CAGR / Sharpe / maxDD,对比同基座的①层曲线** —— 主判据是"是否跑赢持有"。
2. **分周期符号稳定性**(2018熊/2020-21牛/2022熊/2023-24复苏/2025-26熊):**≥4/5 周期为正**才算稳。
   单周期靠一段行情堆出来的胜利不算(S-78/S-80 的教训)。
3. **换手与成本拖累**:倾斜必然增加换手;若 10bps 下优势消失 → 记为"成本不可行"。
4. **容量**:倾斜后的持仓相对 ADV 的占比;超配小市值资产是最常见的假胜利。
5. **事件计数不适用**(这是连续持仓,不是事件策略)—— 用分周期符号稳定性替代。

## 2.5 通过标准(pre-declared,事后不许改)
**Sharpe 提升 ≥ +0.15 且 maxDD 不劣化 ≥ 2pp 且 ≥4/5 周期为正 且 10bps 下仍成立。**
达不到 ⇒ 诚实结论是"CIS 在②层无产品价值",回落到①层等权/市值持有 —— **这也是一个有价值的结论**。

# Layer-③ — 暴露乘数 (M-WO-C)

## 3.1 它到底是什么
**择时总暴露,不做空、不选券。** 持有①(或②)的组合,按市场"相"缩放总仓位;
不足 100% 的部分**持现金**(可计入无风险利率,v1 记 0)。

## 3.2 构造(2026-07-27 修订:含空仓与裸空档)
```
exposure_t ∈ {−0.3, 0.0, 0.5, 1.0, 1.3}   # 五档离散
w_i,t = base_w_i × exposure_t              # 相对权重不变(归因用);⓪层转向时可整体压制
cash_t = 1 − exposure_t                    # exposure=0 ⇒ 全现金;exposure<0 ⇒ 裸空(见 3.4b)
```
**档位语义:** 1.3x 加杠杆 · 1.0x 满仓吃 beta(默认)· 0.5x 减仓 · **0.0x 空仓** · **−0.3x 裸空**。
**空仓与裸空只允许由⓪层(风格/流动性周期转向)触发**,不许由②层选券信号触发。
**信号来源(每个单独测,不许一开始就融合):**
| 变体 | 信号 | 出处 |
|---|---|---|
| E1 | **regime × vol 相位**(S-78 的格子) | 用暴露乘数的标准重测 —— 它当年被用中性 sleeve 的尺子误杀 |
| E2 | **stablecoin 流动性 Δ 门** | WEEKLY_REVIEW 2026-07-21:SR 0.83 vs 持有 0.64 |
| E3 | **CIS v5 risk_score / 市场宽度** | O 主导的风险分,规格见 cis_v5_architecture |

## 3.3 判据(与②不同 —— 门槛本来就该不同)
**③层的任务是改善持有体验,不是产生独立收益。** 因此:
1. **主判据:maxDD 改善 ≥ 5pp,且 total_return 不低于①层的 95%。**
   (少赚一点换显著少回撤 = 成功;这与 alpha sleeve 的判据根本不同 —— S-78 正是被错误的尺子判死的)
2. Sharpe 提升 ≥ +0.10。
3. **分周期:熊市周期必须改善**(2018/2022/2025-26 至少 2/3 改善),牛市周期不许损失 >10% 收益。
4. **换手**:档位切换频率 ≤ 12次/年(过频=择时噪声)。
5. **诚实检验**:与"永远 1.0x"对比之外,还要与**随机切换同频率**对比 —— 排除运气。

## 3.4 杠杆的边界(必须明确)
1.3x 需要杠杆。**v1 先做 {0.0, 0.5, 1.0} 三档(纯减仓/空仓版本),1.3x 作为独立变体单独报告**,
并注明融资成本假设(perp 资金费率或借贷利率)。**不许把杠杆收益混进"择时有效"的结论里。**

## 3.4b 裸空档(−0.3x)的额外纪律
做空是**唯一允许的例外**(④层其余仍冻结),因为它服务于风险,不是服务于 alpha。必须满足:
1. **只由⓪层转向信号触发**,且该信号在 2018/2022/2025-26 三段崩塌中**至少 2 段**提前触发(样本外)。
2. **成本显式**:借贷利率 + 资金费率 + 强平风险;裸空版本必须单独报告,不与减仓版混算。
3. **硬止损**:裸空头寸单独设 maxDD 停止线(见 §3.5),触及即平仓回到 0x。
4. **合规**:对外表述只用定位语言("降低/规避市场暴露"),**绝不出现做空建议类措辞**。

## 3.5 Millennium 化:每个变体必须自带止损规则(新增,强制)
`HIGH_DIM_ONTOLOGY.md` §5b-ter:平台的 edge 在**风险分配**,不在单个 sleeve。因此:
**每个 ②/③ 变体在 pre-declare 时必须写明 `max_dd_stop`(如 −12%)与 `capital_action_on_breach`
(削半 / 归零 / 观察 N 日)。没有止损规则的变体不许进生产 —— 由 `StrategyRecord` 证据字段 + CI 强制。**
回测时必须**带着这条止损跑**(不是事后加),因为止损会改变曲线形状。

## 4. 叠加(只有在①②③各自通过后才做)
```
最终组合 = ①合格池 × ②倾斜权重 × ③暴露乘数
```
**叠加报告必须给出归因分解**:总收益 = ①贡献 + ②贡献 + ③贡献 + 交互项。
任何一层未通过 ⇒ 该层乘数设为中性(②的 m≡1.0 / ③的 exposure≡1.0),**不许"整体跑赢"掩盖单层失败**。

## 5. 统一交付格式(两层通用)
- NAV 入 `beta_core_nav`,variant 命名:`tilt_{T1|T2|T3}_{ew|cw}_{0|10}bps`、`mult_{E1|E2|E3}_{...}`。
- 每个变体一张分周期表 + 对比①层的 Δ(return/Sharpe/maxDD/换手)。
- 结论写成 M- ledger 条目,**pre-declared 标准写在实验之前**(§2.5 / §3.3),事后不许调门槛。
- 报告口径统一:`total_return` · `vs ①层同基座` · 再报超额。

## 6. 边界
不做空 · 不加新资产类 · 不做单资产择时(那是④层或另一个产品)· 不在②③里偷偷做④。
**这两层的全部野心是:让"持有"这件事做得更好。**
