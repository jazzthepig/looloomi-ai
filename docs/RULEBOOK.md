# RULEBOOK.md — 现行交易规则(研究 / 模拟 / 实盘共用的默认值)

> **设计任何策略、模拟、回测之前先读这一页。** 它只回答一件事:**现在算数的是哪一版**。
> 为什么、证据、历史在出处里(DECISIONS / 台账 / 卡);这里不重复论证,只写现行值和它取代了什么。
> **规则改了 ⇒ 同一次提交里改这一页和 `src/data/evaluation/house_rules.py`**(`tests/test_house_rules.py` 校验两边说同一件事)。

## 研究前三问(每一份预注册的第一段;新研究脚本里写成 `HOUSE_RULES`,CI 查)

1. **哪一层、对哪个基准、用哪把尺?**(下面「层」与「尺」两节)
2. **用了哪些现行规则(原样)?改了哪一条?** 改的那一条就是被检验的变量,写进预注册;没写的就必须是现行值。
3. **有没有碰到下面任何一条裁定?**(① 只做多现货;条件 = 盯不是单;空单是票、要 ⓪ 签名;不提前止盈 …)碰到了 ⇒ 先停,问 Jazz 或改设计。

## 空头(T-370 v1,11-15 定稿;取代教义 §12 的「碰到目标就平 / 1R 移保本」)

| 规则 | 现行 | 出处 |
|---|---|---|
| 谁开 | **⓪ short 状态:Jazz 签名(选币、档位)才开**;系统管止损 / 到期 / 上限;`flat` / `off` ⇒ 全平 | DECISIONS 11-13;T-370 |
| 状态 | 线下(面板 `dist_200` < 0)· 稳定币抽(`stable_supply_30d` < 0) | T-370 v1;SETUP_REGISTRY #1 |
| 触发 | 收盘 < 此前 20 根日线的最低价(不含当天);7 日资金费 > 0(S-886) | `setup_watch.trigger_1` |
| 认错 | 被破那一档 × 1.01,且离进场 ≤ 8% | T-370 v1 |
| 管法 | **一次进满、不自动加仓;拿满 28 天;不提前止盈;不移保本**;冲高加仓 = Jazz 单独签名的一笔,自带止损、算进上限 | T-370 v1;S-612 / S-865 / S-874 / S-929 |
| 尺寸 | 档位 1 / 2 / 3 = 空头总名义占账户 10 / 20 / 30%,均分到各币 | T-370 |
| 配置级的空 | 低频、双向、用落袋利润做、扛单不设价格止损 —— 另一种对象,按账户口径判;**还没有站得住的规则** | DECISIONS 11-11;教义 §12 scope note |

## 多头票(R-v2,真钱)

| 规则 | 现行 | 出处 |
|---|---|---|
| 自有账户 | 名额 10、名义 ≤ 80%、每票风险 0.75% | DECISIONS 10-29 / 11-12;S-831 |
| 机构产品规格 | 每票风险 0.25%;单一来源的风险占比 ≤ 40% | DECISIONS 11-13;S-834 / S-835 |
| 管法 | 突破进场、SMA20 跟踪出场;不分批止盈、不收紧 | 教义 §11;S-612 |
| 过滤 | 跳过开票日 OI / 市值前 1/3;Binance 下架公告与监控标签 = 硬规则 | DECISIONS 10-27 / 11-07 |

## 尺(怎么判)

| 规则 | 现行 | 出处 |
|---|---|---|
| 多头 sleeve | 先报总收益、对「持有 ①」,再报超额 | HIGH_DIM §5b 纪律 2 |
| 对冲 / 套息 / 现金 / 空头 | 按**账户口径**:加上它之后整个账户的回本时间与收益 | DECISIONS 11-12 |
| 风险 | **回本时间**,不是最大回撤 | DECISIONS 11-11 |
| 策略选择 | 按「状态 × 2 – 3 个月」打分;要高盈亏比,不要高胜率;不要求全周期存活 | DECISIONS 10-07 / 11-15 |
| ⓪ | 在 2018 / 2022 / 2025-26 这几段崩塌里削掉了多少回撤 | HIGH_DIM §5b-bis |
| 不用的尺 | 「去掉最好 N 笔」只报不判;拿空头单独对「持有 ①」 | DECISIONS 10-20 / 11-12 |
| 证据 | 先登记后计算;发现段 / 留出段;带对照(不带条件的全样本、平移);记试验数 | CLAUDE.md;SETUP_REGISTRY |
