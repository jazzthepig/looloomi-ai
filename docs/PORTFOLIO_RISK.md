## 0. 已经有的,不重写

`src/data/accounting/combine.py`(S-543,策略自选拼组合)已经能:按给定权重把几本账拼起来,算组合收益、
**风险贡献**(wᵢ·cov(rᵢ, r组合)/var)、按层归因(① / ② / ③ / ④)、前向与回放两种口径分开标。
**缺的是四样**,本稿只补这四样,全部建在 combine.py 上。

## 1. 每条腿换成同一个风险单位(海龟的 N)

- 每本账的日收益 → EWMA 60 日波动 σᵢ(年化)。腿的「1 份风险」= 让该腿年化波动等于 1% 净值的名义额。
- 权重不再手给,而是由**风险预算**给:wᵢ = bᵢ / σᵢ(再按相关性修正,见 §2),bᵢ 是这条腿分到的风险份额。
- 按回报层级(CLAUDE.md:① → ② → ③ → ④)给默认预算:① 核心 ≥ 60%;X1V 交易层 ≤ 20%;R 等探索腿合计 ≤ 10%;其余留现金。

## 2. 跨腿相关与总风险

- 滚动 90 日相关矩阵 C、协方差 Σ = D·C·D;组合目标年化波动 σ*(Jazz 定,默认按 S-605 档位:T25 档对应约 25% 回撤上限)。
- 整体缩放 k = σ* / √(wᵀΣw);**k 上限 1.0**(组合层只减不加 —— 加杠杆是 ③ 的事,且 ③ 自己封顶 1.3)。

## 3. 硬上限(3AC 的教训,优先级高于预算)

| 项 | 默认 | 为什么 |
|---|---|---|
| 单一资产**跨腿合计**敞口 | ≤ 净值 35% | BTC 同时出现在 ①、X1V、R 里,各腿各自合规,加起来可能过半 |
| 总名义(多头) | ≤ 1.3 × 净值 | 与 ③ 的定义一致,组合层不再叠杠杆 |
| 单笔仓位相对流动性 | ≤ 该币 30 日日均成交额的 1% | 出得去才算仓位(S-608:做空薄币的尾部) |
| 组合回撤 | 触及档位上限的 80% ⇒ 全部腿按比例降到 k = 0.5,直到回到上限的 50% 以内 | 先活下来;规则化,不靠当时的情绪(Druckenmiller 2000) |

## 4. 按边际贡献评腿(Numerai)

- 每条腿每月算一次:**整本账有它 vs 没它**(其余腿按同一规则重新分预算)的风险调整收益差、最大回撤差。
- 前向口径为准,回放只作语境;不足 90 天前向的腿只报不评。
- 连续两个月边际贡献 < 0 ⇒ 预算减半;连续四个月 ⇒ 降为 0(只留纸面记录)。**不看这条腿单独的夏普**(Quantopian)。

## 5. 输出

- 新表 `portfolio_risk_daily`(d, sleeve, sigma, budget, weight, risk_contrib, marginal, cap_flags)+ 一行组合汇总。
- 执行器的计划(`/internal/executor/plan`)以后从这里读 X1V 这条腿的名义上限,而不是写死 3,000 USDC。
