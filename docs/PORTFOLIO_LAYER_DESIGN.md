# 组合层(SPINE 第 7b 段)—— 灵活组合 T25 用真钱跑起来(设计,待 Jazz 拍板)

*Seth,2026-10-29。来源:10-29 高维复盘 + Jazz 当天「好的」;S-604 / S-605 / 10-16、10-21 的决定。这一页只定结构,代码等拍板。*

## 为什么是这一层

FoF 的本体是**把腿组合起来、守住总回撤**。现在每条腿单独对 ① 打分,没有任何代码在组合它们(SPINE 7b「缺段」)。
同时证据说:纯加密的每一本都在 −50% 回撤上下(2023-07 起 ① −56.8%、BTC −53%),**「攻守都突出」只有跨资产给得了** ——
S-604 的 T25(加密 X1V 30 / 股票 30 / 黄金 20 / 现金 20)在悲观摩擦下中位年化 22.6%、最差 5% 回撤约 −25%。
它 10-16 起只在纸上(`forward_book_nav` 的 `flex_x1v`)。这一层要做的,是让**真钱账户就是这本账**。

## 结构:一张目标表,各执行器只读它

```
研究 / 回放(离线)──► 规则(冻结,S-604 / S-605)
                          │
                          ▼
              portfolio_targets_daily        ← 组合层唯一的输出
   (d, sleeve, target_w, rule, tier, why)    sleeve ∈ crypto_x1v / equity / gold / cash / rv2
                          │
        ┌─────────────────┼──────────────────┐
        ▼                 ▼                  ▼
   HL 执行器(东京)    链上钱包执行器(新)    纸面账本(现有)
   crypto_x1v、rv2     gold、equity、cash    flex_x1v 前向账本照记,作对照
        │                 │
        └──── 每日账户快照(全部场所)──► 锚定(OpenTimestamps,现有 forward_anchor)──► 证据面「真钱」一行
```

- **权重来自规则,不来自判断**:T25 = 30 / 30 / 20 / 20;加密腿内部由 X1V 决定在场与否(不在场 ⇒ 那 30% 是现金)。
  21 个交易日回到目标,或任一腿偏离 > 5 个百分点(先到为准)。
- **升档写死**(S-605):真钱跑满两周、实施缺口有数、没有一次出场晚于收盘后 1 小时 ⇒ 升 T35(40 / 40 / 20 / 0)。
- **R-v2 是独立的凸性腿**,不在 T25 的 100% 里:它的资金 = 永续子账户净值,单票风险 0.5%、组合杠杆 L ∈ [1, 5](10-21)。
  组合层只给它一个**风险预算上限**(占总资本的比例),不管单票。
- **杠杆只在这一层选**(10-21,≤ 5 倍);T25 本身是 0.8 倍毛敞口,不加杠杆。
- **现金腿 = 现金等价物**(10-05):法币储备稳定币或净值型代币化国债;不放基差 / 借贷循环的美元。

我们的量级(几百到几千美元)在这几条腿上都没有容量问题。缺的是**第二个执行器**:一个只持这几种代币的链上钱包,
同样的原则 —— 私钥只在主机、主机自己重算目标、读不到就不动。

## 要 Jazz 拍板的

1. **资本:** T25 真钱从多少开始?现在 HL 上的钱基本只够 R-v2 的最低要求(每票 0.5% 风险、最小名义 $10 ⇒ 永续里 ≈ $550–600)。
2. **R-v2 的风险预算上限**(占总资本的比例)。10-08 的探索仓区间是 5–30%;R-v2 是凸性单票,我建议先按 30% 上限、单票风险不变。
3. **链上那一侧用哪个钱包 / 哪条链**(私钥同样只经你的手)。P2 的调查会给你一张对比表再定。
4. **再平衡:** 21 个交易日 + 5 个百分点偏离带(S-604 回放用的是 21 天);同意就照这个写。
