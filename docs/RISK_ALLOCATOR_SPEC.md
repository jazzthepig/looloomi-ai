# 中心风险分配器 — 规格书 (Seth, 2026-07-27)
*Millennium 模型的核心。层级见 `HIGH_DIM_ONTOLOGY.md` §5b-ter · ⓪层闸门见 `REGIME_OVERRIDE_SPEC.md`*

> **第一性原理:平台的 edge 不在任何单个 pod,而在"如何分配风险、如何砍掉失败者"。**
> 我们已有运作框架(`portfolio.py` 的 meta risk-parity),**缺的是标准** —— 本文补四样:
> 风险预算 · 回撤阶梯 · 相关性上限 · 晋升降级。

## 0. 诚实的现状(不许假装我们是 100-pod 平台)
今天:①层基准未建成、②③⓪层在规格阶段、可交易 sleeve **实际为 0**(R77 已降级为 regime-specific
candidate,R76–R94 全灭)。**所以本规格的 v1 目标不是"优化分配",而是"建立纪律,使得未来每一个
sleeve 从诞生第一天就活在规则里"。** 规则先于规模 —— 这正是 Millennium 与"很多策略"的区别。
§9 明确标注哪些条款**现在生效**、哪些**≥5 个 pod 才启用**。

## 1. 风险预算,不是资本预算(最重要的一条)
**分配的单位是"风险",不是"钱"。** 一个 40% 年化波动的 sleeve 和一个 8% 的,分同样的钱 = 分了 5 倍的风险。
```
risk_budget_i  = 目标组合波动 × 风险份额_i        # 份额之和 = 1
capital_i      = risk_budget_i / vol_i             # 波动越高,给的钱越少
```
- **组合目标波动**:v1 = **年化 15%**(FoF 核心,LP 可承受;非对冲基金式 25%+)。
- **vol_i** 用**滚动 90 日已实现波动**,PIT,不许用全样本。
- 新 sleeve 无实测波动 ⇒ 用回测波动 **×1.3 保守系数**(回测总是低估真实波动)。

## 2. 风险份额的确定(三个因子,可审计)
```
风险份额_i ∝ conviction_i × capacity_i × diversification_i
```
| 因子 | 定义 | 取值 |
|---|---|---|
| **conviction** | 证据等级 | paper<60d: 0.25 · OOS通过+60d paper: 0.5 · 多周期+事件计数通过: 1.0 |
| **capacity** | 容量约束 | min(1, 声明容量 / 该份额所需资金) —— 装不下就自动降份额 |
| **diversification** | 与现有组合的正交度 | 1 − max(|corr| 与已配置 pod) ,corr>0.7 ⇒ 因子 <0.3 |
**禁止人工覆盖。** 任何调整必须改上述输入(且留痕),不许直接改份额 —— 这是防"我觉得这个会涨"的闸。

## 2b. ⚠️ 波动率目标是第一道风控,止损只是尾部保险(S-91 实测修订,2026-07-27)

**实测颠覆了本规格原先的假设:只靠回撤阶梯,回撤会"阶梯式累积"** —— 每次触发后高水位重置,
下一轮从新低点再算,0.85ⁿ 复利叠成 −54%(23 次触发/339 天)。**单次被限制,次数没有被限制。**
而且:**收紧止损(−15%→−10%)使回撤更糟(−60.1%)**,因为触发更频繁、每次都在低点减仓。

**正解是事前的波动率目标(vol targeting),不是更严的事后止损:**
```
exposure_t = min(cap, target_vol / realized_vol_30d)     # PIT,30日已实现波动
```
| 配置 | Sharpe | maxDD | 正年 |
|---|---|---|---|
| 仅阶梯(原规格) | 0.79 | −53.9% | 8/9 |
| **+ vol target 25%** | **1.01** | **−23.8%** | **8/9** |
| + vol target 25% × 2.0x 杠杆 | 0.87 | −39.1% | 8/9 |

**⇒ 风控的正确顺序:① 波动率目标定基座(事前)→ ② 回撤阶梯做尾部保险(事后)→ ③ 杠杆放大。**
**目标波动实测 25% 优于本规格原写的 15%**(15% 会过度降杠杆,牺牲过多收益)——
§1 的"组合目标波动 15%"据此修订为 **25%(加密资产类;传统资产另议)**。
**杠杆必须加在优化后的基座上** —— S-87 曾测出"杠杆全程不提 Sharpe",根因是当时基座 Sharpe 仅 0.79;
基座做到 1.01 后,2.0x 杠杆给出"收益追平裸持有、回撤仅其一半"的形态。

**⚠️ 本规格 §3 的"组合层熔断 −20%/−25%"条款需修订:** 实测按 ATH 计的硬熔断**不带恢复机制会永久锁死**
(总收益 +2%)。修订为:熔断后进入观察期,连续 N 日站上恢复线则解除,且解除时重置高水位。

## 3. 回撤阶梯(机械执行,无自由裁量)—— Millennium 的牙齿
| pod 自身回撤(自其历史高点) | 动作 |
|---|---|
| **−8%** | 风险份额 **×0.5**,进入观察 |
| **−12%** | 风险份额 **×0.25** |
| **−15%** | **归零**,停止交易,进入 30 日冷冻 |
| 冷冻期满 | 需**重新走晋升阶梯**(§5),不自动恢复 |
- **触发即执行,当日生效**;不许"再等等看"。
- **回撤按 pod 自身 NAV 计**,不按组合。
- **回测必须带着这条阶梯跑**(事后加止损会改变曲线形状 —— 那是自欺)。
- **组合层熔断**:组合回撤 −20% ⇒ 所有 pod 份额减半,并强制复盘;−25% ⇒ 全部归零,只留①层。

## 4. 相关性 / 拥挤度上限
- **任意两个 pod 的 90 日滚动相关 > 0.7** ⇒ 合并视为一个 pod,共享一份风险预算(取 conviction 高者主导)。
  依据:`redundancy()` 已证 `risk_direction_score` 是枢纽 —— 我们**以为**有的分散度往往不存在。
- **单一 pod 风险份额上限 40%**;**单一资产在组合层的合计暴露上限 25%**(穿透所有 pod 计算)。
- **有效 pod 数(ENB)< 2 时,不许把总暴露开到 1.0x 以上** —— 分散度不够就不许放大。

## 5. 晋升 / 降级阶梯(资本如何流动)
```
研究通过 → paper(60d,0 资金) → 试点(风险份额 ≤10%) → 标准(≤25%) → 核心(≤40%)
```
| 关口 | 条件(全部满足) |
|---|---|
| → paper | pre-declared 标准齐全(cause/OOS/止损规则)、CI discipline 通过 |
| → 试点 | 60 日 paper 完成 · 前向表现与回测偏差 <30% · 无止损触发 |
| → 标准 | 90 日试点 · Sharpe ≥ 回测的 50% · maxDD ≤ 预期 1.5× |
| → 核心 | 180 日 · 跨 ≥2 个 regime 相位 · 容量已用 fill-attribution 验证 |
**降级永远比晋升快:** 任何一关的条件失守 ⇒ **立即退回上一级**(不是"再观察一个月")。
**这是 Millennium 与学院派的分水岭:进场慢,退场快。**

## 6. 与 ⓪层的交互(谁说了算)
```
最终暴露_i = 风险份额_i × capital_i × exposure_cap(⓪层)
```
- **⓪层是乘性闸门,凌驾一切**:ⓠ=CRISIS ⇒ 所有 pod 暴露 ×0(或按裸空规格反向),
  **无论该 pod 自身表现多好**。躲开系统性风险优先于任何单 pod 的 alpha。
- 反之ⓠ=EXPANSION 也**不自动放大** —— 放大仍受 §4 的 ENB 约束(分散度不够不许加杠杆)。

## 7. 再分配节奏
- **常规:月度**(与①层再平衡同日),避免换手噪声。
- **例外立即执行:** 回撤阶梯触发 · ⓠ层相位切换 · 相关性突破 0.7 · 容量违约。
- 每次再分配产出一条**审计记录**(前后份额、触发原因、输入因子值)—— 落 `risk_allocations` 表。

## 8. 永久淘汰(进坟场)
满足任一:① 冷冻后重启再次触及 −15%;② 发现 PIT/look-ahead 缺陷(binary kill,I4);
③ 容量被证伪(实际 fill < 声明 50%);④ 连续 2 个 regime 相位跑输①层基准。
**淘汰记入 `REFUTATION_LEDGER` 并保留向量坐标**(坟场是资产 —— 它标记了不该再去的区域)。

## 10. 边界
分配器不产生 alpha、不选券、不择时 —— **它只决定"给谁多少风险、什么时候拿走"。**
它的成功指标不是收益,而是:**没有任何一个 pod 能造成超过预算的伤害。**
