## 4. ② 规则 A / B:换仓频率 + 随机门控对照(CHANGES ②)

### 4.1 三个换仓频率(24 名主口径 / 16 名连续面板对照)

| 规则 | 24 名主口径:毛 / 净 / 开关数 / 年化净 | 16 名面板:毛 / 净 / 开关数 / 年化净 |
|---|---|---|
| A 常开 | 19.726 % / **19.576 %** / 2 / 5.108 % | 19.992 % / 19.842 % / 2 / 5.177 % |
| B 日换仓 | 22.419 % / **17.019 %** / 72 / 4.440 % | 22.500 % / 17.400 % / 68 / 4.540 % |
| B 周换仓 | 21.274 % / **18.274 %** / 40 / 4.768 % | 21.899 % / 19.349 % / 34 / 5.048 % |
| B 月换仓 | 20.451 % / **19.401 %** / 14 / 5.062 % | 20.636 % / 19.736 % / 12 / 5.149 % |

门控信号 = 过去 7 日 funding 均值 > 0,**滞后 1 日**(不看当天);周换仓 = 每个 ISO 周第一个有数据日重算,
月换仓 = 每个自然月第一个有数据日重算,两次调仓之间保持上一次信号。

**读法**:门控的**毛**收益确实高于常开(+2.7 pp,日换仓),但费用按开关次数吃:
日换仓 72 次 × 7.5 bp = 5.4 %,净收益反而低于常开 2.6 pp。
**换成周 / 月换仓后费用降到 3.0 % / 1.05 %,净值就高于常开**(B 月 19.401 % vs A 19.576 %,
基本持平;B 周 18.274 % 仍低 1.3 pp)。
⇒ **「按日换仓不值」;换成周 / 月换仓,门控的毛优势才留得下来。**

### 4.3 随机门控对照(同开关次数 + 同开仓天数 ⇒ 费用完全相同)

## 5. ④ 「是不是伪装的 β」:过去 30 日 vs 未来 30 日(CHANGES ①)

### 5.1 过去 30 日窗口(**只作对照,不回答这个问题**)

24 名主口径,1400 天中可用 1370 天(与未来窗口对齐的那部分):负费率日 BTC **过去** 30 日 = **−3.302 %**,
正费率日 = **+7.402 %**,全样本 +4.412 %;P(BTC 过去 30 日为负 | 负费率日) = 61.6 %,而 | 正费率日 = 33.3 %。
块置换零分布 p = 0.0000(v1 的同一统计量)。

**这只说明「资金费符号 ≈ 过去趋势」**(涨过之后费率才高),**不能**回答「这个 sleeve 是不是伪装的 β」——
套息赚的是**未来的**费率,它承担的是**未来的**风险。

### 5.2 未来 30 日窗口(**结论只按这一段写**)

`btc_fwd30[d] = close[d+30] / close[d] − 1`(日历日)。可用 1370 天(2023-01-01 → **2026-10-01**,
末尾 30 天因没有未来价格而不可用,已剔除)。

| 统计量 | 值 |
|---|---|
| 负费率日(387 天)BTC 未来 30 日均值 | **+3.044 %** |
| 正费率日(983 天)BTC 未来 30 日均值 | **+4.503 %** |
| 全样本 | +4.091 % |
| P(BTC 未来 30 日为负 \| 负费率日) | **40.6 %**(157/387) |
| P(BTC 未来 30 日为负 \| 正费率日) | **42.0 %**(413/983) |
| 块置换零分布(块长 **30**,1,000 次,种子 222) | 负费率日均值 **p = 0.279**(零分布 95 % 区间 [0.855 %, 7.260 %]) |

**读法**:未来窗口里,负费率日之后的 BTC 反而**略高**(+3.04 % vs +4.50 %),符号与「负费率 ⇒ 未来要跌」相反,
且**统计上不显著**(p = 0.279)。也就是说:
1. **「负费率日 ⇒ 未来下跌」不成立** —— 负费率日的 BTC 未来 30 日**上涨**的天数占 59.4 %。
2. **「大部分是 β」这句话撤掉**(v1 的措辞来自过去窗口)。未来窗口既没有支持「它是 β」,也没有支持「它是 α」——
   它说的是:**费率符号对 BTC 的未来方向没有可测的信息**。

**这是本轮最重要的一处口径分歧,需要 @seth 定**(我不自己定):
- **同期口径**(S-707 (c) 字面写的「BTC 月收益」):ρ = 0.368 > 0.3 且 p = 0.012 < 0.05 ⇒
  **两个条件都不满足** ⇒ 按字面,月度套息收益与 BTC 当月回报有**可测的正相关**,像是穿在 β 里的东西。
- **未来窗口口径**(§Seth-1102f 要求的「结论只按未来窗口写」):ρ = 0.033 ≤ 0.3 且 p = 0.834 > 0.05 ⇒
  **两个条件都满足** ⇒ 套息的月度收益**不**跟着 BTC 的**未来**走。
- 两者的差额恰好说明机制:费率**高**的月份 = BTC **当月**涨过的月份(ρ_同期 = 0.37,与过去 30 日 ρ = 0.371 几乎相同),
  但费率**不预测** BTC 的**未来**(ρ_未来 = 0.033)。
  **所以它不是「伪装成套利的 β」,而是「滞后的 β」**——套息拿到的是**过去的**波动补偿。
  这个区别很重要:滞后的 β 是**已经赚到**的(它已在净值里),但**不可外推**(未来不再付你)。
