## 3. 复算脚本怎么写的(`docs/research/t301_recompute.py`)

- **事件**:直接 import 自己的 `docs/research/t297_clean.py`(S-777 交付),调 `detect(pan, uni_mask, off=0, guards=True)` —— 即 S-777 干净口径(f7 为空 / ATR14 ≤ 0 / qv20 ≤ 0 不是事件)。面板用今天重拉的数据。逐 `(kind, symbol, d)` 与 `crowding_watch` 的 410 行 backfill 对账,报两边独有条数 + 前 20 条 + 全量清单(落 `t301_events.csv`)。
- **前向(S-726 口径)**:日历口径 `d+1 开盘 → d+30 收盘`,进场那天没开盘价 ⇒ 不算(报个数);出场 = 窗口内最后一个收盘;未到期(d+30 > 数据末日)不计。篮子 = 内核 `uni` 在同一进出窗口的时点等权。**全向量化**:入口价 = 全局日期轴上 `d+1` 的开盘矩阵;出场价 = 收盘矩阵的反向填充(窗口内最后一个收盘);超额 = 代币收益 − 同日篮子均值。同时把**副口径**也算了:只用 `kind='coin'` 且已上市 ≥ 30 天的篮子(参考实现 `forward()` 的篮子口径),以及参考实现自带的 **bar 口径**(bar j+1 开盘 → bar j+30 收盘)作交叉对照。
- **自检**:逐事件把算出来的 `x30` 与库内**已存的** `x30` 比(报 max|diff| 与逐条相等的条数)—— 这一步同时验「前向口径」和「篮子宇宙」。
- **零分布**:同币同年随机日,每抽每个事件独立取一个随机日;`n=1000`、`seed=783`;零分布与分位**只用** `src/data/evaluation/apparatus.py` 的 `null_distribution` / `percentile_of`(不用自己写的);报中位的分位与均值的分位(两个都要,S-781 的判据里均值分位是 0.056)。
- **两半**:事件日 ≤ 2022-12-31 / ≥ 2023-01-01。
