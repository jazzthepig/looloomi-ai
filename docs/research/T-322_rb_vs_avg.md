**对照臂 AVG_w 的口径:** 先跑 RB 臂拿到核的调仓日志(每次调仓的目标权重),取三腿权重的算术平均 → 一个常数权重向量;再用**同一个** `dynamic_mix_nav`、同一 reb / 成本 / 起止日跑一遍常数臂(现金 = 1 − Σ权重)。
AVG_w 的权重来自核日志(核内 `round` 到 4 位):W1 = 加密 0.2616 / 股 0.3123 / 金 0.2941 / 现金 0.1320(15 次调仓的平均);W2 = 加密 0.2777 / 股 0.3546 / 金 0.2543 / 现金 0.1135(34 次的平均)。
⇒ AVG_w 与 T25_K 一样是**每 21 天调回常数目标**(不是买入持有),三臂记账完全同口径,差别只在目标权重是否随时间变。

## 4. 判据与结论

**预注册的判(逐条):**

| 窗口 | RB 总收益 ≥ AVG_w? | RB 最大回撤 ≥ AVG_w? | 该窗口 |
|---|---|---|---|
| W1 | −9.90% ≥ −13.91% ✅(差 +4.01pp) | −19.47% ≥ −25.01% ✅(浅 5.54pp) | ✅ 过 |
| W2 | +65.03% ≥ +62.13% ✅(差 +2.90pp) | −9.49% ≥ −9.76% ✅(浅 0.27pp) | ✅ 过 |

**⇒ 两个窗口都过:时变部分有用(✅),形式上「摆给 Jazz 的仍是 RB」。**

但要摆清楚的是**幅度与归因**(这是本卡真正回答的问题):RB 相对常数 T25_K 的增益,有多少是「常数配比」、多少是「时变」?

| 窗口 | 量 | RB − T25_K | 其中常数部分(AVG_w − T25_K) | 其中时变部分(RB − AVG_w) | 时变占比 |
|---|---|---|---|---|---|
| W1 | 总收益 | +5.80pp | +1.79pp | **+4.01pp** | 69% |
| W1 | 最大回撤(浅为正) | +6.44pp | +0.90pp | **+5.54pp** | 86% |
| W2 | 总收益 | +11.25pp | +8.35pp | **+2.90pp** | 26% |
| W2 | 最大回撤(浅为正) | **−0.63pp** | −0.90pp | **+0.27pp** | — |

读法:
- **崩盘段(W1):时变部分是真东西。** 少亏的 86% 来自时变(5.54pp),常数配比只解释 0.90pp;ab p(RB ≤ AVG_w) = 0.0865(单侧,勉强在 0.10 之下,但该样本量 underpowered)。
- **平常段(W2):时变部分几乎分不出来。** 收益差 2.90pp、p = 0.394;回撤差 0.27pp(0.3pp 级别);而且 **RB 在这一段的最大回撤(−9.49%)比常数 T25_K(−8.86%)还深 0.63pp** —— RB 在 2024–26 没有把回撤做浅。
- **最稳的一块反而是「常数配比」本身**:AVG_w 在两个窗口都优于 T25_K,W2 里 p = 0.0275(verdict "B > A")。但这是**带未来信息**的常数配比(权重是整段窗口 RB 权重的平均,含窗口后段的 hindsight),不能直接当可实施的建议 —— 见 §5。

**对 C 道自己提的第 ① 条(「少亏里有多少只是常数地少放加密、多放黄金」)的直接回答:**
- W1 的收益增益:31% 来自常数配比、69% 来自时变;回撤增益:14% 来自常数配比、86% 来自时变。
- W2 的收益增益:74% 来自常数配比、26% 来自时变;回撤:RB 相对常数 T25_K 反而深 0.63pp。
⇒ 「RB 的好处主要是换了配比」在 W2 成立、在 W1 不成立;「RB 的好处主要是择时」在 W1 成立、在 W2 不成立。**两者都不是全貌:RB 的价值集中在崩盘段的风险闸门,收益端不必依赖它。**

## 5. 必须随结论一起说的三条限制

1. **AVG_w 是 in-sample 的。** 它的常数权重来自整段窗口 RB 调仓权重的平均(用了窗口后段的信息),因此「AVG_w 优于 T25_K」不能读成「把 T25 换成 AVG_w 这个常数配比更好」。要做「换一个常数配比」这条路,必须另立预注册,用滚动/扩展窗口(只用 ≤ t 的 RB 权重均值)估计常数权重,并在新数据上做零信号对照。**本卡没有做这件事,也不宣称它成立。**
2. **本卡的两条对照臂在 W2 里互相之间差异极小**(2.90pp / 0.27pp),而 709 天的 MDE 是 19.4pp(总收益 log 差)—— 换句话说,**本卡没有能力在 W2 里把 RB 与它的常数平均分开**;W1 也只能勉强(p=0.0865,underpowered)。判据形式上过了,但证据强度远弱于 T-321 的 (a)(b)(c)(三条全过、p=0.073)。
3. **RB 的尾部权重是它自己的结构风险,AVG_w 天然没有。** RB 的加密权重: W1 中位 23.5% / 最大 **63.3%**(2022-07-13),W2 中位 20.2% / 最大 **65.5%**(2025-05-08);2026-02-09 起连续 6 次调仓把加密放在 43.8%–63.3%(正好覆盖 RB 在 W2 的最大回撤峰 2026-01-28 → 谷 2026-03-30)。这与 S-799 指出的第 ② 条(SIGMA_FLOOR 让 X1V 空仓的加密腿看起来低风险)是同一个机理。**RB 的常数平均(加密 26.2% / 27.8%)与 DECISIONS 11-01 的策略层 30% 上限不冲突;RB 的尾部会冲突。** 这是「常数配比」在风控上的真实优势,不能只当收益问题看。

## 6. 探索性发现(不在本卡判定里;需另立预注册、在新数据上过零信号对照)

1. **W2 里 RB 的回撤比常数 T25_K 深 0.63pp,且深度集中在 2026-02 → 08 的连续高加密权重段** —— 说明「风险预算」在低波动/空仓期反而放大风险敞口。若要提给 Jazz,应把它作为「接进真钱之前必须改的地方」(与 S-799 第 ② 条同列)。
2. **RB 相对「自身平均配比」的优势几乎全部来自崩盘段**(W1:收益 +4.01pp / 回撤 +5.54pp;W2:+2.90pp / +0.27pp)。若只能取一个数作为真钱门槛,应按「崩盘段少亏」而不是「平常段多赚」来谈。
3. **AVG_w 在 W2 的 ab_test 显著(p=0.0275),而 RB 相对 AVG_w 不显著(p=0.394)** —— 这与 §5.1 一致(AVG_w 带未来信息),但提示「常数配比」这条路的**幅度**可能比 RB 的时变部分更大;值得用滚动窗口版本另立预注册验证。
4. **两个窗口里 RB 的黄金权重几乎顶在上限**(W1 中位 = 上限 30%)—— 所谓「RB 的少亏」有一半是「黄金配比被顶满」的效果,与波动倒数本身的择时混在一起;把黄金单独当成一条腿看会更干净。
