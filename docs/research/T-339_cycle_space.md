## S-814 原文(照抄)

> ## S-814 — 回到高维:**周期位置空间** —— 把 MVRV / Puell / 算力 / 离 200 日线 / 365 天收益 / 距高点回撤 / 波动 / 恐惧贪婪放进一个向量空间,用「历史上最像今天的日子之后 180 天怎么走」代替阈值,能不能给出配置级的 add / trim —— 预注册(Seth,2026-11-11 04:51 UTC;Jazz 11-11「we have built the system with vector database and strategies with decision and loop engineering together, we should keep in high dimension to work things out」;内核 `src/data/state/cycle_space.py` 已写好、单测过,**没在任何真实序列上跑过**;交 A 道 T-339 用内核算、C 道 T-340 只读本条原文盲复算)
> **为什么。** 见上:阈值规则七年 1 个过热样本。向量空间给每一天一个分级的相似度,2011 年起四轮周期的每一天都参与;决定进回路(每周三条 180 天情景进 `scenario_ledger`,到期 Brier 结算 —— 已接线,不等判定)。
> **空间(写死;= 内核的常量,盲复算只读这一段):** 数据 `macro_daily`:btc_price_usd、btc_mvrv、btc_puell、btc_hash_30d(Coin Metrics,2011 起)、fng(2018-02 起)。8 维,d 当天只用 ≤ d:mvrv = ln(MVRV);puell = ln(Puell);hash_30d(原值);dist_200 = ln(价 ÷ 最近 200 个连续日均价);ret_365 = ln(价 ÷ 365 天前的价);dd_ath = 价 ÷ 截至当天最高价 − 1;vol_90 = 最近 90 个日对数收益的总体标准差;fng_30 = 最近 30 天恐惧贪婪均值(≥ 20 个观测;没有 ⇒ 这一维不存在)。**标准化:** 每一维用严格更早的值算均值 / 样本标准差(该维 ≥ 730 个观测才出 z),截到 ±6。**距离:** 两天都有值的维上的欧氏距离 × √(8 ÷ 共有维数);共有维 < 5 不比。**近邻:** 候选 = 日期 ≤ t − 181 天的所有日子,取最近 **K = 60**。**结果:** fwd = 价(s + 180 天)÷ 价(s)− 1;down = fwd ≤ −20%,up = fwd ≥ +25%。**独立段数:** 近邻日期排序后与上一个相差 ≥ 90 天才算新段。**收缩:** p = w · 近邻频率 +(1 − w)· 无条件频率,w = 段数 ÷(段数 + 3);无条件 = 所有日期 ≤ t − 181 天的日子的频率。**倾斜:** tilt_excess =(p_up − p_down)−(无条件 up − 无条件 down)。**表态:** 段数 ≥ 3 且 tilt_excess ≥ +0.25 ⇒ add(现货 1.0);≤ −0.25 ⇒ trim(0.35);否则 hold(0.70)。
> **检验(走步,只调生产函数):** 每个周一 t,从第一个能出读数的周一起,到最后一个 180 天结果已知的周一。
> **判据(全过才 ✅):** (a) 周度 Spearman(tilt_excess, 实现 fwd180)≥ **0.20**,且把实现序列整体循环平移(`apparatus.circular_shift`,块长 26 周,1,000 次,种子 814)的 `p_upper` ≤ 0.05;(b) 三档 Brier(收缩后的 p)< 无条件频率的 Brier,配对块自助(块长 26 周,2,000 次,种子 814)差的 95% 上沿 < 0;(c) **配置:** 周一收盘定权重、次日收盘生效、10bp × 换手、现金 0 —— 对 HOLD70:总收益 ≥ HOLD70 **且** 最大回撤浅 ≥ 5pp,且 Calmar 对「权重日程整体循环平移」零分布(1,000 次)`p_upper` ≤ 0.10;(d) **四轮周期的极端:** 顶 = 每个减半纪元(2012-11-28 / 2016-07-09 / 2020-05-11 / 2024-04-20 起)里的最高收盘日,底 = 每个顶之后到下一个顶之前的最低收盘日;顶 ±30 天内**没有** add、底 ±30 天内**没有** trim,且至少 2 个顶附近出现过 trim、至少 2 个底附近出现过 add;(e) 两半(按周数)Spearman 同号。
> **另报(不判):** 单维基线 —— 只用 MVRV 的扩张分位、只用 dist_200,同一个 Spearman(空间比一个指标多给多少);add / trim / hold 的周数占比与每年换仓次数(Jazz 要低频);独立 180 天区间数(检出力);K = 30 / 120。
> **后果:** 全过 ⇒ 提给 Jazz:周期读数作配置级输入(T25 加密带 20–40% 里的位置、以及 S-812 双向动作改由它触发),我不代拍;不过 ⇒ 空间留作描述臂 + 记分账,极端时点的判断仍走 Jazz 的 ⓪ 开关。

## 结果之外看到的(探索性 —— 需另立预注册、在新数据上过零信号对照)

1. **阈值 0.25 加上「段数 ≥ 3」把空间压成了 84.9% 的 hold**;真正的动作只发生在 101 次换仓里,而这些换仓在 (d) 的四个极值点方向全反 ⇒ 更像是**样本内的噪声**(24 个独立区间),不是「空间不够聪明」。
2. **空间不如单指标**:dist_200 单指标 ρ=+0.2150 > 8 维空间 ρ=+0.0389。若要保留高维,下一轮该问的是「空间是否**加**了什么」,而不是「空间本身有多少」—— 这需要重新预注册(否则就是挑数据)。
3. **生产读面当时是死的**(macro_daily 缺 3 条序列 ⇒ `load()` 抛错):这是本轮最硬的工程发现,与统计结论无关,但会影响 `run_once` 每周写情景 —— 入库补齐前,情景账其实是空的。
4. HOLD70 在 2014–2026 只有 +4144%(年化 34%)、回撤 −69.8%:日频 70% 仓位在大涨日占优(凸性),比「BTC 涨 89 倍 × 0.7」低很多 —— 任何拿「持有面板 × 仓位」当基准的比较都要先说清是日频复利还是期末比例。
