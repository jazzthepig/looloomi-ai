## 一、预注册(S-771 原文,照抄,只算一次)

**因。** 同一个币在韩国比海外贵 = 韩国散户的买盘超过了套利能搬过去的量(韩国资本管制让溢价能持续);溢价是「疯狂」的价格,不是新闻。份额是同一件事的量的一面。S-737 用的是**全市场**韩国份额(方向反、不过),这里是**按币、扣掉 BTC 自己的溢价**。

**写死:** 每周一,代号 i:P_i = ln(KRW 收盘_i / 全球美元收盘_i) − ln(KRW 收盘_BTC / 全球美元收盘_BTC)(全球价 = Binance 现货 `ohlcv_daily` binance_hist 收盘,没有则 `asset_mcap_daily`;过去 7 天中位);S_i = Upbit KRW 成交额 / (全球成交额 × USDKRW)(过去 7 天和;USDKRW 用 Upbit KRW-USDT 收盘,上市之前的周不算 S)。截面:当周两边都有价、Binance 现货在、市值 ≥ 2,000 万。目标 = 之后 4 周相对 BTC 的超额。

**判(P、S 各自,BH 两条):** IC 均值 < 0 且 NW t ≤ −2;最高五分位 − 最低五分位 < 0;周内打乱 1,000 次分位 ≤ 0.05;2021–2023 / 2024–2026 两段同号 ⇒ ✅。**诚实:** Upbit 下架的市场取不到(幸存者)⇒ 「溢价高之后跑输」会被**低估**(保守);最低五分位(韩国折价 = 韩国散户在割肉)单独报,那一头的幸存者偏差方向相反、不保守,只报不判。**试验计数:对手盘族 +4。**

### 附加判据(按金额)——Jazz 11-07 规则,本卡照做

S-771 原文的「最高五分位 − 最低五分位 < 0」按 **Jazz 11-07 的「按金额」规则**执行(T-299 的教训:秩 IC 是正的,
可肥尾让按金额算的多空价差是负的):

- **按金额** = 五分位内的收益按**信号日市值加权**(市值大的币说话算数,单币暴涨不翻转结论);
- 五分位差 = Q5(信号最高) − Q1(信号最低)的**市值加权**四周相对 BTC 超额;
- **扣真实成本**:一轮往返 20 bps(单边 10 bps 现货 taker),每周一建仓、持有 4 周;
- **块自助**(平稳块自助,平均块长 4 周 = 目标重叠长度,2,000 次,种子 771)给单侧分位;
- 判:**净成本后 < 0 且分位 ≤ 0.05**。
- 同时只报:等数量(每档等权)口径的同一价差,以及多头倾斜形态(Q1 相对面板等权)。

## 五、两处实现缺陷与修正(必须写在结论旁边)

上一轮(48d335ba)写好的分析脚本里有两个**实现**缺陷,本轮修掉。**判据定义一个字未改**,只修实现;
两处都会让结论偏保守(P 会被判 ❌),所以这是修 bug,不是事后放宽口径。

1. **周内打乱的切片偏移算错**:`shuffle_null` 里 `slices.append((len(packed_v), …))` 用的是「已装的**周**数」当元素偏移,
   切片整体错位 ⇒ 打乱零分布不是「当周内打乱」。修后 P 的打乱分位 **0.287 → 0.001**、S **0.117 → 0.000**。
2. **块自助把「实际值在自身自助分布里的分位」当 p**:那条零分布是**原始序列**的自助分布,中心就在实际均值上,
   分位恒 ≈ 0.5(本卡旧口径实测 **0.501 / 0.493**)—— 退化量,不是检验,会让第 ② 条对**任何**信号都判 ❌。
   按台账 S-690 族的约定(「p = 抽样差 ≥ 0 的比例」)改成尾概率后:P 净 **0.0155**、S 净 **0.021**。
   旧口径的数字仍保留在 `t292_results.json` 的 `degenerate_pct_of_actual` 字段里备查。

## 六、诚实与边界

- **幸存者**:Upbit 下架的市场取不到 ⇒ 「溢价高之后跑输」这一侧被**低估**(保守);最低五分位那一头方向相反(不保守),只报不判。
- **覆盖**:映射命中率 28.3%(Binance)/ 51.7%(市值)—— 截面是「能配上的」那批,不是全部 300 个 KRW 市场;
  每周实际 56–70 个币。
- **S 的样本只有 2024-06 起**(USDKRW 代理的硬约束),单半样本 ⇒ 判据④对它不是「不过」而是「不可判」;
  S 的所有数字(尤其 IC −0.094)都只描述 2024–2026 这一段行情。
- **口径变动**:入场用 t+1 收盘(S-774 用 t+1 开盘);S 的分母用窗口内 USDKRW 中位;全球价只用了 Binance 一处
  (`asset_mcap_daily` 备用分支未触发,因为截面本来就要求 Binance 现货在)。这些在结果出来前定死,不改。
- **「按金额」判据的方向**:本卡假设方向是负的(溢价高 → 之后跑输),所以判据写成「净成本后 < 0 且分位 ≤ 0.05」,
  与 T-299 的「> 0」是同一条规则的镜像。
- **P 的 ✅ 的力度分布**:IC 两段都在(−0.0388 / −0.0151),但**金额**价差的统计力集中在 2024–2026(h2 t −2.06;h1 t −0.60)。
  ⇒ ✅ 是「IC 判据全段 + 金额判据全样本」撑起来的,不是 h1 的金额效应撑起来的。
- **情景文件**:上一轮写的 4 条是**结果之前**的先验(README 规定写下不能改,照常结算);本轮**另加**新 id 记录
  看过结果后的看法(T-292-5/6/7),不覆盖旧条目。

## 七、结果里还看到了什么(探索性 —— 需另立预注册、在新数据上过零信号对照才算)

① **市值本身有排序力**:市值秩与目标的 IC **+0.0512**(NW t +2.33)⇒ 小市值在这段样本里跑输。
   **控制市值秩后**,P 的偏相关 IC 仍有 **−0.0240**(NW t −2.42)⇒ **P 不是「小市值的代理」**;
   而 S 的偏相关 IC 只剩 **−0.0328**(NW t −1.19)⇒ **S 的强度有相当一部分是市值代理**。
② **S 的效应集中在中小市值**:等数量口径 −4.335%(t −4.24)远强于金额加权 −2.616%(t −1.69)。
   ⇒ S 在金额口径下被大盘币稀释,这也解释了它为什么只差判据④(而②③都过)。
③ **「按金额」规则确实在做事**:P 的 IC 口径与金额口径方向一致(−0.0273 vs −1.979%),但金额口径对**单币肥尾**更钝 ——
   CHZ 2021-02 就是「韩国溢价极高 → 之后暴涨 14 倍」的反例(单币、单月)。
④ **韩国折价那一头不是反向信号**:P 的最低五分位 +0.401%(t +0.25)、S 的 −0.405%(t −1.07)⇒ 预注册写「只报不判」是对的。
⑤ **P 的溢价是有结构的**:若要另立预注册,值得测的方向是「溢价高 = 上线新市场 + 换手异常」的组合,
   而不是单看溢价水平(本卡没做,不做「看完结果再挑因子」)。
