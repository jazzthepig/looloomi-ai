## 一、预注册(S-771 原文,照抄,只算一次)

**因。** 同一个币在韩国比海外贵 = 韩国散户的买盘超过了套利能搬过去的量(韩国资本管制让溢价能持续);溢价是「疯狂」的价格,不是新闻。份额是同一件事的量的一面。S-737 用的是**全市场**韩国份额(方向反、不过),这里是**按币、扣掉 BTC 自己的溢价**。

**写死:** 每周一,代号 i:P_i = ln(KRW 收盘_i / 全球美元收盘_i) − ln(KRW 收盘_BTC / 全球美元收盘_BTC)(全球价 = Binance 现货 `ohlcv_daily` binance_hist 收盘,没有则 `asset_mcap_daily`;过去 7 天中位);S_i = Upbit KRW 成交额 / (全球成交额 × USDKRW)(过去 7 天和;USDKRW 用 Upbit KRW-USDT 收盘,上市之前的周不算 S)。截面:当周两边都有价、Binance 现货在、市值 ≥ 2,000 万。目标 = 之后 4 周相对 BTC 的超额。

**判(P、S 各自,BH 两条):** IC 均值 < 0 且 NW t ≤ −2;最高五分位 − 最低五分位 < 0;周内打乱 1,000 次分位 ≤ 0.05;2021–2023 / 2024–2026 两段同号 ⇒ ✅。**诚实:** Upbit 下架的市场取不到(幸存者)⇒ 「溢价高之后跑输」会被**低估**(保守);最低五分位(韩国折价 = 韩国散户在割肉)单独报,那一头的幸存者偏差方向相反、不保守,只报不判。**试验计数:对手盘族 +4。**

### 附加判据(按金额)——Jazz 11-07 规则,本卡照做

S-771 原文的「最高五分位 − 最低五分位 < 0」按 **Jazz 11-07 的「按金额」规则**执行(T-299 的教训:秩 IC 是正的,
可肥尾让按金额算的多空价差是负的):

- **按金额** = 五分位内的收益按**信号日市值加权**(市值大的币说话算数,单币暴涨不翻转结论);
- 五分位差 = Q5(信号最高) − Q1(信号最低)的**市值加权**四周相对 BTC 超额;
- **扣真实成本**:一轮往返 20 bps(单边 10 bps 现货 taker),每周一建仓、持有 4 周;
- **块自助**(平稳块自助,平均块长 4 周 = 目标重叠长度,2,000 次,种子 771)给单侧分位;
- 判:**净成本后 < 0 且分位 ≤ 0.05**。
- 同时只报:等数量(每档等权)口径的同一价差,以及多头倾斜形态(Q1 相对面板等权)。

| 项 | 取值 | 与预注册的关系 |

| 信号日 | 每周一,2021-01-04 起 | 照抄 |
