## 4. 「90 vs 88」对齐(两个不同的量,差 2 天)

M-220 §0.3 写 `1−90/335 = 0.731343`「正是 lane-c 报的 avg_cash」;lane-b 10-30 的探针输出 **88**。✅ 本轮实测(OOS = 60/40,836 天窗口,末 335 天):

| 量 | 值 |
|---|---|
| OOS 天数 | 335 |
| OOS 里 **phase==CASH** | **245** |
| OOS 里 **phase≠CASH** | **90** |
| OOS 里 regime∈{RISK_OFF, STAGFLATION}(V5) | 187(其中与 phase=CASH 重叠 185) |
| OOS 里 **live**(非风控 ∧ phase≠CASH) | **88** |
| 差的那 2 天 | **2026-06-06、2026-06-07**,两天 V5 regime = **STAGFLATION**、phase≠CASH |

⇒ **90 = OOS 里 phase≠CASH 的天数;88 = 这 90 天里 regime 不是风控的天数。差的 2 天就是上表那两天。** 两个数不是同一个量,不需要「对齐」—— 但两者合起来把 avg_cash 钉死:

- `245/335 = 0.7313432835820896` ← **实测 avg_cash,逐位相等**
- `1 − 90/335 = 0.7313432835820896` ← M-220 的写法,**与上式恒等**(335−90 = 245)
- `187/335 = 0.5582089552238806` ← 「风控天占比」口径,**不等于** 实测 avg_cash

**⇒ 修正 M-220 §0.3 的归因**:avg_cash 的分子是 **phase==CASH 的 245 天**,不是「Layer B 的 RISK_OFF→全现金」的 187 天(也不是两者的并集 247/335 = 0.7373)。M-220 原句「avg_cash 恒 0.7313,是 Layer B 的 RISK_OFF→全现金 在起作用」与实测不合 ⇒ **台账 §0.3 按本条改写**;Layer B 的 regime 乘数仍是 no-op(§3 P1 同族问题)。
