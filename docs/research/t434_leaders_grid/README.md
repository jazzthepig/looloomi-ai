# 龙头网格 v1(T-434 · 台账 S-912)

Jazz 2026-11-24:「各行各业各地区的龙头」;11-25:公开免费的来源就够,不要求即时。

- **是什么**:23 个行业 × 10 个地区,每格市值第一且 ≥ 100 亿美元的公司。186 格有龙头,去重后 **156 家**;其中 55 家已在 World50 的候选池里,101 家是新的。
- **来源**:companiesmarketcap.com 的行业榜第一页(前 100),2026-11-25 的快照。`grid_v1.json` 里每格有龙头和备选(第二名)。
- **只是研究池**:不进 World50、不进 CIS、不进任何账。产品池的资格仍是「链上可持有」—— 按 11-17 的链上数据,这 156 家里日成交 ≥ 10 万美元的只有 18 家,几乎都在美国。
- **已知的问题**:行业归类是站点的口径(Apple 在「软件」、CATL 在「电力」、「金融服务」与「银行」重合);银行 / 金融服务 / 制造 / 石油天然气四个行业第 100 名的市值高于 100 亿,名次更靠后的地区龙头可能漏;原计划 30 个行业,这一版只取了 23 个(饮料、消费品、钢铁、航空航天、综合企业、建筑、娱乐没取);是今天的快照,不是按时点的名单。
