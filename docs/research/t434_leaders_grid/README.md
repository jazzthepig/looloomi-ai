## ⑤ 按时点的龙头 · 美国部分 v1(T-434 ⑤,台账 S-915,2026-11-25)

- **来源**:SEC XBRL frames 的 `dei:EntityPublicFloat` —— 10-K 封面的「非关联方持有的普通股市值」,一次请求 = 当年所有 10-K 申报公司,**含后来退市 / 被并购的**(没有幸存者偏差)。库表 `sec_public_float` / `sec_assets` / `sec_company`(只服务端可读),周度循环的 float 段维护。
- **名单** `pit_us_v1.json`:2011–2025,每个行业 × 每年,美国公司里流通市值第一的那家(行业:今天还在榜上的用网格主行业,其余按 SIC 对照)。重做:`pit_us.py sql` 生成查询 → 在库上跑 → 结果存成 JSON(这次的原件是 `pit_us_query_2026-11-25.json`)→ `pit_us.py build <结果>`。
- **读法**:2015 起当过龙头、今天不是的 38 个(公司 × 行业),今天已不上市的只有 1 个(Dow Chemical)—— 美国这一侧用今天的名单回测,主要的偏差是「今天的龙头当年不是龙头」,不是「死掉的公司没算」。
- **已知的口径差**:流通市值不含关联方持股(家族 / 创始人控股的公司被低估);今天还在的公司用今天的行业归属(GE 2016 年算航空航天);伯克希尔 / Linde / Nike 的行业或地区与网格不一致(见台账 S-915 结果 2)。**守卫和取数方式有两轮是看了数据之后改的**,台账里逐条写了。
- **美国以外**:还没有找到同等的免费批量来源;做任何非美国的历史检验之前仍需另补。
