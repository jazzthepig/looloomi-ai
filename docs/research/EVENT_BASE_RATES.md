## 4 · 这意味着什么

**中文**:三类事件后 30 天相对基准超额的中位数落在 −21% 至 −38%,约四分之三至五分之四的事件为负,且都明显差于同族随机日对照(−6% 至 −10%),因此在相对基准口径上这三类事件整体读作 **UNDERPERFORM** —— 但这是事后描述的基率,不是任何时点可直接执行的信号。

**English**:Across the three event families the 30-day excess return versus benchmark has a median of −21% to −38%, with roughly 75–81% of events negative and clearly worse than the same-family random-day control (−6% to −10%); on a relative-to-benchmark basis these event types therefore read as **UNDERPERFORM** — a hindsight base rate, not an executable signal at any point in time.
