## 4. 结果里还看到了什么(全部为探索性 —— 需另立预注册、在新数据上过零信号对照)

1. **基线在两个半年里都很强且变强**:H1 0.7166 → H2 0.7735;同期 kNN 纹丝不动(0.5186 → 0.5237)。
   形态臂的输出不随市场状态变化(像噪声),基线臂随状态变化(像信号)。
2. **(d) 的均值不是稳健描述,中位数才是**:kNN 前 10% 的 +1.70pp 均值几乎全由 2024-02-05 / 02-12 / 02-19
   三周(+40.6% / +48.2% / +49.0%)撑起来;中位数只有 −0.32pp。均值口径在 140 周上被 3 个早周主导。
3. **「坏决定」在永续宇宙里的可见面本身就窄**:301 个事件代号只对上 **97** 个 USDT 永续(142 个对不上,
   多为监控标签覆盖但没有永续的老币);正例率 1.49%。这是「事件类形态」这条线的结构性上限,与形状好不好无关。
4. **(d) 的等权基准平均只含 444/649 个币**(最少 232)—— 算不出 t+1→t+31 收益的死币不在基准里,
   基准因此偏「活币」。这条对以后任何用全宇宙等权做基准的金额口径都适用。
5. **邻居数越多越接近随机**:K=20 → 0.5109,K=50 → 0.5231,K=100 → 0.5374,离 0.70 越走越远。
   「K 没调对」这个解释空间在 20–100 之间不成立。
6. **正例绝大多数落在参照集之前**:全样本正例 769 条,判定区间查询正例只有 718 条 ⇒ 事件本身稀疏,
   每个币每年最多被标一次事件,30 个月里重复出现的币不多。
