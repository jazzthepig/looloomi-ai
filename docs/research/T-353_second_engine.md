## 0. 一句话

从零写的一台账户引擎，对同一批票（t197 `tickets.A`）出 C0 与尺寸表：

**成交集合逐张对上（358 张）**，同时**独立复现了「∞ 档与 14 档成交集合相同、被名额挡下的正好 76 张」**

## 1. 数据与口径

| 项 | 值 |
|---|---|
| 票 | `docs/research/t197_results.json` → `tickets.A`，956 张（908 张有 `exit_d`，48 张 `still`；44 张 `exit_d == entry_d`） |
| 日线 | `/Volumes/CometCloudAI/cometcloud-local/research/s681/_um_daily.jsonl`（只读），890 个符号 |
| 窗口 | 2020-08-16 → 2026-09-30，2237 天 |
| 规则（逐条来自卡片） | 每票名义 = f × 当日开盘净值 ÷ 止损距离占比；同时在场 ≤ cap_n；同币不重复；名义合计 ≤ 上限 × 净值（超了不进）；进场 = `entry_d` 开盘；出场 = `exit_d` 的 `exit_px`（同日进场同日出场也要出）；来回成本 0.4%；逐日按收盘盯市 |
| 三条不变量（写成断言，跑不过 abort） | ① 没有一张票在 `exit_d` 之后还在 book 里；② 窗口末 book 里只剩 t197 标记 `still` 的票；③ 成交票已实现盈亏之和 = Σ(r × 该票进场时的每票风险额)，差 < 1e-6 × 净值 |

**每一格都跑 `strict=True`**，实测不变量③最大差 2.22e-16（净值口径），全部通过。

## 2. 继承来的假设，用原始数据核一遍

| 假设 | 核法 | 结果 |
|---|---|---|
| `entry_px` = `entry_d` 开盘 | 956 张逐张对 s681 当日 bar | **956/956 ✓** |
| `exit_px` 有出处 | 同上 | **908/908 有出处**：564 张 = `exit_d` 开盘；333 张 = 止损价（当日盘中触止损）；7 张 open+high；3 张 open+high+low+close；1 张 open+low |
| `r` 的定义式 | 两种候选逐张试 | **`r = (exit_px/entry_px − 1 − 0.004) / sd`** —— 净 0.4% 成本折成 R 倍数，**908/908 命中**；「不含成本」那一式 0/908 命中 |
| 不变量③的算式 | 由上式直接推出 | 每票已实现 = `notional × (pct − 0.004)` = `notional × sd × r` = `r × 风险额` ✓ |

## 3. 语义开关（卡片没写死的地方 —— 本卡最重要的发现）

卡片规则里留了两处没写死：**「名义合计」按什么价算**，以及**同一天出场与进场谁先动**。引擎把这两处做成了开关：

| 开关 | 取值 | 含义 |
|---|---|---|
| `ef` | 0 / 1 | 同日 **先进场后出场**(0) / **先出场后进场**(1) |
| `gb` | entry / marked | 「名义合计」= 各仓**进场名义之和** / 各仓**按现价盯市后的名义** |
| `om` | 0 / 1 | 「当日开盘净值」沿用上一收盘(0) / 按当日开盘价重估(1) |
| `ce` | 0 / 1 | 成本时点：出场时全扣(0) / 进场时先扣一半(1) |
| `eoae` / `sde` / `ssd` | — | 出场后净值是否含当日已实现盈亏 / 同日出场是否生效 / 同日进同日出是否直接不进 |

## 4. 验证：逐位复现 t197 已发布 nav.A

`f=1%、cap_n=10、无名义上限` 这一格，与 t197 已发布记录**逐字段相同（Δ=0）**：

```
end 4.953709728711255 | taken 327 | skipped 629 | closed 318 | open_end 9
days 2237 | d0 2020-08-16 | d1 2026-09-30
mdd -0.36937947583288355 (峰 2024-12-08 → 谷 2025-09-25)
peak_gross 1.2628284069900764
```

对应口径 `om0_ce1_sde1_ssd0_ef0`。**一台不共享任何代码的引擎能把 2237 天曲线 + 327 张成交逐位对上，
说明本卡的引擎核心机制是对的。**

## 8. 结果里还看到了什么（探索性 —— 需另立预注册、在新数据上过零信号对照）

1. **2022 年整年 0 张票**：票源里 `entry_d` / `exit_d` 都跳过了 2022（956 张票按年分布：2020 13 / 2021 59 /
   **2022 0** / 2023 320 / 2024 310 / 2025 127 / 2026 127）。所以 C0 曲线 2022 = 0.00% 不是引擎问题，是票源整年空仓。
   ⇒ 这条账户曲线的 MDD（−24.20%）**从未承受过 2022 年的下跌**。是上游信号门控还是数据缺口，本卡未查。
2. **「名义上限 0.40」不是运行中的上限**：上限只在建仓那一刻判定，持仓升值后盯市名义峰值到 0.4595（1.15×）。
3. **C0 的真约束是名义上限，不是名额**：名义挡 522 张 vs 名额挡 76 张（6.9 倍）。
4. **名额 10 档收益更高、回撤更浅**（+110.89% / −21.37% vs +98.35% / −24.20%）：多进的 29 张合计 ΣR 为负。
   与 T-352 同向，数字不同（他们 +107.13% / −21.22%）。
