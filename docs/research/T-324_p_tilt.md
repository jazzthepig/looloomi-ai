```

**判(P 对 M52,全过才 ✅):** (i) P 总收益 ≥ M52;(ii) `apparatus.ab_test`(P vs M52,平均块长 20 天,2,000 次,种子 802)p(P ≤ M52) ≤ 0.10;(iii) 两半 P 的超额(对 HOLD)都 ≥ M52 的超额;(iv) P 的最大回撤不比 M52 深 2pp 以上。另报:三臂对 HOLD 的年化超额、β(对 HOLD)、跟踪误差、换手、最差月。
```

## 5. 与 S-428 发表数的差(口径不同,逐条说清)

S-428 发表(「动量+52w · 周 · k=1」):年化超额 **+17.3%**、t 3.23、样本外 +10.2%(t 1.62)、β 0.98、相对最大回撤 −14.1%、最差 12 个月 +0.8%、年换手 12.8×。
本卡重算同一信号:**年化超额 +3.61%**、β 0.946、回撤 −66.10%、年换手 13.59×、最差月 −27.61%。

差在四处,**不是算错**:
1. **宇宙**:S-428 用**今天的幸存者 24 名**(死币剔除);这里用**按时点 `cap_pit24`**(死币在名单里,直到掉出市值前 24 才走)。
2. **窗口**:S-428 是 2020-01-01 → 2026-09-25,**含 2020/2021 两年牛市**(其分年超额 +35.6% / +41.1%);这里只有 2023-01 → 2026-10 的震荡段。
3. **基准**:S-428 的基准 = 合格币(≥180 天历史)等权;这里 = 当周面板全体等权。
4. **价格源**:S-428 用 Binance 公共日线;这里用 `asset_mcap_daily`(① 的同一出处,才有「按时点」这回事)。

## 6. 结果里还看到了什么

> 下面每条都标「**探索性 —— 需另立预注册、在新数据上过零信号对照**」;本卡只报不判。

1. **② 的「基准」用等权还是用臂本身的权重,能单独决定 ② 的胜负。** HOLD 的最大回撤 **−71.64%**:等权持有 ① 的时点面板(含死币)比想象中惨得多,而 ① 自己的 `cap_pit24` 臂是市值加权 + 单币 ≤ 40%。S-802「写死」了「基础权重等权 1/N」,这个选择此前没人单独审过。(探索性)
2. **P 输在信号,不在倾斜幅度。** P 的 β 0.947 / 跟踪误差 9.23% / 换手 15.30× 与 M52 的 0.946 / 9.71% / 13.59× **同量级** —— 同样大的倾斜、同样贴近 beta,但方向更差 ⇒ 差的是 P 在 ① 面板这 24 名上的排序力。(探索性)
3. **P 在 ① 面板上有 686 个成员-周没有分**(资产流宇宙不含 MATIC / SHIB / CRO / GRAM 等)。这些币按 z = 0 拿 1/N ⇒ P 的倾斜每期只作用在一部分成员上,另一些是「中性持有」。(探索性)
4. **S-428 那 +17.3%/年 的 13.69pp 差,拆成「窗口 −8.09pp + 宇宙 −5.60pp」两半。** 同窗口、只换面板:S-428 的幸存者 24 名 ⇒ 年化超额 **+9.21%**;同一批名单、只换窗口(2023-01→2026-10)⇒ **−8.09pp**;再把面板换成按时点 `cap_pit24`(含死币)⇒ **+3.61%**,即宇宙效应 **−5.60pp**。**窗口比宇宙吃掉的还多**,而 §5 里这两条此前只是「口径不同」的一句话。(探索性)
