## ③ 机制:为什么反着(三条,都来自原始数)

1. **HL 的费率系统性地高于 Binance**,不是「两所各有拥挤、时高时低」。
   逐日逐名 26,594 个格子(Binance 日费率 − HL 日费率):均值 **−1.3479bp/日**、中位 **−0.8752bp/日**、
   p10 −6.1987 / p90 +3.3527;**Binance 更高的只有 29.91%,HL 更高 65.58%**。
   ⇒ 「挑高的那所」多数时候挑的就是 HL:选中名-周里 **81.51% 落在 HL**(Binance 只占 **18.49%**;
   全部名字口径 1161/(22×178) = 29.63%)。跨所臂实际退化成「HL 单所臂 + 换所成本」。
2. **选所依据(过去 7 天均值)与实现值不同向**:Binance 系统性更低 ⇒ 你只在 Binance 短暂冲高时切过去,
   而那正是 Binance 费率回落的窗口。副项「只在 Binance 做(现货 + 永续同所)」:
   全样本资本 **3.8600%**(A1 的 10.5654% 的三分之一),**2026H1 资本 −1.3781%(负)**。
3. **2026H1 的压缩是两所共同的**,不是 HL 一所:连 Binance-only 都是负的。跨所不但没救回那半年,
   反而因为切向更差的那所 + 换所成本(196 次 × ~13bp),把资本口径从 A0 的 2.0940% 压到 1.4126%。

成本侧原始数:换所 196 次(平旧空 + 开新空 ≈ 13bp/次,现货腿不动),年化 **57.6 次**;
事件计数:开 422 / 平 411 / 现货腿被动 441;基差事件 Binance 腿 299 次、HL 腿 534 次(HL 缺标记价 ⇒ 记 0 并计数),
基差缺数 0 次。总成本拖累:A2 **1.0114pp/yr** vs A0 1.4959pp/yr(A2 的规则 B 更宽松、开平次数更少,
所以拖累反而略低 —— 这也说明拖累不是跨所失败的主因,毛收益增量 −0.9616pp 才是)。
