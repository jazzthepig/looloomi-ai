## 1. ① 序列对比:量纲差 3–6 倍,但 DB 不是「干净现货」,是 hybrid

- 成交量比值(缓存 ÷ DB)按符号中位:全样本中位 **3.22**(p05 1.00 / p25 1.00 / p50 3.22 / p75 4.24 / p95 5.94)。
- **受影响符号(比值中位 < 0.5 或 > 2):171 / 259**;完全一致(比值 = 1 且收盘逐字节相同):**87**。
- 收盘价差(DB vs 缓存)中位 **0.074%**,最大 **0.125%** → 价格几乎一样,量纲完全不同。
- **按月的比值**:2019-10→2020-05 = **1.000**;2020-06 起爬升;2021-06→2022-12 约 2.4→6.5;
  2023→2026-07 约 3–6;**2026-08 起回到 1.000**。
- 逐缓存文件:`t156/_bars_early`(2018-01→2020-12,74 符号)1.00→1.47;`t156/_bars`(2021-01→2025-04,241 符号)1.30→2.83;
  `t159/_bars`(2025-04→2026-10-19,237 符号)2.83→4.06→**2026-08 起 1.0**。
- **交叉核对(`binance_um_hist` = S-698 拆出来的永续序列)**:
  2024 窗口与 2026-06→08-08 窗口内 —— 「缓存 ÷ um_hist」成交量比值中位 = **1.00**(逐日等值),
  「DB ÷ um_hist」= **0.19–0.49**,「DB ÷ 缓存」同值;价格上「DB vs 缓存」与「DB vs um_hist」的相对差
  **完全相同**(0.0008)⇒ **缓存 = 永续量 + 永续价;DB 的 `binance_hist` 现在 = 现货量**(价格只差 ~0.08%)。
- `1000SHIB / 1000LUNC / 1000WHY / 1000X` 比值恒为 1.00(Binance 没有这些现货对,现货接口回的就是永续)
  —— T-235 说的「42 个符号逐字节相同」属这一类。

**结论(口径)**:今天的 `binance_hist` **不是**一条干净的现货序列,而是 **hybrid**:
中段(约 2020-06→2026-07)是现货量,两端(≤2020-05、≥2026-08-08)仍是永续量。
换句话说,现在拉下来的序列里有**两处人为量纲断点**(2020-06 附近下跌 3–6 倍,2026-08 附近又涨回来)。
(判定依据:早期与末期的比值是**逐字节的 1.000**,不是「2019 年永续/现货成交额本来就差不多」——
那个解释要求 87 个符号、15 个月都精确相等,不可信。)

## 5. ⑤ 纸面书为什么是空的:闸门是开的,是没有信号

- 闸门**开着**:DB 序列上 BTC 收盘 76,816–78,354 vs 200 日均 73,147–73,207 → 2026-10-29→11-03 **6/6 天在均线上**;
  majors 风格指数(cap 权重,DB 现读)11.34–11.55 vs 其 200 日均 10.81–10.82 → `gate_open=true` **6/6 天**。
- 但两条序列在这 14 个交易日里**完整信号数 = 0**:宇宙 43–49 个符号 → 过量能门(≥2×40 日均额)只剩 0–4 个
  → 再过 40 日振幅 ≤40% / 120 日回撤 ≤50% / 破 40 日高 / 站上 200 日线后**归零**。
- `r_tickets_paper` 0 行;`r_money_daily` 每天 `nav=1`、`taken/skipped/closed/gross` 全 0
  ⇒ **纸面书空是「没有信号」,不是闸门关、也不是调度器没跑**(16 天每天都有行)。

**一句话**:2026-10-29→11-03 majors 闸门全程开着(BTC 收盘 76.8–78.4k 全在 200 日均 73.1–73.2k 之上),
纸面书空是因为两天序列在那些日子里都没出完整信号(宇宙 43–49 → 过量能门 0–4 → 完整信号 0)。
