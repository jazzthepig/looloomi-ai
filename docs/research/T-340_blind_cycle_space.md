### §1 「该维 ≥ 730 个观测才出 z」——门槛有,窗口没有

原文只写门槛。读法 ①**扩张窗口**(全部严格更早的观测算均值/样本标准差)vs
②**最近 730 个观测滚动窗口**。**我主用 ①**(原文「用严格更早的值算均值/样本标准差」没给窗口,

### §2 「段数 ≥ 3」管不管 trim

原文:「段数 ≥ 3 且 tilt_excess ≥ +0.25 ⇒ add(现货 1.0);≤ −0.25 ⇒ trim(0.35);否则 hold(0.70)」。
第二个分句**没有重述**段数条件。读法 ①字面并列(trim 只看 tilt)vs ②门槛对称。
**我主用 ①**(字面),变体 V1 = ②。**影响**:trim 周数 ⇒ (c) 的回撤路径与 (d) 的极端附近计数。

### §3 无条件频率的分母

原文「无条件 = 所有日期 ≤ t − 181 天的日子的频率」。读法 ①字面(全部 ≤ t−181 的日子,
**含空间外的早期日子**)vs ②只算空间里可比的(≥5 维有 z)。**我主用 ①**,变体 V3 = ②。
**影响**:收缩基线 ⇒ tilt 水平 ⇒ add/trim 频率与 (a) 的 Spearman。

### §4 「三档 Brier」的三档是哪三档

原文只定义两个标签(up: fwd ≥ +25%;down: fwd ≤ −20%)。「三档」= up / down / **中间**(其余)。
中间档概率取 `1 − p_up − p_down`;若改成分别收缩中间档频率,**数学上同一结果**
(频率互补 + 线性收缩),不是真歧义。Brier = 三档平方差之和(用 `apparatus.brier` 逐档算再相加;
除以 3 不改判据)。

### §5 (c) Calmar 零分布的块长

的默认 block=1**;block=26 是另一读法,未跑。

### §6 (c) 换手与生效时点

周一收盘定权重、次日收盘生效 ⇒ 持有期 = t+1 收盘 → t+8 收盘。换手 = `|Δw|`(现货腿单边)× 10bp;

(脚本已同时算)。**影响**:这一条很可能是全卡的边界判据。

### §8 (d) 顶 / 底 的口径与数量

顶 = 每个减半纪元起点(2012-11-28 / 2016-07-09 / 2020-05-11 / 2024-04-20)到下一个减半起点之间
的最高收盘;底 = 每个顶**之后到下一个顶之前**的最低收盘 ⇒ **4 个顶、3 个底**(第四纪元未走完,
没有"下一个顶",故无第四个底)。第四纪元的"顶"是**至今**最高收盘(会随行情变)。
窗口判定用**决策日**(周一),若用生效日(t+1)边界差一天。

### §10 检验窗口的起止

## 2. 已固化的实现(`t340_blind.py`)

**8 维原始值**(d 当天只用 ≤ d):
`mvrv=ln(MVRV)` · `puell=ln(当日发行美元 ÷ 最近 365 天均)` · `hash_30d=ln(近 7 天均 ÷ 30 天前 7 天均)`
(原值,已是 ln) · `dist_200=ln(价 ÷ 最近 200 个连续日均价)` · `ret_365=ln(价 ÷ 365 天前价)` ·
`dd_ath=价 ÷ 截至当天最高价 − 1` · `vol_90=最近 90 个日对数收益的**总体**标准差(ddof=0)` ·
`fng_30=最近 30 天 fng 均值(≥20 观测才有,否则该维不存在)`。

**标准化**:每维用**严格更早**的值算均值/样本标准差(ddof=1);该维 ≥730 观测才出 z;z 截 ±6。

**距离**:`√(Σ_{共有维} Δz²) × √(8 ÷ 共有维数)`;共有维 <5 不比。

**近邻**:候选 = 日期 ≤ t−181 的日子,取最近 K=60(同距按日期);段数 = 近邻按日期排序后相邻间隔
≥90 天切段;`w = 段数/(段数+3)`;`p = w·近邻频率 + (1−w)·无条件频率`(up/down 各一);
`tilt_excess = (p_up − p_down) − (无条件up − 无条件down)`;表态见 §2。

**判据**:
(a) 周度 Spearman(tilt_excess, 实现 fwd180) ≥ 0.20;实现序列循环平移(block=26 周,1000 次,种子 814)
零分布 `p_upper ≤ 0.05`。
(b) 三档 Brier(收缩 p) < 无条件频率 Brier;配对块自助(块长 26 周,2000 次,种子 814)的差
95% 上沿 < 0。
(c) 周一收盘定权重、次日收盘生效、10bp×换手、现金 0;对 HOLD70 总收益 ≥ 且最大回撤浅 ≥ 5pp;
Calmar 对权重日程整体循环平移零分布(1000 次)`p_upper ≤ 0.10`。
(d) 四轮周期极端:顶 ±30 天无 add、底 ±30 天无 trim;≥2 个顶附近有 trim、≥2 个底附近有 add;逐轮表。
(e) 两半(按周数)Spearman 同号。
