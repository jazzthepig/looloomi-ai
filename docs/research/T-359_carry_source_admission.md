## 3. 判据实现(逐条对 S-835 的字)

| 判据 | 实现 | 门槛 |
|---|---|---|
| (i) 相关 | 套息 vs 账户、套息 vs R-v2,月频;全样本 + 压力月(压力月 = ① 最差五分之一的月,照 s834 的 `Km.quantile(0.2)`)。相关**只在套息在场的月份**上算 —— 套息不在场时它是 0,算进去只会稀释或伪造 | 绝对值 < 0.30 |
| (ii) 贡献为正 + 零分布 | **字面读法有坑**:`apparatus.circular_shift` 平移不改变序列均值,所以「套息自己的均值 vs 平移后的均值」零分布是退化的(apparatus 抛 `NoOpNull`)。脚本两版都跑:字面版记录退化事实;**对齐敏感版**(统计量 = 套息在压力月里的累计收益,平移 500 次、block 1、种子 20261113)给可检验的 `p_upper`。判据第二条路(≥60 天为正的前向记录)读 `carry_hl_daily` 表 | `p_upper` < 0.10 或前向 ≥60 天为正 |
| (iii) 不变差 + 来源数升 | 加前/加后各算一次账户最差 20 日(滚动 20 日复利的最差点);有效来源数 = 风险贡献的熵(照 s834) | 最差 20 日不变差、有效来源数上升 |
| (iv) 两窗口同向 | A = 套息起点 2023-06-12 起;B = 2021-10-11 起(账户起点) | 结论同向,否则写「窗口依赖」 |

**尺寸**:套息缩放 `w` 二分到它自己的月频风险贡献 = 10%(口径照 s834:`cov(w·套息月贡献, 账户月收益)/var(账户月收益)`)。
网格先扫一遍确认单调,再二分;不可达就报「不可达」而不是硬凑。
