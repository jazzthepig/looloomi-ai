## 0. 预注册(先写下来,再算 —— 本节在读到任何结果之前定稿)

### 0.1 为什么要重做

T-227 的闸门没过:`events` 表里 `source=binance & kind=listing` 只有 **107 行**(卡上闸门 ≥ 2,000),
且 `ts` 只覆盖 2024-12-11 → 2026-11-02、`recorded_at` 全是 2026-11-02 ⇒ 一次性回填、被公告 API 分页封顶,
再等一轮不会变多。T-227 因此**没有下裁决**,只留下一条方向提示:派生口径(Binance 现货首次出现日)
在固定 25 名篮上的中位数是 **−22.35%**、随机日期对照分位 0.000。

但那个数字不能用,原因是基准坏了而不是结论坏了:

- **固定 25 名篮是「今天的」篮子**。2017–18 的事件里只有 **2–5 个**成分有价,
  等权基准退化 ⇒ 早期事件的相对值被放大(T-227 实测 LTC 一条 −238.73%)。
  「开闸是高位」与「基准坏了」在同一个数字里混着,分不开。
- 事件源本身也从没被单独检验过:`ohlcv_daily(source=binance_hist)` 每符号首次出现日 =
  Binance 现货上币日代理,T-227 抽查 9 个逐条对上(BTC / ETH 2017-08-17、BNB 2017-11-06、
  LTC 2017-12-13、NEO 2017-11-20、QTUM 2018-03-19、ADA 2018-04-17、XRP 2018-05-31、IOTA 2018-05-31)。

本卡换**时点(PIT)**基准重做,并把「基准有多满」这个混淆项显式量出来。

### 0.2 事件源

- 事件 = `ohlcv_daily` 中 `source=binance_hist` 的每个加密符号的**首次出现日 d**。
- 口径与 T-227 一致:`asset_class = 'Crypto'`。T-227 实测该表 262 个符号全部是 Crypto。
- **剔除 2017-08-17 的 BTC / ETH**:那天是 Binance 行情的历史起点,不是上币日 ⇒ **260 个事件**。
- 不用 `assets.listed_at`(那是 CoinGecko 首日:SOL = 2020-04-11 早于 SOL 上线)。

### 0.3 价格

- 事件资产与 PIT 篮都用 `source=binance_hist`(每符号一条序列)。
- 查价语义 = `apparatus.price_on_or_after(d, max_gap_days=3)`:d 当天或之后 3 天内第一个有效收盘;
  没有就是「不可算」,**不是 0**。
- 公告前涨幅单独用 `source=coingecko_pro_ohlc`(同一源两端,不跨源拼接);
  CoinGecko 每股历史窗口有限 ⇒ **n 单独报**,不足就只报不判。

### 0.4 基准(PIT 加密市场等权篮)

- 成分 = **当日有价的所有加密符号**(本口径取 `binance_hist` 的 Crypto 集,262 个)。
  每个成分从自己的首次出现日才有价 ⇒ 篮天然是时点的,不是回看今天的。
- 每个事件都报 **nb**(窗口两端都有价的成分数)。
- **逐位自检**:向量化口径 vs 逐名 `apparatus.long_return` 口径必须逐位相等(见结果里的 `basket.selfcheck`)。
  与 T-227 固定 25 名篮同时报,用来量化「基准坏了」这个混淆项。

### 0.5 主口径与判据(写死,只算一次)

- 主口径 = **d+1 → d+30** 的事件资产收益 **减去** 同期 PIT 市场等权篮收益。
- ✅「开闸是高位」= **中位数 < 0** 且在**随机日期对照**里 **≤ 5 分位**。
- 随机日期对照:同一符号、随机 d、**1,000 次、种子 708**;每次抽样对每个事件取该符号序列里的
  一个随机起点 d,算**同一口径**(出口 = 入口 + 29 天,与 d+1→d+30 同长)的相对收益,取中位数;
  实际中位数在零分布里的中秩分位 = `apparatus.percentile_of`。
- 零分布 / 盈亏只用 `src/data/evaluation/apparatus.py`(`long_return` / `price_on_or_after` /
  `null_distribution` / `percentile_of`)。

### 0.6 信号日挪一天(S-665)

派生量(入场价、篮成分)只在当天成立的不算。所以主口径之外**再判两次**:
`d+2 → d+31`(往后挪一天)、`d → d+29`(往前挪一天)。预注册要求:**主口径与往后挪一天都成立**才算数。

### 0.7 副口径 / 分段 / 子集

- 副口径:d+1 → d+90。
- 三个时代:2017–2020 / 2021–2022 / 2023–2026,各报中位数与分位(分位用该时代子集自己的对照)。
  **时代样本 < 30 ⇒ 只报不判。**
- `nb ≥ 20` 子集:只保留事件窗口里篮成分 ≥ 20 的事件;对照里也要求篮成分 ≥ 20(同口径)。
- 公告前涨幅:d−30 → d(CoinGecko),报 n。

### 0.8 不做

不做交易规则、不扫参数、不判「可以做空」、不改代码、不做 DDL、不入库。

### 0.9 弃算的一次运行(诚实记录)+ 事后加的两条诊断臂

**第一次运行作废,数字不引用。** 原因:PIT 篮的前瞻价矩阵把「等到下一个收盘要等几天」的
减法写反了(`grid − ds` ⇒ 恒 ≤ 0 ⇒ 判据 `gap ≤ 3` 恒真),结果**每个符号在它上市之前的
每一天都被塞进了"下一个价"**,篮成分数在 2017-09-01 恒为 262(逐名 `apparatus` 口径是 2)。
那个运行报出的「主口径中位数 −18.177%、三个时代全部 CONFIRMED」因此**全部无效**。
抓到它的是卡上要求的**逐位自检**(`basket.selfcheck`):逐名单名收益差 = 0.0(通过),
但篮的均值差最大 0.285、成分数在 200 个窗口里有 182 个对不上(不通过)⇒ 判定篮子建错,不是结论错。

修正发生在**读到任何有效数字之前**(弃算的那组数字在修好之前只有那一组)。
修正后新增两条**诊断臂**(不是预注册主口径,单独报、不参与裁决):
- **绝对收益对照**:统计量不用篮,只比绝对收益的中位数 ⇒ 完全绕开「事件窗篮薄 / 对照篮厚」。
- **起点只抽在上市后头一年**:让事件窗与对照窗的篮厚度可比(见 §1 的口径不对等讨论)。

两条都是**对照**(null)的诊断,不是处理臂的参数扫描。

### 1.7 裁决

**✅「开闸是高位」在 T-233 预注册口径下成立**:260 个 Binance 上币事件,上币后 30 天相对
**时点**加密市场等权篮的中位数为 −18.03%,在随机日期对照里处于 0.000 分位;往后挪一天仍成立;
绝对收益(完全不用篮)、篮厚度拉平、排除事件窗、nb≥20 子集五个方向都给出同样的结论。
90 天口径更极端(−29.70%)。三个时代各自都成立。

### 1.8 这张卡**没有**回答的

1. **2026 的上币事件不在样本里**:最后一个事件是 2025-12-21(IR),而价格数据到 2026-11-03 ⇒
   「2023–2026」这一代其实是 **2023–2025**,最近 10 个月的上币完全缺席。
2. **事件源是代理,不是公告**:首现日 = Binance 现货挂牌日(抽查 9 个逐条吻合),但从未在 Binance 现货上市的币不在样本里;
   本表也没有退市事件。
3. **公告前形状仍未测到**(§1.6):`events` 表这次长到 **1,474 行**(T-227 时是 107 行),仍差卡上的 2,000 闸门 ⇒
   公告日历这条更直接的路子还在填,等它过了闸门应当重跑一次(那时才是真正的「公告前 / 公告后」)。
4. **薄篮时代**(2017–2020,nb 中位 57、最小 3)的相对数噪声大;nb≥20 子集只覆盖 243/260 个事件。
5. **三个时代不是三个独立样本**(同一个市场),时代之间的量级差不能当成三次重复验证。

### 1.9 探索性发现(**需另立预注册、在新数据上过零信号对照**)

1. **效应的时代斜率**:相对中位数 −10.1% → −21.4% → −29.2% 单调变差,而同一时期的对照中位数也在变差
   (−3.4% → −4.5% → −7.0%)。两者同向 ⇒ 「越晚上市越差」里既有绝对市场变差,也有超额变差,
   这两件事在本卡口径里分不开。
2. **篮成分数与效应量级无关**:nb 3 的事件(LTC 一条 −175%)和 nb 214 的事件对中位数的贡献结构不同,
   但中位数在 nb≥20 子集上只从 −18.03% 变到 −18.71% ⇒ 主结论不靠薄篮撑着。
3. **上币后 30 天与 90 天的差**:−18.0% → −29.7%(多出的 11.7pp 全在第 30–90 天),说明这不是「一两天崩完」,
   而是一个持续两个月的下行段。
