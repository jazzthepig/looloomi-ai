## 3b. 诊断与限制(读表前先看这三条)

1. **F3 的 z 形态不可算**:扩张五分位塌陷、底两档为空(`bin_counts` = [0, 0, 66, 1235, 454])。资金费拥挤广度绝大多数日子 = 0(没有合约年化超过 30%),水平 z 在这种离散序列上分不出档,顶减底 Δ 无定义 ⇒ F3/z 全是「—」。**F3 只有 Δ30 形态可读**;这一格是口径的产物,不是「没信号」。
2. **日历混淆诊断(照 T-241 同一把尺)**:`cal_gap` = 顶档 − 底档的平均日历日。F2/z 620 天、F1/z 372 天、F4/z 288 天、F5/z 166 天 —— 这些形态的顶档就是「晚几年」,Δ 里有明显的年代成分,不能只当「状态」读。F4/dz30 是 −570 天(顶档反而更早)、F5/dz30 −1 天(无年代成分)。
3. **`pct_adj` 的方向只对收益类结果校准**:`Δ_adj = −Δ` 照的是「高位不良 ⇒ 之后收益更低」,S-724 的候选规则也只用收益类期限(fwd30/60/90)。**回撤频率类结果里更大的 Δ 本身就是不良方向**,所以那些行的 `pct`(原始分位)才是面向不良的那一版 —— 例如 F4/dz30 的「90 天内进回撤段(峰锚)」Δ=+17.2pp、原始分位 0.984,F1/z 同项 +12.0pp、0.987,F5/z 的「起点锚」+14.0pp、0.982:高位拥挤 / 新杠杆 / 集中 与「之后进回撤段」强相关,但**在收益类期限上不显著、且没有先行性**。
