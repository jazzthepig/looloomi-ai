## 2. 两个口径:「水位」与「搬家」必须分开量

v1 的相位要两半同时成立:**恶化分 ≤ −0.5**(水位)+ **shift_pct ≥ 0.75**(搬家距离在自己扩张历史的前 25%)。
本件把两半分头拆开,并各配一个结构量:

- **水位口径**:`n_neg` = 今天有几个分量的 z 落在自己历史的下侧(SIGN·z < 0);`n_le1` = 有几个分量的 z 低于自己历史 **1 个标准差**(SIGN·z ≤ −1)。
- **搬家口径**:`n_bad` = 今天有几个分量相对 90→30 质心**在坏方向**(SIGN·(z − cen) > 0);`bad_weight` = 坏方向分量的 |z − cen| 占比;`argmax_share` = 搬家距离里最大那个分量的平方占比。

## 3. 机制读数(更正 T-239 notes 第 ② 句)

1. **崩塌 = 「水位低、但几乎不搬家」。** crash1 那 45 天里 `n_le1` 中位 **5**(五个分量同时低于自己历史 1σ)、但 `n_bad` 中位 **1**、`bad_weight` 中位 **0.036** —— 慢性单向下行,90→30 质心跟着一起下移,每天相对质心几乎没动。**所以 shift(相对近期质心的搬家距离)在真实崩塌里天然失效**:它量的是「跳」,不是「塌」。
2. **turning = 「搬家」而不是「水位」。** seg1/seg2 的 `n_le1` 中位只有 **1 / 2**(水平上只有一两个分量深),但 `n_bad` 中位 **3 / 4**、`bad_weight` **0.29 / 0.38** —— 多分量同时跳离自己的近期基线。turning 天在 σ 单位上中位只有 **−0.97**,远浅于崩塌日的 −2.02 / −1.57 ⇒ **相位与「深水位」没有对应关系**。
   ⇒ **更正:** notes 说「shift 量的是单分量离群,不是状态迁移」—— 前半句对(两边的 `argmax_share` 中位都 ≈0.47–0.69,都是单分量主导:崩塌是 taker_buy、seg2 是 lend_apy),但后半句**不成立**:崩塌段同样是单分量主导。真正的区分不是「单 vs 多」,而是**离群幅度/分位**与**水平同时性**这两件事。
3. **相位的两半各走各的,永不相遇。** seg1 里 28 天过搬家那半、23 天过水位那半、**同时 0 天**;crash1 里 45 天过水位那半、**搬家那半 0 天**(窗口 223 天最高 0.7298,离 0.75 差 0.02;≥0.70 只有 1 天)。crash2 窗口 123 天里有 9 天 ≥ 0.75,但**与 det ≤ −0.5 的 44 天零重合**。
   ⇒ 相位实际是靠**滞回状态机**(连续 3 天 + det > 0 才出)进的,不是靠当日两条件 —— 这解释了为什么 turning 天里两半同时成立只有 13/222 天,相位却能连续 127 天。
4. **两个真实崩塌窗口的 shift_pct 天花板都恰好卡在 0.75 之下**(crash1 0.7298 / crash2 在 det≤−0.5 的日子里 0.7449),而两段假 turning 的天花板到 0.9869 / 0.9705。**这是 ⓪ 层「只亮假灯」的机械原因**,与阈值 0.75 是不是「对」无关。

## 4. 顺带发现:恶化分的分母逐期漂移(方法学,不是规则试验)

`deterioration = Σ SIGN·z / n`,而 **n = 当天有分的分量数,逐日不同**:2021 全年 n=6(337 天)、2022 n=7(341)、2023 n=7(365)、2024 7→8(40/326)、2025 起 n=8(365);2018–2020 n=0~4 ⇒ 整段无分(与 T-234 窗口从 2021-02-01 起一致)。
⇒ 同一个**绝对**阈值 −0.5,在 σ 单位上分别是 **−1.22σ(n=6)/ −1.32σ(n=7)/ −1.41σ(n=8)** —— 门槛在 2025 年后实质**更严**。跨年代比较恶化分时,必须用 `det·√n` 而不是 det 本身(本件已同时给出两列)。

## 5. 候选(⚠️ **全部未测**)

⚠️ **探索性 —— 需另立预注册、在新数据上过零信号对照。** 以下四条**没有在本件里回测过任何一条**,也没有报它们的收益 / 回撤 / 分位;它们只是从 §3 的结构读数里长出来的候选,**⓪ 层第 3 次试验才谈**。

1. **水位 + 持续**:把相位的第一半改成「恶化分 ≤ 阈值 连续 N 天」,不要求搬家 —— 直接对上崩塌的结构(慢性、单向、持续)。风险:慢性下跌会长期满足 ⇒ 需要独立的恢复/退出条件,否则变成长期空仓。
2. **水平同时性**:`n_neg ≥ 5` 或 `n_le1 ≥ 3`(多分量同时在历史下侧)。⚠️ 实测里它**只对 crash1 成立**(n_le1 中位 5),**crash2 只有 3**(中位)⇒ 单靠它抓不到第二次崩塌,不能当银弹。
3. **搬家换基线**:相对 **365 日**基线而不是 90→30 质心 —— 慢性下跌时相对长期基线仍在「搬家」;或改用带方向的搬家 Σ SIGN·(z − cen)/n 的分位。
4. **消除分母漂移**:恶化分改用 σ 单位(det·√n)或改用「恶化分在自身历史里的分位」,让门槛在 6/7/8 分量年代可比。
