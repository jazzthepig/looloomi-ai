## §2 挖掘

### 关键观察:R3 W3 失败是结构性的
shuffle 用「随机周 × 随机 30 名外名」。 该结构 = 「不分类的随便做空」— 实际是「逮到 2023-2024 大熊 + 2025 末弱市的任何空头」,自然能赚钱。
R3 真实事件集中在 2024 (1196 笔 / 1802 = 66%), 而 2024 4 月比特币冲顶后 5-8 月深熊 — 是做空黄金窗口,但**事件本身就生在那个窗口** ⇒ 事件时间结构上 R3 拥有 β 而非 α。
对照不含「β」是因为它的均值对所有周 (2023/2024/2026) 等权 ⇒ 随机周反而包含更多 5-7 月熊市窗口。

### R1 W1 +17.22% 是事件膨胀假象
W1 (2020-2022) 288 事件,R1 启用 13 周归零 ⇒ 总禁用周数 = 288 × 13 = 3744 周,实际 nM = 156 周 ⇒ **平均每名被禁 ~24 周**(即全年)。
这是结构性的:**R1 在高事件密度窗口等于禁用几乎全部 24 个非 BTC 名 ⇒ 等同于满仓 BTC。** 而 BTC 在 2020-2022 跑赢横截面(尤其是 2021)。
shuffle p49 (中位) ⇒ 等同「满仓 BTC」也是中位结果 ⇒ R1 实际就是「事件密度高 ⇒ 满仓 BTC」机制,而非 z30 信号本身。

### R2 是「BTC 反弹后 + 杠杆」的故事
R2 事件数 W2=18 / W3=29,R2 启用 13 周 ≈ 半年。W2 / W3 打乱分位 91.6 / 85.2 ⇒ 单边信号接近通过。
但超额都 < 0 ⇒ 资金费吃掉了杠杆收益:
  - W2 资金费 -2.95%, 超额 -1.12% ⇒ 净收益略正(多 btc 摊薄到 -1.12%)
  - W3 资金费 -0.93%, 超额 -7.18% ⇒ BTC 自己下行 + 杠杆 = 双重损失
R2 不通过,但 R2 的打乱分布窄(shuf_p10/p90 ≈ 1.52/1.64 在 W1),说明 1.3x 杠杆的损益空间相对固定。

### 与 S-569 prior 的张力
prior 说「非 BTC 名 z30 ≥ 3 之后 30 日相对 BTC −16.4%(81% 跑输),90 日 −38.7%」。
我们 R3 测量 = 短+多 BTC 的对冲净回报(不是单边短)。
- W2: 多 BTC 收益 +4.89% + 短端收益 +12.83% = 净 +17.52%(均值 / 30 天持有)
- W3: 多 BTC 收益 -3.26% + 短端收益 +13.57% = 净 +10.11%

prior 的「相对 BTC -16.4%」是「不持 BTC 的纯短」— 我们的 W3 短端收益 +13.57% 与 prior 的 -16.4% 是不同窗口/不同测量:**prior 用 BTC 8-12 月熊,我们的 W3 是 2025-2026 全段包含 11 月反转上涨后阶段**。两者数值上不同但方向一致(短端有正 α),**绝对数值不应直接比较**。

## §3 失败原因 / 边界

- **R1 = 「满仓 BTC」机制,不是信号**:高事件密度 ⇒ 几乎禁用所有非 BTC ⇒ 与直接持 BTC 等价。**这是结构性失败,不是 z30 信号好坏的问题。**
- **R2 = 杠杆正贡献被资金费吃掉**:BTC 弱势反弹少单边,1.3x 的额外 β 被 funding 6.87% (W1) 吃掉。W3 失败是因为 BTC 在 2025 下行,杠杆放大了回撤。
- **R3 = 真实有 α(短端),但打乱对齐分位低(R3 因 W3 实际 = p0)**,说明「随便做空」比「z30 触发后做空」更容易赚钱。**z30 是「何时不做空」的反向指标 — 真的暴涨后才做空往往会迟到,资金费率已经反转。**
