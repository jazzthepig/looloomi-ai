## 4. 结果里还看到了什么(假设之外)

以下每条都标「**探索性 —— 需另立预注册、在新数据上过零信号对照**」,不是本卡的结论,也不改 S-774 / S-776。

1. **IC 变弱、尾部分化反而变强。** R 的 Q5 − Q1 从 0.042736 升到 0.044233,P 从 0.046092 升到 0.046492,而两者 IC 各降 13% 左右。⇒ 宇宙扩张稀释的是**中段**排序,不是两端。(与 S-790「排除用法要看尾部,不看 IC」同向,但 S-790 记的是「尾部几乎没动」,这里是「尾部没动而 Q5−Q1 变大」,措辞要分开。)
2. **「因」维(R)的尾部对宇宙变化敏感,「相位」维(P)的尾部不敏感。** 最低五分位的漂移:R −0.002483,P −0.000173(差 14 倍)。合理解释(待证):新增币没有历史资金面 ⇒ 因维在新币上几乎是噪声,而相位维(动量/波动)在任何币上都有值。但这是**解释**,不是证据。
3. **排序力和尾部几乎全部来自后半段。** 前半(2023-01→2024-10,92 周)R/P 的最低五分位 ≈ 0(+0.0002 / −0.0008),后半(105 周)是 −0.0438 / −0.0461;IC 也是后半更大(0.133 / 0.153 vs 0.037 / 0.032)。⇒ 「这个排序」在后半段比前半段强 3–4 倍。
4. **最低五分位是双峰的:四分之一的周里它反而是正的**(p75:R +0.0159、P +0.0143)。⇒ 均值 −2.3% / 中位 −2.1% 的差距说明尾部不是每周都坏,是「多数周小亏 + 少数周大亏」。
5. **P > R 在今天的快照上不翻转,但差距收窄。** `IC(R) − IC(P)` 从旧快照 −0.0112 收窄到 −0.0084(t 从 −1.23 附近到 −1.12)。⇒ S-776 的叙述「S-774 的力量来自价格相位」在新快照上仍然成立(只报,不判)。
