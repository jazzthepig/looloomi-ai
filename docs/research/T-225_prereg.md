# T-225 预注册 —— 拆开三个混在一起的变量(面板宽度 × 调仓频率 × 符号)

**写于下列任何数字算出之前。** 2026-11-02 12:53 UTC(`date -u`)。作者:lane-c。
判据照抄 S-694 / T-224: **(a)** 年化净超额 > 0 **且** 1,000 次随机对照 ≥ 95 分位(种子 **694**);**(b)** 两段超额都 > 0 —— 但「两段」的口径本卡改掉(见 §6)。

## 1. 为什么返工

T-224 预注册 L15 写的是「**只改面板**」,报告 L160 实际同时改了**面板(24→50)** 与**调仓频率(周→月)**;
同信号同分段日后段 S-694(24 名 / 周频)= **+2.04% / 95 分位**,T-224(前 50 / 月频)= **−1.24% / 39.7 分位**。
两个设定之间还差一个**符号方向**(减半最差档 vs 加倍最差档)从未单独检验过。
因此 T-224 的结论「**任何宽度都不够用**」**没有证据** —— 它把三个变量混在了同一次回放里。

本卡只做一件事:**把三个变量拆开,每个臂只改一个。** 其余(信号、面板规则、成本、面板内权重口径)一律照 T-224。

## 2. 四个臂(基准臂 = T-224 设定,用来验证重构没改数字)

| 臂 | 面板宽度 | 调仓频率 | 变换 | 相对 T-224 改了什么 |
|---|---|---|---|---|
| **D(基准)** | 50 | 月 | 最差档 **× 0.5** | 什么都不改(复算 T-224) |
| **A(臂①)** | 50 | **周** | 最差档 **× 0.5** | 只改**频率**(月→周) |
| **B(臂②)** | **24** | 月 | 最差档 **× 0.5** | 只改**宽度**(50→24) |
| **C(臂③)** | 50 | 月 | 最差档 **× 2.0** | 只改**符号**(减半→加倍) |

- 每臂有**自己的基线**(同面板、同频率的市值加权,只做多、满仓)。
- 变换方式:命中宽宇宙最差五分位的面板成员权重乘以系数 k(0.5 或 2.0),其余按市值比例补满。
- 臂 B 的 24 名用**与臂 A/D/C 完全同一条规则**(调仓日当时市值前 24),**不是** S-694 用的 ① `cap_pit24` 面板
  (那个是日调仓 + 40% 单币上限),这样「宽度」才是唯一变量。
- 臂 C 与 D 的差就是符号:加倍最差档若显著优于基线 ⇒ T-224 的方向反了。

## 3. 面板(照 T-224 §2,只有宽度变)

- **成员**:每个调仓日按**当时市值**取前 N 名(N = 50 或 24)。
  宇宙 = `asset_mcap_daily`(`coingecko_pro_market_chart`,symbol 键)∪ `cg_coin_mcap_daily`(同 source,coin_id 键),
  按 coin_id 去重、同一 coin_id 优先取 `asset_mcap_daily`;只取 `mcap > 0` 且 `price > 0` 的行;
  观测比调仓日早超过 **10 天**(`STALE_DAYS`)的候选**当期剔除**。
- **剔除**:稳定币 / 包裹与质押凭证 / 代币化真实世界债权与贵金属,名单照 `migrations/2026-10-30_core_pit.sql` 的
  `core_pit_excluded()`,再加 coin_id 关键词兜底(照 T-224 脚本里的名单,一字不改)。
- **含死币**:成员只由调仓日那天的市值决定,之后不因死亡 / 掉出前 N 而剔除。
- **权重**:市值加权(用选成员那天的市值),单币不设上限。

## 4. 调仓频率

- **月频(D / B / C)**:每个月**第一个 BTC 有价的日子**为调仓日(照 T-224)。
- **周频(A)**:每个 ISO 周**第一个 BTC 有价的日子**为调仓日。
- 持有到下一个调仓日收盘;最后一期的退出日 = 2026-09-30 及之前最后一个有数日子。
- 期间:2023-01-01 → 2026-09-30(照 T-224,不动)。
- **年化换算**:月频 ×12,周频 ×52(几何年化,`ann_geo`)。

## 5. 信号(照 T-224 / S-694 / S-691,一字不改)

- **宇宙**:`deriv_metrics_daily` 的名字,过 S-689 映射校验(隐含价 `oi_value_close / oi_close`,重叠日 ≥ 30 且
  中位 |CG 价 × 倍数 / 隐含价 − 1| ≤ 5%)、当天 CG 市值 ≥ 2,000 万、当天 `oi_close > 0` 且 `oi_value_close > 0`、
  五个因子都有定义、当天 **≥ 30 名**。
- **因子**(S-691 冻结短名单):F3 = ln(oi_close_d / oi_close_{d−30})(−)· F7 = 主动买卖比 7 天均值(≥5 个有效日)(+)·
  F8 = 30 天相对 BTC 动量(−)· F9 = 7 天相对 BTC 动量(−)· F11 = 30 天日对数收益样本标准差(≥25 个收益)(−)。
- **合成**:comp = 五个 `percent_rank(符号 × 因子)` 的平均;**最差五分之一 = 宽宇宙 ntile(5) 的第 1 档**。
- 面板成员没有合成值 ⇒ **不倾斜**(照 S-694「没有合成值的名字不动」)。

## 6. 分段:牛 / 熊(本卡改口径,不照抄日历分段)

- **牛熊标记**:`state_daily`(entity = `panel`,feature = `mom_200`)在**调仓日当天**的值。
  **牛 = 值 > 0;熊 = 值 ≤ 0**(点时点:只用当日那一行,不用之后的信息)。
- **两段** = 牛段调仓期集合 与 熊段调仓期集合(调仓日归段,整期算在该段里)。
- 判据 (b) = **牛段净超额 > 0 且 熊段净超额 > 0**。
- 旧的日历切点(≤ 2024-11-30 / 之后)降级为**副指标**,只报不判(便于和 S-694 / T-224 对照)。

## 7. 死币规则(本卡改时点口径)

- 每个调仓日**只用当日及以前的 `last_obs`**:进入价 = 调仓日当天或之前最近一次有价(早于调仓日超过 10 天的候选当期剔除)。
- **不写销**:序列结束(死币)之后**按最后一个有效价持有到底**(期内收益 0),不再把价格归零记 −100%。
- **coin_id 连续性写成硬断言**:某面板成员在持有期内出现 **> 10 天的内部断点**(相邻两次观测之间的空洞)
  ⇒ **报错中止**(数据管道有洞,不许当成死币默默吃掉)。
  **预注册的应急处理**:若断言真的触发,则该 coin_id **自触发日之后**从面板中剔除(此前的面板不动),计数写进报告,重跑。

## 8. 判据(照抄 S-694 / T-224,每臂各判一次)

- **(a)** 年化净超额(变换臂 − 基线,**净**,10 bp 成本)> 0,**且**在随机对照里 ≥ **95 分位**。
  随机对照 = 每个调仓日从**有合成值的面板名字**里随机挑**同样个数**、施加**同一个变换**(0.5 或 2.0),
  再跑同一条臂,**1,000 次**,**种子 694**;毛口径与净口径各报一次分位。
- **(b)** 牛段与熊段的净超额(几何年化)都 > 0。
- 两条都过 ⇒ 该臂过;**只报不判**的副指标:等权口径、面板内 ntile 口径、最差档后 30 天相对面板的表现、
  落在最差档的成员数、死币事件、深跌成员、归因(最差 / 最好调仓期)。

## 9. 成本与结论口径

- 成本:10 bp × Σ|目标权重 − 上期漂移后权重|(两边都扣)。
- **过 ⇒ 那个被单独改掉的变量就是原因**:
  - A 过 ⇒ T-224 的失败是**调仓频率**(月频)造成的;
  - B 过 ⇒ 是**面板宽度**(50 名)造成的;
  - C 过 ⇒ **信号方向反了**(该加倍最差档,不该减半);
  - 四臂全不过 ⇒ 「**月频前 50 设定下**「躲开」不够用」——T-224 报告 L131 与预注册 L58 的
    「任何宽度都不够用」**降级**为「月频前 50 设定下不够用」;「信息被大币吃掉」**撤下**(它只在 24 名面板上被检验过)。
