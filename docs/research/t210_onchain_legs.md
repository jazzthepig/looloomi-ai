## 0. 口径偏差（先说清楚，因为它改了卡上的一个字）

卡上写的跟踪误差口径是「用 Supabase `world50_onchain_forms` 的价格快照对 `ohlcv_daily` eodhd 的 XAUUSD / SPY 同日收盘算」。**这条不可执行**，两个原因都实测过：

1. **该表对 publishable key 无读权限。** `GET /rest/v1/world50_onchain_forms` → `42501 permission denied for table world50_onchain_forms`。原因见 `scripts/supabase_t098_world50.sql:37` —— `revoke all on public.world50_onchain_forms from anon, authenticated;`，只授 service_role。同类的 `tokenization_tilt_daily`（PostgREST 提示的真实价格表名）也是 `42501`。`tokenized_market_data` 这个表名在库里不存在（404）。
2. **那张表里没有价格。** `world50_onchain_forms` 是**形式清单元数据**（`as_of, token_id, key, symbol, name, category, issuer, match_rule`），价格另在 `tokenized_market_data` / `tokenization_tilt_daily`。

**本轮实际口径（替代，并已做敏感性）**：

- 代币价格 = 公开交易所/链上日线收盘：PAXG / XAUT / USDC = Binance 现货日 K 线收盘；USDY = Bybit 现货日 K 线收盘；SPYX (xStocks) 与 SPY (Ondo) = GeckoTerminal 池日线 OHLCV（Solana / Ethereum）。

### 1.4 T-213 重报：跟踪误差（四列 × 两窗口）+ 零信号对照 + 不代币化基线

**为什么重报**：T-210 的跟踪误差只有「逐日、offset 0、各自窗口」一个口径。逐日口径把「代币 24/7 收市」与「基准工作日收市」的日界错位算进了 TE，而上一轮代码里的 `if best_off := …` 判假又让 5 日块检验从未执行（见文首更正记录第 3 条）。本节按卡上的口径重报。

**口径**

- 对齐：代币与基准同一段日历窗口 `[d-1 → d]`（offset 0）。代币 UTC 日线收市 00:00 UTC，基准在美国收市结算 ⇒ 同窗口内仍有约 21 小时日界错位（这是口径的一部分，不是被消掉的误差）。
- **逐日 TE**（年化）= `std(r_tok − r_bench) · sqrt(365)`。
- **5 日不重叠块 TE**（年化）= `std(块差) · sqrt(365/5)`，块 = 连续 5 个成对日收益复合，从第一对开始切、不丢头部；四条腿共用同一组块边界 ⇒ 腿与腿可比。
- **【T-215 更正】本节的 5 日块单点 = 块起点 offset_0 那一格，块起点本身是任意的**（可挪 0..4 位），**单点量级已被 §1.7 作废**：权威口径是**基准 ISO 自然周块**，5 种块起点只报区间；代币序列也改成**固定日期窗口**（原先是滚动 `limit=400`，同码两天不同数）。本节保留 T-213 的原样数字，作为**历史口径的存档**，读时请以 §1.7 为准。
- **累计 price_ratio** = 代币价 / 基准价 的累计变化（%）。
- **波动比** = 代币年化波动 / 基准年化波动。

- **公共窗口** = 四条腿与基准的公共区间：2026-04-30 → 2026-10-28；**各自全窗口** = 每条腿自身可得的完整历史（PAXG 自 2025-09-25，XAUT 自 2026-03-26，SPYX 自 2026-04-30，Ondo SPY 自 2026-04-25）。

### 1.7 T-215 重报：块对齐敏感性 + 固定日期窗口（权威口径）

**为什么重报**：T-213 的头条有两个不稳定源 —— ①「5 日不重叠块」的块起点是任意的（从第 k 行开始切，k = 0..4），而头条只报了 offset_0；② 代币序列用 Binance `limit=400` 的**滚动**窗口取（起点每天前移一天）⇒ 同代码两天跑出不同数。**本节把口径钉死，并给出敏感性区间。**

**口径（T-215 权威）**

- **固定日期窗口**（写死，不是滚动）：代币 2025-09-01 → 2026-10-28；基准 2024-08-01 → 2026-10-28；公共窗口 2026-04-30 → 2026-10-28。
- **块起点钉在基准 ISO 自然周**：同一 ISO 周内（周一~周五）的逐日收益复合成一块，整周不足 4 天则弃；块 TE（年化）= std(块差) · sqrt(52)。
- **行集两套都报**：`canonical` = 公共日期 ∩ 窗口 ∩ 周一~周五 ∩ **日历相邻（gap==1）**；`legacy` = T-213 原行集（保留周五→周一的 gap==3 对）。
- **敏感性**：同一行集下，5 日不重叠块的起点挪 0..4 位，报**区间**（不报单点）。

## 3. 风险

1. **赎回通道在量级外。** PAXG 需 430 枚（≈$1.73M）；OUSG 即时申赎需 $5,000 起且需 QAF 准入；xStocks 赎回走 Backed 另收费；Ondo 赎回需过发行方 KYC 且发行方保留拒赎权。⇒ **$500–$50k 的腿，退出=二级卖出**。T25 若把腿当可赎回资产设计，会在第一次需要流动性时才发现通道不存在。
2. **同名假币泛滥。** dexscreener 上带 "PAXG" 名的池子横跨 $0.00012 到 $5,007 的价格区间、合约地址各不相同 —— 绝大多数是克隆盘。**执行必须走合约地址白名单**（本报告 §2 各表已列出官方地址）。买错地址在链上不可追回。
3. **跨链深度差很大。** USDY：Solana 池 $2.92M vs Arbitrum 池 $41.70（5 个数量级）；代币化 SPY：SPYX 在 Solana 侧 $2.11M vs Ondo 在 Ethereum 侧 **$81.2K**（约 1.4 个数量级，且 **$50k 名义额仍占 Ondo 池深的 61.6%**）。⇒ **链的选择不是偏好问题，是可执行性问题**；同名资产在不同链上根本不是一个可交易性资产。
4. **跟踪误差是这条腿的成本项 —— 但 T-215 把口径钉死后，量级只能读区间。** T-210 引用的 TE（黄金腿 PAXG 6.86% / XAUT 4.53%、股票腿 SPYX 7.52%）是**逐日**口径，含「代币 24/7 收市 vs 基准工作日收市」的日界错位；T-213 的 5 日块单点数则**对块起点敏感**（挪 0..4 位，同一行集的 TE 变 2–3 倍，见 §1.7 表 E）。**T-215 权威口径 = 基准 ISO 自然周块 + 固定日期窗口**（§1.7）：黄金腿 PAXG **1.637%** / XAUT **1.570%**，不代币化的 GLD **1.934%** ⇒ 代币化黄金腿的跟踪成本**方向上不高于**不代币化（5 种块起点下也是 5/5 代币化更紧），**量级不报单点**；股票腿 SPYX **2.237%**、Ondo SPY **6.120%**，对照不代币化基线 SPY(ETF) vs SPX(指数) **0.783%** ⇒ 股票腿的代币化跟踪成本**方向上明显更高**，量级随块起点变（SPYX 3.757–6.385%、Ondo 13.740–17.835%）。对 T25 的含义：月度调仓下，**股票腿的跟踪偏离会吃掉 alpha**；黄金腿的 TE 在块口径下不足以单独立项。**逐日错位仍是执行时点风险**（操作层面）—— 注意这与被撤回的 §4 探索 2（「错位本身可能是可交易的时序源」）不是一回事，后者已列入 §1.6 追加撤回清单。
5. **费用主导而非滑点主导。** $50k 在 Binance 上滑点只有 0.9–1.2 bps，但 Kraken Tier1 现货 taker 是 0.40%（实测自抓 2026-10-29 09:4x UTC）—— **差 30 倍以上**。选错执行场所比选错代币更贵。
6. **发行人单方裁量。** Ondo（SPY/USDY/OUSG）保留单方拒赎权与「酌情判定是否违规」的权利；PAXG 侧 Paxos 亦可拒绝对 verified Customer 兑换/赎回。⇒ 这类腿的「可赎回」是有条件的，不是权利。
7. **香港口径的三个缺口（本轮未核实，不是「没问题」）**：
   - **SFC 持牌虚拟资产交易平台名单本轮未取到**。已探测并留证（`docs/research/t210_sfc_probe.py` → `docs/research/t210_sfc.json`）：名单页 `apps.sfc.hk/edistributionWeb/gateway/EN/va-sfc-list/` 是 JS 应用，正文只抓到 14 字符；探测 4 个候选 API 路径全 404；`main.41ff7da8.chunk.js` 里公开的 API 端点只有 circular / consultation / news / intermediaries-licensing，**不含 VA 持牌名单端点**。⇒ **我们在香港能合法用哪些交易所/平台做这几条腿，本报告没有回答** —— 这一项要么由人查 SFC 名单，要么走 Jazz 拍板。
   - Ondo 资格页按辖区列门槛，**香港对应的 Professional/Qualified Investor 具体标准本轮未定位到**。
   - 香港居民在 Binance / Kraken / OKX 的准入状态未逐一核实（Kraken 费率与 xStocks 页有 jurisdiction 免责语，但那是免责声明不是准入结论）。
   ⇒ **在补上这三点之前，本报告的「香港可执行」结论只对 CEX 层成立，对发行人层（Ondo 申购、Backed 赎回）不成立。**
8. **USDC 作为底仓的隐藏成本。** Circle 的 Blocked Addresses 与冻结权是真实存在的对手方风险；USDC 相对现金的 carry 只有 0.147%/yr，但它是唯一在四家所都稳定 0.05 bps 滑点的资产 —— 这个「便宜」买的是可用性。

## 4. 还看到了什么（探索性）

> 以下每条都是**本轮数据里的意外发现**，不是已验证的结论。都需要**另立预注册、在新数据上过零信号对照**才能进决策。

1. **同一条「代币化 SPY」腿，两家差距在二级流动性而非合规。** Ondo SPY TE_ann 19.15% / drift −11.67%/yr vs xStocks SPYX 7.52% / +1.019%/yr，corr 0.527 vs 0.88。**T-213 补测**：这个 TE 差在逐日与 5 日块两种口径下都过零信号对照（分位 0.000 / 0.000）⇒ **差距可读**，不只是逐日伪影。若某天 Ondo 的二级深度追上（ETH 池从 **$81.2K** 涨到百万级），这条腿可能反转 —— 值得预注册一个「按二级深度分层」的假设来测。
2. **【T-215 撤回】TE 的对齐口径极度敏感 —— 前半句成立，后半句（「错位本身可能是可交易的时序源」）撤。** **成立的部分**：块起点挪 0..4 位，同一行集的 TE 变 2–3 倍（§1.7 表 E）；逐日口径下相关系数掉到 ~0 ⇒ **任何用日收盘算 TE 的方法都必须先声明对齐口径**。**撤回的部分**：「这也提示『代币 24/7 / 基准工作日』的错位本身可能是一个可交易的时序源」—— 本轮**没有做任何小时级对齐检验**，也没有零信号对照支撑；它是从口径敏感性里直接跳出来的猜想。⇒ 列入 §1.6 追加撤回清单；要复活它，需要另立预注册、拿小时级数据、过零信号对照。
3. **用 USDC 直接买同一个代币，$50k 贵 28 倍。** Binance `PAXGUSDC` 进场 32.61 bps vs `PAXGUSDT` 1.15 bps；`XAUTUSDC` 9.03 vs `XAUTUSDT` 0.92。直觉上「用我已有的 USDC 买」省了一次换汇，实际是把点差让渡给 USDC 簿子。
4. **USDY 的 carry 会被调仓吃掉。** carry 3.489%/yr，往回成交成本 4.28–6.63 bps ⇒ 26 次调仓吃光一年 carry。现金腿的持有期决定它值不值，而不是 carry 本身。
5. **同一代币跨链的「跟踪质量」可能差一个数量级。** 同一 USDY，Solana 有 399 天日线与 $2.92M 池，Arbitrum 有 $41.7 池 —— 但跟踪误差是**价格序列的性质**，不是池深度的性质。若某条腿只在某条链上有可交易的深度，那条链就是那条腿的「唯一现实」。这条值得单独预注册。
6. **偏离卡上口径的副作用。** 因为 `world50_onchain_forms` 不可读，我们用交易所日线代替链上价格快照 —— 交易所日线包含交易所自身的价差/流动性结构。若要给出「纯链上」的 TE，需要另建通道（见 §0）。
7. **【T-215 改写】代币化跟踪成本的差在两条腿上的方向不同，但量级只报区间。** 权威口径（ISO 自然周块 + 固定窗口，公共窗口 2026-04-30 → 2026-10-28）：黄金腿 GLD **1.934%** vs PAXG **1.637%** / XAUT **1.570%**（代币化**不高于**不代币化；5 种块起点下 5/5 更紧），股票腿 SPYX **2.237%** / Ondo **6.120%** vs 不代币化基线 SPY(ETF) vs SPX(指数) **0.783%**（代币化**明显更高**；块起点区间 SPYX 3.757–6.385%、Ondo 13.740–17.835%）。⇒ 「要不要用代币化这条腿」在**黄金上没有成本差、在股票上有大成本差** —— 这是**方向性**结论；T-213 的单点量级（+2.785 / +11.322 pp）已作废，区间见 §1.7 表 E。值得预注册一个「按底层资产类别分层」的假设，在更长的样本上复测。
