## 2. 口径实现(都可核)

- **源**:直接取表内现成的 `q_doi7 / q_taker7 / q_turn / q_mom7`,s = 2q − 1(预注册写的就是「居中百分位 2q − 1」,没有自己重算截面百分位)。

- **源缺值的币**:不进该源的 IC 样本(源没定义不能说「自己没动」),在场里以 s = 0 参与扩散。
- **k = 5 / 20**:用 k = 20 的图截断(排序取前 k,与直接建图等价)。**x30**:同口径,NW 用滞后 4(x7 滞后 1)。

- **NW t**:用仓库既有 `src/research/narrative/activation_z_pit.nw_tstat`(Bartlett 权重;与待收编的 `apparatus.newey_west_t` 同式)。**`apparatus.py` 目前没有 NW 函数**(已请 @seth 收编),本卡**没有另起炉灶**。

## 6. 诚实

- **宇宙是幸存者**:`asset_flow_daily` 有 vec 的币,不是全部上币;水平偏乐观,相对比较受影响小。
- **场是价格做的**:预注册自己写明「可能把『同涨同跌』的反射带回来 —— 所以 R1 必须一起报」。R1 的结果正是这一条:反射的扩散比「因」更强。**所以 C1/C3 的 ✅ 里有一部分可能是价格相位在背后**;§4 的资金面场变体(每条弱一半以上)与 S-776(排序力全在价格相位)方向一致。
- 周内打乱只打乱 e 的归属、不打乱目标 ⇒ 零分布回答的是「这个截面排序是不是只是噪声」,不回答「是否已被别的东西解释」。
- **两半**:切点 2024-10-01。C1 两半都弱(+0.0145 / +0.0232);C3 两半几乎一样(+0.0409 / +0.0412);**R1 前半强于后半(+0.0699 / +0.0312)—— 力量在 2024-10 之前**(与 S-774「力量集中在 2024-10 之后」相反,值得记一笔)。
- **只算一次**:不改判据、不换源、不调窗口、不因结果不好重跑口径(修的是汇总层字段映射 bug,见 §7)。

**「结果里还看到了什么」(探索性 —— 需另立预注册、在新数据上过零信号对照):**
1. **C2(主动买)的扩散显著反向**(t −4.13、分位 0.000)—— 若成立,是「主动买入的扩散」本身带反向信息(与 S-726/S-768 的挤压反向同类),不是本卡要测的东西。
2. **R1 反射的扩散比「因」的扩散更强** —— 「因」这条线在本卡上被自己的对照比下去了;S-81 的预言两头都不成立。
3. **x30 两半明显走弱** —— 20 天窗口上「场带动节点」的力量比 7 天弱。
4. **C1/C3 的 IC 量级小(0.019 / 0.041)而零分布极窄(σ ≈ 0.006)** —— 「分位 1.000」来自窄零分布,不是巨大效应(与 S-769 同一种读法)。
