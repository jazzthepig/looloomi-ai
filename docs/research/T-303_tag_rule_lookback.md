# T-303 — S-785「打标签即剔除」回看(只报不判)

> 给 Jazz 拍板用的数:**这条规则在我们自己的 R-v2 回放账本上挡多少票、挡掉的是赚的还是亏的。**
> **本卡不判,只报。** 结论句留给 Jazz。

## 一、S-785 预注册原文(照抄,只此一处)

**写死:** 票 = S-757 同一个生成器(R-v2 规则 r_v2_k2.5_gate200,40% 档,有 R 的成交票),2023-07-26 → 2026-10。
「在标签上」= 开票日 d 之前已有 `events` source = binance、kind = monitoring_tag 含该代号,且之后没有
monitoring_tag_removed(1000 前缀与 S-751 同口径)。两类:① 开票日在标签上 ⇒ 不开;② 持有期间被打上标签 ⇒
次日开盘平(用次日开盘价重算这张票的 R)。报:两类各多少张、原 R 合计、规则下 R 合计、差值;整个账本
2023-07 → 2026-10 的总 R、最大回撤、Calmar 有 / 没有两版;再叠加 S-757 的下架规则一版(两条都在)。
**只报不判。** 票不足 10 张就写「无检出力」。

## 二、名单与口径(数据现读,翻页带 order=,核过总行数)

- `events` source=binance、kind ∈ {monitoring_tag, monitoring_tag_removed}:**27 行**(Content-Range 总数 27 ✓),
  156 个代号出现在标签 / 移除公告里;名单落在 `docs/research/t303_tags.csv`。
- 交叉核对:DB 的 `kind` / `symbols` 与生产解析器(`src/data/market/events.py:monitoring_tag`,标题重解析)
  **零分歧**;唯一一条「解析不出代号」是 2023-07-26 的制度推出公告(本来就没有币名单)。
- 状态机:按 ts 走一遍,打上 ⇒ 在标签上,移除 ⇒ 不在。代号口径同 S-751 的 `is_excluded`:票代号 `1000PEPE`
  与 `PEPE` 同判。
- ① 判在**信号日**(生产语义:计划生成时看名单,与 T-278 主口径一致);② 判在进场日 ≤ 标签日 < 出场日,
  平仓价 = 标签日**之后第一个 bar 的开盘价**,R 按 `(出场价−进场价)/(进场价−止损价) − 0.004×进场价/(进场价−止损价)` 重算
  (与 T-278 的 `apply_rule` 同一函数)。

**① 开票时已在标签上 —— 4 个候选票,原 R 合计 +3.5026(均值 +0.8756,3 胜 1 负):**

| 代号 | 信号日 | 进场 | 出场 | 原 R | 在账本里? |
|---|---|---|---|---|---|
| XEM | 2023-10-30 | 2023-10-31 | 2023-11-22(sma20) | **+0.6013** | 否(候选) |
| XEM | 2024-01-24 | 2024-01-25 | 2024-01-28(止损) | **−1.0158** | **是(账本里唯一一张)** |
| XEM | 2024-11-17 | 2024-11-18 | 2024-12-17(sma20) | **+2.8873** | 否(候选) |
| STX | 2026-08-22 | 2026-08-23 | 2026-09-11(sma20) | **+1.0298** | 否(候选) |

- 规则下:**整张不开** ⇒ 这 4 张的 R 全部归零。账本里真正被挡的只有 XEM 2024-01-24 那一张,**原 R = −1.0158(是亏的)**。
  账本构成变化:挡 1 张、**新增 0 张**(腾出来的名额没有换进别的票)⇒ 总 R 从 110.0372 → 111.053(口径 A)、
  19.4042 → 20.4200(口径 B),差值同为 **+1.0158**。
- **候选层面挡掉的是赚的票(3 胜 1 负,+3.50);成交层面被挡的那一张是亏的(−1.02)。**

**② 持有期间被打上标签 —— 0 张。** 整个 2023-07-26 → 2026-10-14 窗口里,没有任何一张成交票在持有期间
被打上监控标签。规则的全部作用都发生在「开票时已经在标签上」这一端。

**检出力:被挡的成交票 1 张 < 10 ⇒ 「无检出力」。**(与 S-757 的下架规则同一结论形状:这条规则在 R-v2 的
历史账本上是**保险,不是 alpha** —— 代价近零、收益无检出力。)

## 五、敏感性

1. **开票日 = 进场日(台账字面)**:① 4 张 / ② 0 张,规则后总 R 111.053 —— 与主口径**逐位相同**(一天之差不影响)。
2. **口径 A(窗口内独立起账,equity0=630;同一生成器、同一 40% 档)**:无规则 155 张有 R 的成交票 / 总 R
   110.0372 / 总回报 +51.01% / 最大回撤 −21.02% / Calmar 0.6503;只标签 154 张 / 111.053 / +51.55% /
   −20.99% / 0.6574;只下架与无规则**逐位相同**;下架+标签 = 只标签。**规则效应与口径 B 逐位相同(−1 张、+1.0158)。**
   两个口径票数不同(155 vs 67)是账本轨迹不同(入场被挡的约束不同:A 持仓上限挡 301 / 总名义上限挡 141;
   B 全书 2020-07 → 2026-10 合计持仓上限挡 622 / 总名义上限挡 0),**不是规则的差异**。

## 六、诚实与限制

- **只报不判**:本卡不给结论,不给「该不该上」的答案。
- 被剔除的票腾出的名额与本金会改变后续成交 ⇒ 规则版的账本与原账本不是同一批票(本次逐位比较显示:只下架
  两版逐位相同 ⇒ 那条规则确实 0  bites)。
- 票生成器不会因规则重扫信号:被剔除的票所在代号后面若还有信号,仍按原生成器口径参与(与 T-278 同一简化)。
- ② 的次日开盘可能低于止损价 ⇒ 重算 R 用开盘价(跳空止损同路径),不假设止损先成交(本次 ② 为 0 张,未触发)。
- 窗口内独立起账(口径 A)与全书轨迹(口径 B)都给;两者账本级数字不同是正常的(起点净值与占用不同),
  **规则效应两个口径一致**。
- 标签数据只有 27 条公告;S-753 已记的「首批打标签的币不在样本里(推出公告没有币名单)」在本卡同样成立。

## 七、结果里还看到了什么(探索性 —— 需另立预注册、在新数据上过零信号对照)

1. **候选 4 张里 3 张是赚的(+0.60 / +2.89 / +1.03),只有真正成交的那张是亏的(−1.02)。** 样本太小
   (1 张 < 10),**不能当结论**;但方向值得另立预注册:「打标签即剔除」在**候选层**可能砍掉好票
   (XEM 2024-11-17 那张 +2.89 没进账本,不是被规则救下的,是它本来就没成交)。
2. **4 个候选全是 XEM(3)+ STX(1)** —— 与 S-753 记的「当前标签名单与五本多头账零交集」同形:
   R-v2 的候选池和监控标签池几乎不相交,这条规则的覆盖面本身就很窄。
3. **持有期间被打标签 = 0 张** —— 这条规则「前移」的收益点(持仓中被打标签就平)在历史上**一次都没触发过**;
   真正会发生的只有「开票时已经在标签上」这一端(1 张)。
4. 两条规则(下架 + 标签)在 R-v2 账本上**互相不重叠**:下架挡 0 张、标签挡 1 张,合起来的净效果 = 只标签。
