# T-227 —「开闸」回测:Binance 现货上币之后 30 / 90 天相对宇宙

**状态:预注册闸门未过 ⇒ 预注册裁决不下;下面是覆盖审计 + 一个明确标注为探索性的替代口径。**
脚本:`docs/research/T-227_listing_event.py`(只读 SELECT;零分布/对照只用 `src/data/evaluation/apparatus.py`)。
数据截止 2026-11-03。

---

## 1. 预注册段(S-708,写死,只算一次)

**闸门**:先核 `select count(*) from events where source='binance' and kind='listing'` ≥ 2,000。
不够 ⇒ 只回一行等下一轮。

**判据**(全部写死):
1. **事件**:`events` 表 `kind='listing'`、`payload.scope='spot'`(Alpha / Margin / Futures 分开报,不混);
   `symbols` 非空;每个 `(symbol, ts)` 一个事件;同一符号 90 天内重复公告只留第一条。
2. **价格**:`ohlcv_daily`,源优先级 `binance_hist` → `binance_hist_ffill` → `coingecko_pro_ohlc`;
   每个符号写清用了哪个源、没价格的符号个数。事件日 d = 公告 UTC 日;信号日派生量**挪一天**再判一次(S-665)。
3. **主口径**:上币后 d+1 → d+30 的收益 **减去**同期等权宇宙(cis 加密宇宙 25 名)的收益。
   ✅「开闸是高位」= 中位数 < 0 **且** 在随机日期对照(同一符号、随机 d,1,000 次,种子 708)里 ≤ 5 分位。
4. **副口径**:d+1 → d+90;按时代分段(2017–2020 / 2021–2022 / 2023–2026)各自报中位数与分位;
   再报 d−30 → d(公告前涨幅)—— 公告前已涨、公告后跌 =「密集营销时是高位」的形状。
5. **不做**:交易规则、参数扫描、「可以做空」的判断。

**试验计数**:闸门 1 次;主口径 1 次;副口径 1 次;时代分段 3 次;对照抽样 1,000 次(种子 708)。
不做参数扫描 ⇒ 没有多重比较问题。

## 2. 闸门结果:GATE FAIL(107 / 2,000)

`events` 里 `source='binance' & kind='listing'` = **107 行**(所有 source 的 listing 行也只有 107 ⇒ 只有 Binance 有上币事件)。
`source='binance'` 全表 **440 行**,`ts` 覆盖 **2024-12-11 → 2026-11-02**(22 个月),`recorded_at` 全是 2026-11-02
⇒ 回填是**一次性**的,深度被 Binance 公告 API 的分页封顶,不是按年份取全。**等下一轮不会变到 2,000** ——
要么做更深的分页回填,要么改用下面的替代事件源。

**⇒ 预注册裁决不下**(卡上写死的闸门没过)。

## 3. 为什么预注册臂跑不动(覆盖审计)

107 行 → scope:spot 86 / margin 21;展开 `symbols` + 90 天去重后:**spot 69 / margin 9** 个事件,70 个不同符号。
其中 **只有 9 个符号在 `ohlcv_daily` 里有价**(AVGO 2975、CHIP 15、HYPE 901、MEGA 15、META 5726、
QNT 3730、QQQ 5726、STX 5990、AERO 15),其余 61 个**零行**。
而且 listing 行里大量是**代币化股票**(AVGO / MSFTB / QQQB / BRKBB / PLTRB / INTCB…),不是加密上币。

⇒ 预注册臂实际可算:**spot 3 个、margin 1 个**。N=3 不构成中位数检验,也没有对照分位。**报告到此为止,不下结论。**

## 4. 替代事件源(探索性 —— 需另立预注册、在新数据上过零信号对照)

`events` 表不可用 ⇒ 改用**派生上币日**:`ohlcv_daily` 里 `source='binance_hist'` 的**每个符号的首次出现日**
= 该交易对在 Binance 的第一根日线 = 上币日。

**验证(用原始数据核,不靠记忆)**:BTC 2017-08-17、ETH 2017-08-17、BNB 2017-11-06、**LTC 2017-12-13**、
NEO 2017-11-20、QTUM 2018-03-19、**ADA 2018-04-17**、**XRP 2018-05-31**、**IOTA 2018-05-31** —— 与 Binance
实际挂牌日逐条对上(BTC/ETH 的 08-17 是 Binance API 的最早日线)。

**同时排除一个看似可用、实则不可用的源**:`assets.listed_at` **不是** Binance 上币日,是 CoinGecko 首次有数据的日期
(SOL = 2020-04-11,早于 SOL 上线 ⇒ 不可能是 Binance 挂牌日)。用它会把「上币日」换成「数据起点」。

样本:**262 个加密符号、445,866 行**;上币日按年:2017:5 / 2018:12 / 2019:42 / 2020:53 / 2021:54 /
2022:26 / 2023:22 / 2024:17 / 2025:31(2026:0)。按预注册的时代分段:
**2017–2020 = 112、2021–2022 = 80、2023–2026 = 70**。

## 5. 实测数字(探索性口径)

**B1 臂:固定 25 名篮(预注册的基准)** — n = 262 / 262 可算
- 主口径 d+1 → d+30 的**相对收益中位数 = −22.35%**
- 随机日期对照(1,000 次,种子 708)**分位 = 0.000**
- 绝对收益中位数 −2.809%(spot 臂)/ −2.809%(margin 臂)

**这个 −22.35% 不能直接当结论用,原因要写清楚**:固定 25 名篮是**今天**的篮子,2017–2018 年的事件里
只有 **2–5 个**成分有价(实测 nb: BTC/ETH nb=2,BNB/NEO/LTC nb=3,QTUM/ADA nb=4,XRP/IOTA/XLM nb=5),
早期加密的 ±200% 波动全落在 2–5 个名字上 ⇒ 相对值被放大。同期逐条(相对 25 名篮):
BTC +2.81%、ETH −2.81%、BNB −17.80%、NEO −28.93%、**LTC −238.73%**(篮 +224% vs LTC −14.4%)、
QTUM −20.71%、ADA −13.01%、XRP −2.38%、IOTA −28.26%、XLM −13.87%。
⇒ 「分位 0.000」这一条**同时**包含「开闸是高位」和「早期基准退化」两件事,本轮分不开。

**本轮没跑出来的东西(诚实清单)**:
- **时代分段的中位数与分位**:脚本已实现(每个臂都出 `eras_fwd30`),本轮被上下文限额打断,**没有数字**。
- **PIT 时点市场篮(当时有价的所有加密符号等权)**:脚本已实现(`MarketBasket`,带与
  `apparatus.long_return` 的逐位自检),本轮**没跑**。这是拆掉「早期基准退化」的关键一臂。
- **nb≥20 子集(固定篮基本填满的事件)**:脚本已实现,**没跑**。
- **公告前 d−30 → d 的涨幅**:脚本已实现(用上币**之前**就有价的 `coingecko_pro_ohlc` / ffill 序列),
  本轮**没跑**;另外 CoinGecko 每股只有 ~433 天历史,只对近一年上币的标的够用。

## 6. 结论(截至本轮)

1. **预注册口径没有得到裁决**:闸门 107 < 2,000,预注册臂只有 3 / 1 个可算事件。
2. **派生上币日(B 臂)是可用的替代事件源**:262 个上币日,抽查 9 个与 Binance 实际挂牌日逐条吻合。
3. **B1 臂的方向**:上币后 30 天相对固定篮的中位数 −22.35%,对照分位 0.000 —— **但基准在早期退化,
   这一条现在只能算「方向提示」,不能当结论**。下一步跑 PIT 市场篮 + nb≥20 子集即可分辨。
4. **事件库要按年回填**(`events` 的 listing 只有 22 个月,且以代币化股票为主),否则 2,000 的闸门永远达不到。
