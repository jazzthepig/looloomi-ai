## §6 ⚠️ 未解的口径矛盾(判定表暂不可作准入依据)

规则 A 候选自身全日历收益 H30 窗口2 = **−44.54%**;同一条序列叠到账户上,账户年化 **35.7% → 48.28%**,即贡献 **+12.53pp**。
算术上不可能:w = 0.2254 ⇒ 候选累计 −44.54% ⇒ 对账户的拖累约 −10%,账户年化只会**低于** 35.7%,不会升到 48.28%。
两处数字必有一处口径不对:把 `on_acct` 从「工作日直取」改成「工作日区间复利聚合」之后,(i)(ii)(iii) 的数**逐位未变** ⇒ 这一处修动没有改变账户侧口径。
诊断字段已内置(`diag_srs_n / diag_acct_n / diag_srs_in_A0_A1 / diag_on_agg_cum_pct / diag_on_reindex_cum_pct / diag_cum_srs_A0_A1_pct`),
下一轮跑一次读 `t360_run.log` 即可定位。**在此之前不写准入/不准入。**

另:零分布中位数 +11.13pp 与实测 +12.53pp 只差 1.4pp,p_upper 0.005 主要来自**分布很宽**(200 次平移的中位数几乎等于实测值)——
这个 p 值的说服力也要在口径定位后重估。

## §7 探索性(需另立预注册、在新数据上过零信号对照)

1. **逐票有效应、组合没有**:规则 A 逐票相对 BTC 收益 H30 **+25.24%**(胜率 0.799)、H90 +60.24%(0.84)、H7 +6.23%(0.66)——
   与 S-569 原文的事件级效应一致(30 日 −16.4、90 日 −38.7、跑输比例 0.81);但**账面口径(等权固定毛敞口)为负**。
   ⇒ S-569 的效应是**事件级相对收益**,不是组合级可交易收益;两者之间的差(等权 + 固定毛敞口 + 同期多票重叠)就是它消失的地方。
2. **持有期越长、与账户越同向**:H7 → H90,corr(账户) 0.267 → 0.338 ⇒ 长度带来账户同向性,(i) 在 H90 因此越界。
3. **规则 B 尺寸不可行**是结构性的:BTC/ETH 级反转的波动太小,作为 10% 风险贡献来源需要 >1 倍资金 ⇒ 任何「主流暴跌做多」的引擎在账户口径下先天不合格。
4. **零分布中位数 ≈ 实测值**:口径修好后要重新看 p 值是否还有分辨力(现在 p=0.005 主要来自分布宽)。
