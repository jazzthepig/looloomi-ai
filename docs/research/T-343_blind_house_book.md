## 4. 判据(S-815 写死,只判 L3 与 L4)

**L3**
- **(i) 全窗口最大回撤不深于 −25%** → **❌ 不过**:L3 = **−34.73%**,深了 9.73pp。
- **(ii) CAGR ≥ L1** → **✅ 过**:L3 = **+21.54%** ≥ L1 = **+17.75%**(+3.79pp)。
- **(iii) 逐年收益都 ≥ L1 同年 − 1pp** → 逐条判定见 `t343_results.json → judgement.L3.iii_yearly.per_year`
  (同一条 note:本报告落笔时上下文守卫触发,未能把逐年数抄进正文;**判据总结果已在内核里算出并落库**)。

**L4**
- **(i) 全窗口最大回撤不深于 −25%** → **❌ 不过**:L4 = **−43.26%**,深了 18.26pp。

⇒ **L3 不过、L4 不过。**

### 是哪个开关把哪一年 / 回撤弄坏的

- **回撤**:链子很清楚 —— **L0 基线本身就是 −25.91%,已经越线 0.91pp**;真正把回撤打坏的是
  **R-v2 叠加**(L0→L1 回撤 −12.93pp),**RBv2 权重反而修回 3.99pp**(L1→L2),
  **现金计息对回撤中性**(+0.12pp)。所以「回撤不深于 −25%」这一条,不是现金的问题,是叠加的问题。
- **f 提到 1.0%(L4)**:回撤再恶化 8.53pp、收益掉 50.14pp。**原因不是「风险放大所以亏更多」,是 40% 名义上限开始咬合**:
  f 0.5% 时被名义上限挡掉 114 张,f 1.0% 时挡掉 **702 张**,进场票从 208 张掉到 **175 张**,
  叠加自己的总收益从 +63.50% 掉到 +49.07%、mDD 从 −25.71% 掉到 −42.47%。
  **f★ 这一档在 40% 名义上限下是负向的**,不是「同样的票放大一倍」。
- **逐年**:逐条判定已落库(见上)。

## 5. 结果之外看到的(探索性 —— 需另立预注册、在新数据上过零信号对照)

1. **叠加是这本日历里最大的收益来源,也几乎全部的额外回撤来源。** L0→L1:总收益 +74.20pp、回撤 −12.93pp。
   这正是「已经过了检验的部件拼在一起」的第一课:合并不是加法。
2. **「每票风险 0.5% → 1.0%」这条常规加杠杆路径,在有 40% 名义上限的簿子上是反向的**(§4)。
   常规直觉(风险翻倍 ⇒ 收益近翻倍 ⇒ 回撤可控)在**名额 + 名义双重封顶**下不成立。
3. **加密腿 X1V → 直接持 ① 是净负**(−3.65pp 收益、−6.07pp 回撤)。在这个窗口里 X1V 的空仓机制**降了回撤**,
   代价是收益。**「β 捕获的代价与回报」的方向和直觉相反**:少拿 β 反而回撤更小。
4. **house book 相对 ① 自己的超额**:+179.50pp 总收益 / +24.39pp/年,且回撤从 −77.73% 收到 −40.80%。
   分成两笔:RBv2 权重 + R-v2 叠加 + 现金计息。
5. **现金计息值 +5.08pp / +0.46pp 每年**(2023-02-10 起的 1359 个日历日,平均年化 4.40%)——
   对 20% 的闲置现金,这个数是对的量级;**它不是回撤的来源也不是解药**。
