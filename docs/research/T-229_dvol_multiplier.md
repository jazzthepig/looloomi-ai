# T-229 —— DVOL(BTC 隐含波动率指数)一年分位 ≥ 0.80 时把敞口降到 0.5 的回放

**卡**:T-229(lane-c) · **预注册**:`REFUTATION_LEDGER.md` 的 S-710(Seth,2026-11-03 15:55 UTC) · **判定**:❌ 三条判据都没过
**区间**:2022-03-01 → 2026-10-31 · **脚本**:`docs/research/t229_dvol.py` · **原始结果**:`docs/research/t229_results.json`

## 0. 一句话

DVOL 一年分位 ≥ 0.80 时把敞口降到 0.5 的规则,在 2022-03 → 2026-10 把最大回撤从 −66.73% 只压到 −63.96%(相对浅了 4.15%,判据要求 ≥ 15%),规则自己的 Calmar 0.166 落在「随机降仓」零分布的 **30.5 分位**(要求 > 95 分位),两半里第二半的 Calmar 反而低于持有 —— **三条判据全不过,这条减仓规则不成立**。

---

## 1. 预注册口径(照抄 S-710,写于结果之前)

**规则 R(写死,不扫)。** 每日收盘后算 DVOL(BTC)在**过去 365 日**里的分位;分位 ≥ 0.80 ⇒ 次日敞口 0.5,直到分位 < 0.60 恢复 1.0(滞回);其余 1.0。主资产 BTC(现货日线 `binance_hist`),2022-03-01 → 2026-10-31(前 365 日做分位窗口),成本 10bp × |Δ敞口|。

**判据(照抄 S-692,三条全过才 ✅)。**
- (a) 最大回撤比持有浅至少 15%(相对);
- (b) Calmar 高于随机降仓分布的 95 分位 —— 随机对照 = 同样的「在 0.5 的总天数」在时间轴上随机分段(段长分布照规则实际产生的段长抽),1,000 次,种子 710,走 `apparatus.py`;
- (c) 两半(≤ 2024-06-30 / 之后)各自的 Calmar 都 ≥ 持有。

**副列(只报,不判)。** 分位阈值 0.70 / 0.90 各一列;ETH 同规则一列;DVOL 低分位(≤ 0.20)作为「加回」信号的对称臂一列。

**诚实(预注册原文)。** 2022-03 起只有一个完整的熊市与一个完整的牛市;DVOL 高分位与价格下跌同时发生是机制的一部分(IV 跟着实现波动走),所以 (a) 容易过、(b) 的随机对照才是判据。

## 3. 实现口径(判据怎么算的)

| 项 | 口径 |
|---|---|
| 分位 | 过去 365 日(**不含当日**)窗口内 DVOL 观测值里 ≤ 当日值的比例;分母 = 窗口内**实际观测数**(区间头约 300 天窗口未满,DVOL 自 2021-03-24 起) |
| 状态机 | 收盘后算分位;≥ 触发阈值 ⇒ 次日 0.5;< 恢复阈值 ⇒ 次日 1.0;其余保持。状态机自 2021-03-24(DVOL 首日)起连续运行,区间首日继承之前的状态(2022-03-01 是满仓) |
| 敞口作用 | 收盘信号 ⇒ **次日**生效:敞口 s[d] 乘 d 的下一根日收益;换仓成本 10bp × |Δs| 记在换仓当日。全程 34 次换仓 = 合计 **17bp** |
| 价格 | `ohlcv_daily`(`symbol=BTC, source=binance_hist`)的 `close`;区间首日收益用区间前一日(2022-02-28)收盘 |
| 指标 | 总收益 = 净值复利;年化 = (1+总收益)^(365/n) − 1;最大回撤 = 净值对历史峰值;Calmar = 年化 / |最大回撤| |
| 随机对照 | 把规则实际产生的 35 个段(敞口 + 段长)**整体随机重排** ⇒ 同样的 0.5 总天数(261 天)、同样的段长分布;1,000 次,种子 710;零分布与分位用 `src/data/evaluation/apparatus.py` 的 `null_distribution` / `percentile_of` |

**不扫参数**:主臂只算一次(0.80 / 0.60),副列按预注册各算一次(阈值 0.70、0.90 的恢复阈值按同一滞回宽度取 0.50、0.70)。

## 5. 结果里还看到了什么(探索性 —— 需另立预注册、在新数据上过零信号对照)

1. **减仓减在反弹之前。** 减仓日之后的前瞻收益均值都高于满仓日:次日 +0.164% vs +0.049%,7 日 +0.678% vs +0.483%,30 日 +3.18% vs +2.18%(n:减仓日 261 / 满仓日 1,444)。DVOL 高分位是「已经跌过」的读数,不是「要跌」的读数 —— 与 S-685 的结论同向。
2. **2022 熊市里几乎没起作用。** 两次触发(2022-05-11、2022-11-09)都在崩盘发生之后,减仓改变不了已经发生的回撤,却错过了随后 2022-11-21 起的反弹。
3. **触发滞后 + 一次性触发,导致 0.5 段很少覆盖真正的下跌。** 全区间 261 个减仓日里,最长的 0.5 段是 2026-02-03 → 2026-04-07(64 天),而 2022-11-09 的段只有 8 天。
4. **阈值族是单调的**:0.90 → 0.187,0.80 → 0.166,0.70 → 0.115。看起来不是阈值选错,而是「DVOL 分位」这个输入与后续收益本身负相关。
5. **对称臂(低分位满仓)同样不成立**:+29.54% vs 持有 +79.75%,Calmar 0.101 vs 0.200。说明「DVOL 分位 → 敞口」这条线两头都不通。
