**时点纪律怎么落实的**

- 每天 d,三臂拿到的 `fwd` 都不含「结果还没出完」的历史日:只取 `x + 30 ≤ d`(≈ 1,647 天)。
  融合臂与基率臂用这一份;**原近邻臂另用 `x ≤ d − 31`**(acceptance ① 的「排除最近 31 天」),
  向量取 d 之前 3 天内最近的一天 —— 实测 `market_state_vectors` 逐日齐全,**滞后 0 天 / 1587 天**,
  融合臂的向量滞后也全是 0 天。
- ⚠️ **要盯住的一处**:生产函数 `exposure_decision.knn_rates` **没有** 31 天排除开关(它只靠 `fwd` 的可得性),
  所以排除是在**传进去的 fwd** 上做的;副作用是原臂的收缩目标(无条件频率)也比融合臂少一天(1/1647)。
  另做了一版「生产口径」对照(近邻 ≤ d − 30、不额外排除):原臂 Brier 0.206802、融合臂 0.206577、
  自助 95% 区间 [−0.006707, +0.006110] —— **结论不变**(见 §4 副项 5)。
- 无条件频率(技能分母)也是逐日 PIT:每天用当日已出完的结果算频率,不是全样本频率。

## 3. 为什么三臂几乎一样(诊断,不是新判据)

- 三臂**都贴着气候态**:离时点无条件频率的平均偏离只有 0.053(融合)/0.052(原)/0.025(基率),
  而 Brier 的差距在 1e-4 量级 —— 偏离幅度与 Brier 改善不同量级。
- 收缩口径决定了这一点:三臂都按「独立段数」向无条件频率收缩(`SHRINK_K = 5` 伪段)。
  原臂每天的近邻是 150 天、但独立段数只有 **4–8 段**(相邻近邻日相差 ≥ 30 天才算新段),
  于是收缩后剩下的几乎全是气候态。基率臂有 **403 / 1587 天**直接退回无条件(同桶 n < 60)。
- 24 维向量的 **179 行全零**(写者热身期)是真缺陷:全零向量两两距离 0,会挤进原臂的 top-150 ——
  实测 2022-06-01 有 **38/150**、2023-04-14 有 **53/150** 是全零向量,2024-02-25 起才是 0。
  这稀释的是**原臂**,不是融合臂的功劳。
- 标签分布(公共样本):down 260 / flat 898 / up 429。

## 5. 结果里还看到了什么(探索性 —— 需另立预注册、在新数据上过零信号对照)

1. **结论依赖价源**:永续价下融合臂略好、现货价下略差,两个源都在 ±0.0004 以内。
   → 需要另立预注册,固定价源口径再在新数据上过零信号对照。
2. **K = 250 时融合臂技能转正(+0.0068),是所有规格里唯一为正的**;K = 100 时反而更负(−0.0069)。
   → K 是自由参数,这样挑等于重新开一摊,需要另立预注册。
3. **六状态里 S2 / S5 融合臂明显更好、S3 / S6 更差**(S2:0.168 vs 0.189),方向不一致;
   而且 463/1587 天因特征缺失进不了状态地图,两套描述的样本口径不一样。
4. **24 维向量的 179 行全零热身向量挤占原臂 top-150**(2022-06 有 38/150)。这是原臂的缺陷,
   值得单独量化(但修它就是改生产代码,不在本卡范围)。
5. **30 天三档 BTC 方向这个题,三臂技能都在 ±0.002 以内**;连基率臂也只是把气候态挪了 0.025 的平均偏离。
   「③ 的近邻描述」在这个问题上目前**没有可兑现的技能**。
6. 块长 30 / 60 / 90 给出的区间宽度几乎一样(±0.006),日均差的噪声比差值大 36 倍。
