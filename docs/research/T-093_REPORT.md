## §3 挖掘

### 关键观察 — 条件规则不是「规则变弱」而是「条件信号没区分力」
W3 R2c 是唯一看起来通过的边缘案例:实际 +3.94%, 打乱分布 p50 = 2.66%, p90 = 7.65%。实际比中位好,但打乱分位 62.8 < 90,pass 失败。
**所有规则的边际改进都在(打乱分布均值) ± 几个 pp 之内 — 这意味着状态标签本身对「事件该不该被启用」几乎没有信息含量。**

### W2 R1c shuffle_pct=0.6 是结构性结论
W2 R1c 实际改进 -1.72%,但 shuf_p10 = -0.87%, p90 = 28.07%。**实际比 99.4% 随机都差。**
原因:W2 有 564 个事件(每年 280+,几乎每周一个),条件版加权后大量事件被「改善周半权重」放过,反而引入了一半的下行风险。
**条件规则 = 「无条件更严」,而事件多为下行 ⇒ 条件版系统性差。**

### R3c 弱底子回暖未被触发
R3c 中「弱底子回暖 = growth_30d ≤ 2% 且 delta > 0」的事件回补逻辑 — 在所有 3 窗口加起来只有 20-23 周被标记为 weak_recovery。
W2 共有 1798 个 R3 事件触发,但 weak_recovery 的周占 < 22 ⇒ 回补覆盖率极低,**这条逻辑没有显著影响 R3c 结果**。

### 与 S-570 prior 的张力
prior S-570 探索性结论:「暴涨名 30 日相对 BTC 在边际变差时 −28.9(中间组 −6.6),改善时 −13.0(中间组 −5.0)」。
我们测量的条件改进 ≈ 0%(−3.27% 到 +3.94%)。**这与 prior 方向一致(变差组更差、改善组没那么差),但绝对数值完全不同** — 因为我们测量的是**条件版 vs 无条件版的差**(本身就是双重事件)。
**S-570 的「变差更差」 ⇒ 我们的条件版(变差周 R1c 全禁、R3c 加仓)在 W2 R1c 上确实是「变差周内最严」 ⇒ 应该 +3 到 +5% 改进,但实测 −1.72% — 与 prior 单边信号不一致。**

## §4 失败原因 / 边界

- **状态标签信息含量低**:W1/W2/W3 改善周占比都 ≈ 50%。**边际流动性 × BTC 趋势的二元状态对该面板的事件组合相关性极低。**
- **W2 高事件密度陷阱**:564 个事件 × 13 周 ≈ 7300 禁用周,已经覆盖 100% 的面板。**条件版的「加权 vs 不加权」差异被事件总数淹没**。
- **W1 事件数 255,禁用周数 3315 < nM × 23 = 3105 ⇒ 几乎覆盖**:同样密度问题。
- **状态标签与事件触发时间相关性弱**:z30 事件触发(异常涨幅) vs 状态标签(USDT 边际 / BTC MA200)是不同维度的信息。
