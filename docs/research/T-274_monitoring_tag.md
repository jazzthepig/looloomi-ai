## 副项(只报不判)

1. **打标签后 180 天内被宣布整币下架的比例:45 / 80 = 56.25%**;任何时候被下架的 54 / 80 = 67.5%
   (来源 `delisting_watch`)。
2. **标签被移除(monitoring_tag_removed)之后 30 天**:8 个代币(CVX / FLOW / GPS / MBL / MLN / SUN / ZEC / ZEN),
   5 个可算,中位 **−24.27%**、均值 −13.95%、80% 为负。
3. **按标签前市值三分位**:小市值 n=11 中位 **−45.47%** / 中 n=11 **−19.90%** / 大 n=12 **−14.64%**(单调:越小越差)。
4. **标签之前**:打标签前 30 天超额中位已经 **−13.19%**(83.3% 为负),公告当天跳空中位 −9.23%,标签后 7 天超额中位 −7.07%。
   ⇒ 标签是**滞后的**:跌幅在标签之前就已经开始,标签之后是继续跑输,不是「贴标签才跌」。
5. **把硬规则前移实际吃到的那一段(描述,不判)**:36 个有价代币里 28 个后来被宣布下架,**打标签日 → 下架公告日**
   中位 **62 天**(均值 94 天),这一段的超额中位 **−41.39%**、均值 −43.68%、p10 −70.44%、89.3% 为负(n = 28,全部可算)。
   ⇒ 「公告即剔除」前移到「打标签即剔除」,平均能提前约两个月离开这批名字,那一段的超额中位约 −41%。

## 覆盖与诚实说明(三条,都会影响读数方向)

1. **2023-07-26 推出监控标签的那批代币不在样本里。** 入库的解析器只从**标题**取代号,而推出公告的标题
   (`Introducing Seed Tags & Monitoring Tags for Tokens with High Volatility and Risks`)里没有代币列表 ⇒ 该行 `symbols` 为空。
   所以样本是**后来被「Extend … to Include」逐批加进来的 80 个**(首次打标签 2023-10-04 → 2026-10-09),
   **不是**当初被打上「高波动 / 高风险」标签的原始一批。那一批是最贴题的一批,补进来大概率让效应更负 —— 但那是**样本口径变更**,须另立预注册,本卡不做。
2. **价格覆盖 36 / 80**(`asset_mcap_daily` 里完全没有这 44 个代号)。缺失的 44 个里有 **23 个在 180 天内被下架**
   ⇒ 缺失集偏向「跌得最狠 / 已死」的那批,留下的 36 个偏幸存者 ⇒ **真值大概率比 −18.28% 更负**,但本卡只报了有价的那 36 个。
3. **副项 2 只 5/8 可算**(GPS / MBL / CVX 无价格源);副项 5 的 28 个全部可算。
