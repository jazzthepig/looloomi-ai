## 0. 预注册口径(先写后算,只算一次,不扫参数)

**样本**
- state_daily(entity=panel)自 2019-01-01 起(四个特征都从这天开始)。
- 条件 C 需要三个特征同时非空,而 `vol_pct_3y` 在 **2021-07-12 及以前全是 NULL** ⇒ **C 的最早可得日 = 2021-07-13**。
- universe = 2021-07-13 起、且 BTC 侧还剩满 28 根日线的每个日历日(**n = 1912**,末位 2026-10-06)。

**条件 C**(三个同时成立)
`breadth_above_ma50 ≤ 0.10` 且 `dist_200 ∈ [0, 0.10]` 且 `vol_pct_3y < 0.20`

**事件簇**
满足 C 的日子按时间排序,**相邻间隔 ≤ 10 天归为同一簇,取簇首日**;簇数 = 独立事件数。

**观测窗**(t = 簇首日,入场 = t 日收盘)
- 窗口 = t+1 … t+28 共 28 根 BTC 日线(ohlcv_daily,symbol=BTC,source=binance_hist)。
- (1) **碰线**:窗口内任一天 BTC 收盘 < **当日** 200 日均线(用 binance_hist 收盘自算 200 日简单均线)⇒ touch = 1。
- (2) **28 日收益** = close[t+28] / close[t] − 1。
- (3) **28 日最大回撤** = 窗口内(含 t 收盘)收盘序列 running peak → trough 的最大跌幅。

**对照**
- **无条件基率**:universe 内每一天同口径。
- **随机对照**:抽**同样个数的簇首日**,块抽样(平稳块自助,`apparatus.stationary_bootstrap_index`,mean_block=20),
  1,000 次,种子 232;分位用 `apparatus.null_distribution` / `apparatus.percentile_of`。

**判定门槛**
独立事件簇 **< 8 ⇒ 只报不判**(不写「显著 / 不显著」)。

**副列(只报不判)**
C 且 `stable_supply_30d < −0.02`(该特征最早可得日 2019-01-01)。

纪律:只读;不改代码、不做 DDL、不入库;翻页带 `order=`;零分布与分位只用 `src/data/evaluation/apparatus.py`。

## 5. 稳健性

| 变体 | 条件 C 碰线率 | 无条件 | 差 |
|---|---|---|---|
| 主口径(簇首日,窗口 t+1…t+28) | 0.500 (2/4) | 0.5868 | −0.087 |
| **信号日挪一天**(入场 t+1,窗口 t+2…t+29) | 0.500 (2/4) | 0.5866 | −0.087 |
| **改用簇末日**当信号日 | 0.500 (2/4) | 0.5868 | −0.087 |
| **只保留 t 当天 BTC 在线之上**的日子 | 0.500 (2/4) | **0.2329** (n = 1022) | +0.267 |
| **只保留 t 当天 BTC 在线上 0~10%(C 选的那条带)** | 1.000 (n = 1) | **0.6266** (n = 241) | — |

三条口径说明,按重要性排:

1. **无条件基率 0.587 被「t 当天就已经在线下方」的日子抬高了** —— universe 里 1912 天有 890 天
   在 t 当天不在线上,只要还在线下,窗口内必然算「跌破」。把比较限制在 t 当天在线之上的日子,
   基率掉到 0.233。
2. **但 0.233 也不是当前状态的可比数** —— 复盘里的当下是**贴线**(自算距线 +5.8%,state 口径 +5.9%),
   离得越近越容易碰。同带子集(自算距线 0~10%,n = 241)的无条件碰线率是 **0.627**。
   这才是复盘里「随机游走给约 50%」该对照的数:**主观的 ~50% 与实测的 63% 同量级,并不离谱**
   (随机游走 28 天 σ≈8.7%、线在 −5.6%,给 50% 有几何依据)。
3. C 的 4 个簇里只有 1 个(2023-08-16)落在「自算 0~10%」带内,带内条件 C 的碰线率因此是 1/1 ——
   没有信息量。带内 0.627 与带外 0.233 的差别主要来自「离线的距离」,不是来自 C 的另外两个条件。

结论仍不变:**4 个簇,只报不判**;上面这些是量出来的基线,不是「C 有效 / 无效」的判词。
4 个簇里 2 次跌破分别发生在窗口第 1 天(2023-08-17)与第 13 天(2024-07-04)。

### 5.1 探索性:把 dist_200 换成自算的 BTC 距线(样本更大)

条件 C 用的是 state 的 `dist_200`(§6:与自算的 BTC 线不同源)。**探索性**地把 dist 换成
「自算 BTC 距线 ∈ (0, 10%]」再套同样的另外两个条件,样本大得多:

| 切分(未预注册,只报) | 满足日 | 独立簇 | 逐日碰线率 | **簇首日碰线率** | 簇首日 28 日收益 均值 / p10 / p50 / p90 | 簇首日回撤均值 |
|---|---|---|---|---|---|---|
| 自算带 0~10% + vol<0.20 | 62 | 11 | 0.581 | **0.364** (4/11) | +15.4% / −5.4% / +16.1% / +36.6% | −7.6% |
| 自算带 0~10% + vol<0.20 + 广度≤0.10 | 19 | 6 | 0.684 | **0.500** (3/6) | +10.6% / −8.7% / +7.8% / +17.4% | −7.3% |
| (预注册的 C,state 带) | 25 | 4 | 0.500 | 0.500 (2/4) | +10.8% / −8.7% / +21.1% / +26.9% | −10.6% |

三行的结论一致:簇首日碰线率落在 **0.36 ~ 0.50**,28 日收益分布的 p10 三行都是 −5% ~ −9%。
预注册的 C 用 state 的线,探索性的两行用自算的线,样本从 4 簇扩到 6 / 11 簇,量级没变 ——
**这不是「C 有效」的证据(没有对照检验),只是说 C 的样本没有被换口径放大或缩小。**

## 6. 口径警告:条件里的「200 日线」与碰线判定的「200 日线」不是同一条

- `state_daily.dist_200` 的 source 标为 **`registry.core_nav`**(组合基准净值口径),不是 binance_hist 的 BTC 收盘。
- 用 ohlcv_daily 的 BTC 收盘自算 200 日均线,得到的距离与 state 的 `dist_200` 有系统性偏差(按年中位数):
  2019 −0.151、2020 +0.022、2021 +0.090、2022 −0.005、2023 −0.058、2024 −0.035、2025 −0.015、2026 −0.026。
  换 coingecko 序列算,偏差几乎一样(±0.005 以内)⇒ **不是价格源的问题,是线的定义不同**。
- 最靠近当下几天两者几乎一致(2026-11-01:0.0693 vs 0.0705;11-03:0.0592 vs 0.0580),
  但历史上可差到 5~15 个百分点。四个历史簇里最极端的是 2023-08-16:
  state 的 `dist_200` = **+0.0007**(贴着线),而按 binance 序列 BTC 在自家 200 日线上方 **+5.4%**。
- 后果:条件 C 说「贴着标记线」,碰线判定说「跌破 BTC 自己的 200 日线」,**两条线不同源**。
  本卡不擅自统一口径(会改预注册),只报差异;若要统一,应另立预注册卡并写清用哪条线。

## 7. 给复盘里主观情景权重的一个底(前向预期,机器结算)

用同一批数据量出来的「28 天后条件还在」的比例(universe 内,同口径):

| 量 | n | 28 天后仍成立的比例 |
|---|---|---|
| `dist_200 ∈ [0, 0.10]` → 仍 > 0 | 209 | **0.493** |
| `breadth_above_ma50 ≤ 0.10` → 仍 ≤ 0.10 | 527 | **0.362** |
| `vol_pct_3y < 0.10` → 仍 < 0.10 | 324 | **0.355** |

据此写下的前向预期(`docs/research/scenarios/lane-c-T-232.json`,到期按 Brier 结算):

| id | 命题 | 概率 | 到期 |
|---|---|---|---|
| T-232-1 | 2026-11-26 state `dist_200` 仍 > 0 | 0.45 | 2026-11-26 |
| T-232-2 | 2026-12-01 state `breadth_above_ma50` 仍 ≤ 0.10 | 0.35 | 2026-12-01 |
| T-232-3 | 2026-12-01 state `vol_pct_3y` 仍 < 0.10 | 0.35 | 2026-12-01 |
| T-232-4 | 2026-10-29 起 28 天内 BTC 曾收盘低于当日 200 日均线 | 0.40 | 2026-11-26 |

T-232-4 的 0.40:实测三档簇首日碰线率 —— 自算带 + vol(11 簇)0.364、自算带 + vol + 广度(6 簇)0.500、
预注册的 C(4 簇)0.500;当下簇属最后两档的形状,取 0.40(比最宽口径的 0.364 略高,
因为当下簇同时满足广度≤0.10 与 vol 分位极低 0.050)。**注意:这不是「C 显著」的结论**,
4~11 个簇的样本量撑不起检验,这里只用一个被量过的数做前向预期。
T-232-1 的 0.45 在实测 0.493 上打了点折(当下簇已经在状态里待了 6 天,剩余持续时间短于新鲜样本)。
