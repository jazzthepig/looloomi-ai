## 3. T2 / T4 的符号反转是数据的事实,不是实现 bug(四种独立复核)

T2 预注册「F2 → BTC 收益**负**」,实测 **+0.1474**;T4 预注册「F3 → 回撤**更深**」,实测 **+0.1707**
(mdd30 是负数,正 IC ⇒ F3 高时回撤更**浅**)。这种反转必须排除是自己的实现问题。四条独立证据:

1. **scipy 独立重算**(不碰脚本里的 `rankdata` / `pearson`):
   T1 +0.0306(主跑 +0.0292)· T2 **+0.1491**(+0.1474)· T3 +0.0048(+0.0058)·
   T4 **+0.1692**(+0.1707)· T5 +0.1265(+0.1264)—— 全部一致到 ±0.002。
2. **符号约定核对**:mdd30 分布 n=2075、mean −0.0872、min −0.4306、max +0.1545 ⇒ 确实是「负数、更负 = 更深」,
   T4 的正 IC 就是「F3 高 ⇒ 回撤浅」,不是符号写反。
3. **严格窗口敏感性**(365 天分位要求窗口内满 365 个有效值、180 天均值要求满 180 个):
   F2/F3 样本起点从 2021-04-30 推到 2022-01-29 —— T2 仍 **+0.1327**、T4 仍 **+0.1088**、T1 变 −0.0089、T5 衰减到 +0.0351。
   **T2/T4 的符号不依赖窗口口径。**
4. **零分布换写法**:主跑的 `np.roll(整条序列)` 受前段暖机 NaN 影响(每次抽样有效子集略不同);
   改成「先压缩有效子序列再循环滚动」重算:T2 原方向分位 0.0400(主跑 0.042)· T4 0.0720(主跑 0.098)· T5 0.7400。
   结论不变。

**事后翻方向也救不回来**:把 5 条的方向全部翻过来重算 BH(单侧 p 变成 0.545 / **0.042** / 0.488 / 0.098 / 0.755),
BH q = 0.68125 / **0.21** / 0.68125 / 0.245 / 0.755 ⇒ **仍没有一条过 q = 0.10**。
⇒ 「预注册方向写错了」不是本卡失败的原因;即便如此,家族口径下也没有证据。

**趋势混淆诊断**(F2/F3 与日期序号的 Spearman:F2 **−0.6737**、F3 **+0.6880**、F1 −0.2860;
结果变量 btc_ret30 +0.0587、btc_mdd30 +0.2186、alt_exc30 −0.0825):把**特征与结果都对时间取秩回归残差**后再算偏相关,
T2 **+0.1341**、T4 **+0.1468**、T5 +0.1174、T1 +0.0249、T3 −0.0007 ⇒
**方向反转不是纯日历影子**(F3 本身是「越晚越高」的强趋势,这一层已部分剥离)。

## 4. 口径偏离(逐条写明)

① 山寨价格用 `ohlcv_daily`(source=binance_hist,同日去重)—— 卡写的 `cg_coin_mcap_daily` 里**没有 ① 面板任何一个主币**(实测 0 行)。
② T5 台账未写方向 ⇒ 双侧判(|IC| 对 |零分布|),两段 / 残差只要求与全样本同号。
③ 山寨等权在两端都有价的名字不足 22 名里的 80%(≥18 名)时该日记缺失(实测最低覆盖 0.818)。
④ 控制变量用永续 BTC 的过去 30 天对数收益(只用 ≤ d)。
⑤ 山寨超额里减的 BTC 用 `ohlcv_daily` 现货(与山寨同源)。
⑥ F2/F3 的 365 天分位在窗口内有效值 < 91 时留空(⇒ 实际样本从 2021-04-30 起,台账写的样本起点是 2021-03-01)。
   §3.3 的严格窗口版本已作敏感性对照。
⑦ 零分布的「循环平移」算子写在脚本内(`np.roll`),机器与分位仍走 `apparatus.null_distribution` / `percentile_of`。
   —— 给 @seth:这个算子每张卡各写一遍正是 10-14「手写零分布」的病根,建议进 `apparatus.py` 统一。

## 5. 结论与后续

- **S-742 的 5 个检验在预注册口径下 0 通过** ⇒ 「谁在买」这一族(场所成交份额 → 之后 30 天)在本数据上**没有拿到证据**。
- T2 的反向读数(韩国现货占比高 ⇒ 之后 30 天 BTC 收益**更高**,反向单侧 p = 0.042;两段同号;控制后 +0.1159)
  与 T4 的反向读数(衍生品占比高 ⇒ 回撤**更浅**)在家族 BH 下都过不了(q 0.21 / 0.245)。
  **探索性 —— 需另立预注册、在新数据上过零信号对照**,不能在本卡改判、也不能反过来说 S-742「其实是正方向成立」。
- 观察到的量级值得留意:F3(衍生品 ÷ 现货 365 天分位)对 **山寨 30 天超额** 的 IC = **+0.2294**、控制时间后 +0.2409
  —— 这一条**不在 S-742 的 5 个检验里**,是探索性读数。
- 另注:场所份额的**原始水平**对结果几乎没有 IC(+0.0009 / −0.0240 / +0.0128 / +0.2964 / +0.1448),
  效应几乎全部来自「份额相对自身历史的位置」—— 若另立预注册,应把「水平」与「历史位置」分开,并预注册双向 + BH。
- 台账未写方向的检验(T5)应写死方向,否则事后翻方向会污染家族口径。
