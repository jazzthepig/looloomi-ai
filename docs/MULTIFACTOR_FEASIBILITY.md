## 2. WorldQuant 式为什么不能 —— 是数学,不是意愿

主动管理基本定律:**`IR ≈ IC × √广度`**。WorldQuant 的 edge 是**制造上千个弱 alpha 再分散**,
它成立的前提是广度足够大,让每个 IC 0.02 的信号叠加成可交易的 IR。

**我们的广度实测:**
```
75 个资产 · 2,775 对 · 平均两两相关 ρ̄ = 0.310  (p25 0.09 · p75 0.60)
N_eff = 75 / (1 + 74 × 0.310) = 3.1
```
**75 个资产的有效独立赌注是 3.1 个。** 加密资产由一个共同因子主导,这不是数据问题,是资产类别性质。

**再叠加历史长度:** CIS 五柱 **436 天(约 1.2 年)**。
WorldQuant 的 alpha 在数十年、数千标的上检验。

**⇒ 在 N_eff≈3 且 1.2 年历史上搜索上千个弱因子,不会得到分散化收益,
只会得到多重检验的产物。**

### 而这个实验我们已经跑过了
**R76–R94 的 15 连败,就是 WorldQuant 式搜索在广度不足条件下的结果。**
台账写得很清楚:那不是运气,是**设定错误** —— 横截面去均值 = 按构造扔掉 beta,
然后在残差里找不存在的东西。**再做一轮更大规模的同类搜索,是重复同一个错误,只是更贵。**

S-101/S-102 又给了一次独立佐证:**473 个事件、5 个档位,没有一档显著为正;
把它切成 5 个偏离桶后每桶只剩 16–17 个事件,两端立刻欠功效。**
**样本不是被浪费了,是本来就只有这么多。**

## 3. Millennium 式为什么"结构上能" —— 缺的是 pod 不是机制

Millennium 的核心不是因子,是**中心风险分配**:风险预算而非资本预算、
机械回撤阶梯、慢升快降、相关性上限、有效宽度约束。**这些我们都有规格且部分已实现:**

| Millennium 要件 | 我们的状态 |
|---|---|
| 风险预算(按波动归一) | ✅ `RISK_ALLOCATOR_SPEC §1` |
| 机械回撤阶梯 + 冷冻 | ✅ 已实现且有单元测试(S-90 修复了不解冻 bug) |
| 事前波动率目标 | ✅ 已验证优于事后止损(Sharpe 0.79→1.01,DD −53.9%→−23.8%) |
| 慢升快降晋升阶梯 | ✅ 规格 §5 |
| 相关性上限 / 有效宽度 | ✅ 规格 §4 |
| **≥5 条不相关 pod** | ❌ **0 条通过门槛** |

**⇒ 分配器是对的,但"分配"需要有东西可分。一个 pod 的 Millennium 就是一个策略。**
**`N_eff = 3.1` 同时也约束了 pod 数** —— 在同一个高相关面板上做 5 条 sleeve,
它们大概率互相高度相关,规格 §4 的"相关 >0.7 合并为一个 pod"会直接把它们并掉。

## 4. 那我们的数据结构支持什么

**不是"上千个弱信号分散",而是"少数几个有因、带相位条件的强赌注"。**

证据链指向同一个形状:
· **`N_eff=3.1`** ⇒ 分散化收益有限,集中度是被迫的,不是选择;
· **U 形 / 偏离度单调**(S-102)⇒ 有效信息在**离群**而非**排名**;
· ~~**近中位显著跑输**(t=−2.91 / −1.96,两种参数化都成立)⇒ **排除信号比选择信号证据强**~~
  🔴 **2026-08-07 S-103 推翻。** 中性化上线后重测:NEUTRAL 档 naive −6.63%(t=−8.68)
  拆开是**基准错配 −5.66 / β −0.70 / 真残差 −0.27(t=−0.58)**。85% 来自拿 **BTC** 当基准
  (BTC 相对面板 +2.16pp,t=3.96,67% 交易日跑赢)。**五档没有一档 |t|>2。**
  且 NEUTRAL 就是低 β 桶(β=0.15),"剔除近中位"= 剔除低 β = **给账本加杠杆**,不是排除产品。
· **①层 + vol target** 已有可复现的风险形态(8/9 正年,DD −23.8%)—— **本条未被 S-103 触及**,
  因为它测的是总收益 vs 持有面板,不含"减一个不对的基准"这一步。

**这正是 ①②③ 三层的形状:吃 beta → 在持仓内倾斜 → 择时调总暴露。**
它不需要广度,它需要**一个正确的基准和一个可靠的排除规则**。
