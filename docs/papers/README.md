## 分界线(防止互相稀释)

**I 只论 agent 行为。** 金融数字只作为"失效被观察到的基质"出现,不作为金融结论。
任何"这个策略好"的主张都不属于 I。

**II 论的是规格错误,不是运气。** R76–R94 十五次失败的共因是横截面去均值 = 按构造丢弃 β,
即把④层当①层做。II 的证伪条件:若某个纯α sleeve 在 OOS 稳定跑赢 hold-the-panel,II 的强命题就被推翻。

**III 是纯经验发现,不依赖 I 或 II。** 23 次触发 / 339 天 / 每次重置高水位 → −54%;
收紧到 −10% → −60.1%。事前 vol targeting → Sharpe 1.01 / DD −23.8%。**这篇可以独立投。**

**IV 从 I 中剥离。** I 里它是"补救措施",在 IV 里它是主论点,需要更严的方法论
(现在只有观察性证据 4/4 vs 0,无对照臂 —— IV 必须补一个真实验臂才够格)。

**V 从 I 中剥离。** I 里极性错误是 APC 的一个实例(现成结论没被查阅);
V 里它是一个可推广的因子构建规程:**先分类,后使用**。
