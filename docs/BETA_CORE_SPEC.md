# Layer-① Beta Core — 规格书 (Seth, 2026-07-27, M-WO-A 的实现依据)

> **它是什么:** 我们保证吃到的市场收益 —— FoF 的核心持仓,长期满仓多头、被动、低成本。
> **它更重要的身份:** **所有策略的基准。** 从今天起"跑赢"的定义是跑赢这条曲线,不是跑赢 0。
> 层级见 `HIGH_DIM_ONTOLOGY.md` §5b。本文件是 M-WO-A 的唯一实现依据 —— 有歧义先问,别猜。

## 0. 为什么规格必须先写死
一条"等权持有"的曲线看起来无脑,但它有 **4 个能凭空造出几十个点收益的陷阱**(§4)。基准被污染
= 之后每个 sleeve 的"超额"都是假的。**这条曲线的可信度 = 整个验证体系的可信度。**

## 1. 成分与资格(PIT,零存续偏差)

**候选池:** `ohlcv_daily` 中 `source='binance_hist'` 的 crypto 面板(当前 41 符号,2017-08 起)。

**每次再平衡日 t,资格规则(只用 t 之前可得的信息):**
| 规则 | 阈值 | 理由 |
|---|---|---|
| 上市成熟期 | 在 t 前已有 **≥ 180 个交易日**收盘价 | 新币上市初期暴涨暴跌,纳入即制造虚假收益(listing bias) |
| 流动性 | 过去 30 日**日均美元成交额 ≥ $5M** | 容量约束:装不进去的收益不是收益 |
| 数据完整 | 过去 30 日缺失 ≤ 3 日 | 缺口用前值填 = 虚假的低波动 |
| 稳定币/包装币 | 排除(USDT/USDC/WBTC 等) | 不是 beta,是现金/重复暴露 |

**关键纪律:资格在 t 判定,持有到 t+1 再平衡;绝不用"今天还活着"来筛选历史。**
一个币在 2022 年符合资格就该进 2022 年的持仓,哪怕它 2024 年归零 —— **归零必须被记进曲线**。

## 2. 权重(两个变体,都要做)

- **① EW(等权)** — 每个合格资产 `1/N`。代表"广度暴露",波动高、更能体现选券空间(②层的画布)。
- **① CW(市值权重,带上限)** — 权重 ∝ 流通市值,**单一资产上限 30%**,超出部分按比例分给其余。
  上限是必须的:不封顶时 BTC 会占 60%+,这条曲线就退化成"BTC 走势",失去 FoF 含义。
- 两条都产出。**对外/对 LP 的默认口径是 CW-capped**(更像真实基金);EW 用于内部研究基准。

## 3. 机制

| 项 | 规格 | 理由 |
|---|---|---|
| 再平衡频率 | **月度**(每月首个交易日),外加季度变体做成本敏感性 | 月度是行业惯例;更高频只增成本 |
| 权重漂移 | 两次再平衡之间**不干预**(让盈利头寸自然长大) | 这才是"持有";日频再平衡会偷偷做空动量 |
| 成本 | 换手 × **10 bps 单边**(基准情形),另跑 5 / 20 bps 敏感性 | 必须显式;"零成本基准"是自欺 |
| 现金 | **0%**(永远满仓) | ①层的定义就是暴露;择时属于③层,不许混进来 |
| 分红/质押收益 | v1 **忽略**,并显式声明 | 保守 = 低估我们自己的基准,可接受;高估不可接受 |
| 计价 | USD(USDT 报价视同 USD) | |

**退市/归零处理(最容易造假的地方):**
资产被下架或数据中断 → **在最后一个有效收盘价卖出,当日按比例分配给其余持仓**;
若因归零而下架,**必须记为 −100%**,不许静默剔除。这一条决定曲线是否诚实。

## 4. 四个必须显式检验的陷阱(交付时逐条回答)

1. **存续偏差** — 成分是否只含"今天还在的币"?→ 交付必须包含**已退市/归零资产的清单及其贡献**。
2. **上市偏差** — 是否纳入了上市 <180 日的暴涨期?→ 报告每年新纳入数量与其贡献。
3. **回填偏差** — Binance 历史是否"事后补录"了当年不可交易的币?→ 抽查 3 个 2018 年成分,确认当时确实可交易。
4. **成本幻觉** — 换手率与成本是否显式?→ 报告年化换手 + 成本拖累(bps/年)。

## 5. 交付物(M-WO-A 的验收标准)

1. **日频 NAV 曲线**,2017-08→今,四条:EW / CW-capped × {0bps, 10bps}。落 Supabase 表 `beta_core_nav`
   (date, variant, nav, n_holdings, turnover, cost_bps_applied)。
2. **分周期报表**(2018熊 / 2020-21牛 / 2022熊 / 2023-24复苏 / 2025-26熊 + 全期):
   total_return · CAGR · Sharpe · maxDD · 年化换手。
3. **对照基准**:同期 **BTC 单一持有** 与 **ETH 单一持有** —— 回答"我们的 FoF 内核凭什么优于直接拿 BTC"。
   这是 LP 会问的第一个问题,必须先自己回答。
4. **§4 四个陷阱的逐条书面回答** + 退市资产清单。
5. **前向 paper**:同一规则每日跑,写 `beta_core_nav` variant='live_ew'/'live_cw' —— 从今天开始积累真实前向记录。

## 6. 之后如何被使用(避免歧义)

- **②层(CIS 倾斜)** 的测试形式:同样的合格池、同样的再平衡日,权重改为 `w_i ∝ EW × f(CIS_rank)`,
  **单资产 0.5x–2.0x 上下限、仍然满仓多头、不做空**。判据:**总收益 / Sharpe / maxDD 对比本规格的 EW**。
- **③层(暴露乘数)** 的测试形式:持有本规格的组合,总暴露按相位缩放 **0.7x–1.3x**(不足部分持现金,
  **绝不做空**)。判据:改善本曲线的 return/DD。
- **所有 sleeve 的报告口径**:`total_return` · `vs 本规格 CW-capped` · 再报超额。

## 7. 边界
不含杠杆、不含衍生品、不做空、不择时 —— 这些都在②③层。①层唯一的工作是**诚实地、可容纳地、
低成本地拿到市场收益**。它无聊是对的;无聊且诚实的基准,是后面一切主张的地基。
