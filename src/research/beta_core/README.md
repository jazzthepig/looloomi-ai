## 三个可对外的事实
1. **等权持有面板 > 持有 BTC**(+490% vs +372%)—— 回答了"凭什么不直接拿 BTC"。
2. **成本不吃收益**:10bps 下仅掉 4pp(年化换手 75%)⇒ 可容纳、可复制。
3. **ⓠ闸门同时提收益 + 削回撤**:+1107% / −64.2%(vs 裸持有 +490% / −83.3%),净额已含 67 次切换成本。

## 诚实边界(必须随结果一起报告)
- ⓠ闸门用 **BTC 200日均线**(趋势代理),**不是** `REGIME_OVERRIDE_SPEC` 要的 O1 stablecoin 流动性信号 —— 真正的因还没测。
- 切换 **7.9 次/年**,超出规格 ≤6 次/年 的上限 ⇒ 需加迟滞(hysteresis)。
- 单一参数、未做敏感性分析(200MA 是否稳健?150/250 呢?)。
- 20 币面板(非全 41 币);CW 用成交额代理市值(无市值历史)。
