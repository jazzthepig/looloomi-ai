# Prompt — 精简并整理记忆/协调文档

可复用指令。粘给 Claude Code(精简 `~/.claude/memory.md`)或 Minimax(精简 `MINIMAX_SYNC.md`)。

---

**任务:精简并整理记忆/协调文档(memory.md 及任何超长的 .md)**

目标:让下一次会话能快速 orient,而不是被历史淹没。

规则:
1. **区分 durable 与 dated。** Durable(偏好、工作方式、关键关系、常用流程、架构决定)——保留并磨利。Dated(具体项目、截止日、一次性任务)——若已完成或日期已过,移到归档文件,只把"持久结论"折叠进 durable 段(例:"散户走纯去中心化 vault"留,"6/14 修了某 bug"归档)。
2. **合并重复。** 同一个人/项目/偏好分散在多处的,合成一条,保留信息最全那份的路径。
3. **时间绝对化。** "下周/本季/周五前" → 具体日期。
4. **能随时重查的就删。** 日历、文档、连接工具里随手能拉到的,不留;只留难以复得的(偏好、决策背后的 context、谁负责什么)。
5. **历史不删,归档。** 完成/过期的段落抽到 `ARCHIVE_<name>.md`,主文件只留"现状 + 规则 + 当前任务 + 指针"。
6. **体量约束。** 索引/主 memory 控制在 **<200 行、<25KB**,每条一行、<150 字符:`- [标题](文件) — 一句话钩子`。

输出:列出改了几个文件、各做了什么(合并/归档/删除/改日期)。**先备份原文件再改。**
